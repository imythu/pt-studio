# 05 · 混合资源类型与术语表

## 1. 混合资源类型（决策 D8）

前人的问题：Gazelle 绑定音乐，UNIT3D 绑定影视加 TMDB，NexusPHP 只有平铺的分类，没有结构。

**资源类型本身就是插件。**

```
Group（作品，可选）── 由资源类型插件定义字段和分组规则
  └─ Torrent（核心 torrent 插件只存种子本身 + group_id + type）
```

每个资源类型插件（电影、剧集、音乐、动漫、游戏、电子书、软件、课程等）负责：

| 职责 | 说明 |
|---|---|
| 字段 schema | JSON Schema，上传表单根据它自动生成 |
| 元数据源 | TMDB、豆瓣、IMDb、MusicBrainz、Bangumi、IGDB 等 |
| 分组规则 | 电影按 IMDb ID 分组，音乐按专辑和发行版分组 |
| 标题规范 | 命名规范和校验，在 `torrent.before_upload` 钩子中执行 |
| 搜索 | 索引字段映射、筛选项（见 [04-search.md](04-search.md)） |
| 展示 | 详情页组件，通过前端插槽注入 |

一个站点可以同时安装多种资源类型，新增类型不需要改动核心。

## 2. 术语表系统（决策 D7）

### 2.1 背景

不同站点对同一概念的叫法不同。例如 PTerClub 把魔力值叫“猫粮”；等级名称各站不同，有的站用“府丞 / 府尹”这类古代官职。

### 2.2 会因站点而改名的概念

| 类别 | 概念 |
|---|---|
| 虚拟货币 | 魔力值、做种积分、上传量奖励、各站自己起名的货币 |
| 用户等级 | 等级名、各等级权限、保号等级、VIP / 贵宾、荣誉等级 |
| 身份标识 | 头衔、勋章、徽章、自定义称号 |
| 促销 | 免费 / 2x / 50% / 30% / 2x 免费的名称和图标，全站促销活动名称 |
| 考核 | 新手考核、H&R 的名称和规则说明、保种任务 |
| 种子状态 | 候选、待审核、已审核、禁转、官方、原创、置顶 |
| 社区 | 求种 / 悬赏、站内信、论坛版块、签到、彩票 / 竞猜 |
| 内容 | 分类名、资源类型、制作组标签 |

### 2.3 设计

- 内核提供 `ctx.terms` 服务（由 `terms` 插件实现）。
- 每个插件在清单中声明自己的术语键（如 `bonus.currency`、`levels.class.5`），并提供各语言的默认值。
- 管理员在后台统一覆盖：名称、单位、图标、复数形式。
- 前端统一调用 `t('term:bonus.currency')`；MCP 返回结果、邮件和通知模板使用同一套术语。
- 等级不只是名字不同，规则也不同，所以等级插件采用**数据驱动的规则**（升级条件写成表达式），不同站点不需要改代码。
