## 1. 引言

定义 Bangumi（bgm.tv）元数据源插件，主要服务 type-anime（也可用于书籍、游戏、音乐条目）。共用部分见 [../_shared/metadata-providers-common.md](../_shared/metadata-providers-common.md)。

条款要点：公开 API `https://api.bgm.tv`（v0），要求设置符合其规范的 User-Agent（应用名 / 版本 / 项目地址）；访问令牌可选（公开条目不需要；含 NSFW 条目需要令牌）。

## 2. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-MDBGM-001 | 条目查询 | `lookup("<subject_id>")`：中文名（`name_cn`）、原名、类型（动画 / 书籍 / 音乐 / 游戏 / 三次元）、放送日期、话数、平台（TV / OVA / 剧场版 / WEB）、标签、评分、封面、简介 | P0 | |
| FR-MDBGM-002 | 关联条目 | 获取续集 / 前传关系（`/v0/subjects/{id}/subjects`），供 type-anime 在作品页展示“其他季” | P2 | |
| FR-MDBGM-003 | 搜索 | `search(query, "anime")`（`POST /v0/search/subjects`，type = 2 动画） | P0 | |
| FR-MDBGM-004 | 封面 | 转存 `images.large` | P1 | |
| FR-MDBGM-005 | User-Agent | 必须配置项目 URL；格式 `PT-Studio/<ver> (<project_url>)` | P0 | |
| FR-MDBGM-006 | NSFW | 默认不请求 NSFW 条目；站点配置 `access_token` 并开启 `allow_nsfw` 后才可查询 | P1 | |
| FR-MDBGM-007 | 限速与缓存 | 默认 5 次/秒（保守值，官方未公布硬限时自行限制）；缓存 30 天，连载中条目 7 天 | P0 | |

## 3. 可配置项

静态：`project_url`（必填）、`access_token`（secret，可选）、`api_host`（`api.bgm.tv`）。运行时：`rate_per_sec`（5）、`allow_nsfw`（false）。

## 4. 外部接口需求概述

导出 `metadata-provider`（`type_ids = ["anime", "generic", "music"]`）；HTTP `/api/p/metadata-bangumi/v1/lookup`、`/search`、`/related?id=`；`metadata.fetched`；cron `refresh_stale`。
