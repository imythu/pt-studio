缓存、转存、限速（固定窗口，`rate_per_sec`）、熔断、表结构同 metadata-tmdb 03（schema `metadata_bangumi`）。

## 1. mapper

| Bangumi 字段 | 统一模型 |
|---|---|
| `name` | `titles.original` |
| `name_cn` | `titles.localized["zh-CN"]` |
| `infobox[]` 中 key = 别名 / 英文名 | `titles.aliases`、`titles.localized["en"]` |
| `type`（1 书籍、2 动画、3 音乐、4 游戏、6 三次元） | `kind`：book / anime / music_release_group / game / tv |
| `date` | `release_date`、`year` |
| `eps` / `total_episodes` | `episode_count` |
| `platform`（TV、OVA、剧场版、WEB、TV 特别篇……） | `extra.platform` → type-anime kind 映射：TV→tv、OVA→ova、OAD→oad、剧场版→movie、WEB→web、其余→special |
| `tags[0..10].name` | `genres`（原样中文标签，type-anime 作为搜索字段） |
| `rating.score`、`rating.total` | `ratings.bangumi` |
| `images.large` | `images.cover`（转存） |
| `summary` | `overview["zh-CN"]` |
| `infobox` 中 动画制作 / 导演 / 原作 | `people[]`（role developer / director / writer） |
| `nsfw` | `extra.nsfw` |
| — | `ids.bangumi`；`attribution = {source: "bangumi", url: "https://bgm.tv/subject/<id>", license_note: "数据来源：Bangumi 番组计划"}` |

`infobox` 的值可能是字符串或 `[{v: …}]` 数组，统一取文本。

## 2. 请求

- 头：`User-Agent: PT-Studio/<ver> (<project_url>)`；有令牌时 `Authorization: Bearer <access_token>`；
- 搜索请求体：`{"keyword": q, "sort": "match", "filter": {"type": [2], "nsfw": allow_nsfw}}`，`?limit=<n>`。

## 3. 接口

`GET /v1/lookup?id=`、`GET /v1/search?q=&type=anime`、`GET /v1/related?id=`（返回 `[{id, relation(前传/续集/番外篇…), name, name_cn}]`）。
