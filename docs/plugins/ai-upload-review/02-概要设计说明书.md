| 类别 | 内容 |
|---|---|
| 原则 | 先确定性检查再模型；模型只看最小必要信息；结论是建议；不依赖 moderation（moderation 可选依赖本插件，反之会成环） |
| 模块 | `trigger`（订阅与调度）、`facts`（收集种子事实）、`rules`（确定性检查）、`dupes`（疑似重复）、`llm_review`（提示词与结构化输出）、`report`、`budget` |
| 依赖 | `ctx.torrents`（`get_detail`）、`ctx.llm`（`use`、`profile:cheap`）；optional `ctx.mediainfo`（`compare`）、`ctx.search`（`query`）；视图 `torrent.v_torrent_fields` |
| 事件 | 发布 `ai.upload_reviewed`；订阅 `torrent.created`、`mediainfo.parsed`、`torrent.updated`（字段变化后重审） |
| 延迟任务 | `review`（dedupe = torrent_id + revision） |
| 关键流程 | torrent.created → 调度 review(now + wait_mediainfo_secs)；mediainfo.parsed 到达 → 提前调度（dedupe 保证只跑一次）→ facts → rules → dupes → budget 允许 → llm_review → report → 事件 |
| 设计决策 | DD-AIUR-1：模型调用 effort = low、结构化输出、单轮（无工具）；DD-AIUR-2：只发送种子技术信息与描述摘录，不发送上传者身份；DD-AIUR-3：确定性检查的结论优先级高于模型（模型输出与确定性结论矛盾时以确定性为准并记录） |
| 平台契约新增 | `ai.upload_reviewed` 载荷增加 `model_skipped`、`report_id`；服务 `review` 返回结构见 03 |
| 权限点 | `ai-upload-review.read`、`ai-upload-review.manage`（已登记） |

需求追溯：FR-001、009 → trigger；FR-002 → rules；FR-003 → llm_review；FR-004 → dupes；FR-005、006、010、011 → report；FR-007、008 → budget。
