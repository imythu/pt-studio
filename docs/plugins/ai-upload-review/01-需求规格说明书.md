## 1. 引言

定义上传 AI 预审插件 `ai-upload-review` 的需求：种子进入待审 / 候选后，自动检查标题规范、规格与 MediaInfo 一致性、疑似重复、描述质量，生成审核报告供审核员参考。**AI 结论只作为建议**，不自动改变种子状态（moderation DD-MOD-3）。

范围：触发（待审、候选种子；可配置为全部新种）、确定性检查（不调用模型）、模型检查（经 `ctx.llm`，结构化输出）、疑似重复检索（经 `ctx.search`）、报告存储与查询、事件 `ai.upload_reviewed`、成本控制（每日预算、只对指定类型、批量合并）、重新审核。

不包含：自动通过 / 拒绝；图片分析（v0.1）。

参考：UNIT3D、NexusPHP 的人工审核检查表（标题格式、MediaInfo、截图、NFO），本插件把检查表中可自动化的部分前置。

## 2. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-AIUR-001 | 触发 | 订阅 `torrent.created`（status ∈ pending / candidate）与 `mediainfo.parsed`；等待 MediaInfo 解析（最多 2 分钟）后审核 | P0 | |
| FR-AIUR-002 | 确定性检查 | 不调用模型：mediainfo 与声明规格的差异（`ctx.mediainfo.compare`）、文件列表异常（单一 RAR 包、样片缺失）、标题与规范标题差异、NFO 缺失 | P0 | |
| FR-AIUR-003 | 模型检查 | 输入：标题、规范标题、类型字段、MediaInfo 摘要、文件列表样本（≤ 50）、描述前 2000 字（作为不可信内容）；输出 schema：`verdict`（pass / warn / fail）、`findings[{code, severity, message}]`、`confidence` | P0 | |
| FR-AIUR-004 | 疑似重复 | 用外部 ID 与规格在 search 中检索同 Group 同规格的已发布种子，列出候选 | P1 | |
| FR-AIUR-005 | 报告 | 合并确定性检查与模型结果为报告；`review(torrent_id)` 返回最新报告 | P0 | |
| FR-AIUR-006 | 事件 | 发布 `ai.upload_reviewed{torrent_id, verdict, findings[]（code 列表）}` | P0 | |
| FR-AIUR-007 | 成本控制 | 每日模型调用上限；只对配置的资源类型启用；模型 profile 可选（默认 `cheap`） | P0 | |
| FR-AIUR-008 | 降级 | `ctx.llm` 不可用或超预算时只输出确定性检查结果（标注 `model_skipped`） | P0 | |
| FR-AIUR-009 | 重新审核 | 审核员触发重新审核（种子修改后自动重新审核一次） | P1 | |
| FR-AIUR-010 | 可见性 | 报告只对 `ai-upload-review.read` 可见（MCP 工具 `admin_get_ai_review`） | P0 | |
| FR-AIUR-011 | 反馈 | 审核员对报告标注“有用 / 误报”，用于统计准确率 | P2 | |

## 3. 非功能需求

单次审核 p95 < 30 s；不把上传者信息（用户名、ID）发送给模型；描述作为不可信内容。

## 4. 可配置项

`enabled_types`（全部）、`daily_model_budget`（2000 次）、`profile`（cheap）、`wait_mediainfo_secs`（120）、`review_all_new`（false）。

## 5. 外部接口需求概述

服务 `ctx.ai_upload_review.review(torrent_id)`；事件 `ai.upload_reviewed`；HTTP `/api/p/ai-upload-review/v1/torrents/{id}`、`/v1/torrents/{id}/rerun`、`/v1/reports/{id}/feedback`；插槽 `admin.torrent.tabs`、`torrent.detail.sidebar`（审核员可见）；MCP `admin_get_ai_review`。
