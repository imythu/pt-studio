## 1. 引言

定义站内助手插件 `ai-assistant` 的需求：回答新手关于站点规则与使用方法的问题（基于管理员维护的规则文档与 FAQ，答案附引用），并可调用只读工具查看提问者自己的状态（分享率、H&R、考核、等级），帮助用户理解“我为什么不能下载”这类问题。

范围：知识库（文档、FAQ 条目，Markdown，后台编辑）、检索（Meilisearch 自建索引 `assistant_docs`；可选混合搜索）、对话（多轮，只追加历史）、只读工具（经内核 MCP 注册表调用 `audience = user` 且 `write = false` 的工具，以提问者身份执行）、引用来源、对话保存与删除、限流与预算、MCP 工具 `ask_site_help`、反馈（有用 / 无用）、无法回答时引导到论坛或工单。

不包含：执行写操作（购买、签到等）；回答与站点无关的问题（礼貌拒绝）；读取他人数据。

## 2. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-AIAST-001 | 知识库 | 管理员维护文档（标题、正文 Markdown、标签、可见等级）；修改后重新索引 | P0 | |
| FR-AIAST-002 | 检索 | 问题 → 在 `assistant_docs` 中检索前 5 个片段（按标题与段落切分，每段 ≤ 1500 字） | P0 | |
| FR-AIAST-003 | 回答 | 模型基于检索片段回答，必须标注引用（文档 ID 与段落）；没有依据时回答“规则中没有找到”，并给出论坛 / 管理员联系方式 | P0 | |
| FR-AIAST-004 | 只读工具 | 允许模型调用提问者自己的只读工具：`get_my_profile`、`get_my_stats`、`get_my_ratio_status`、`list_my_hnr`、`get_my_exam`、`get_my_level`、`get_my_bonus`、`list_active_promotions`（白名单可配置）；以提问者身份执行；最多 5 轮工具调用 | P1 | |
| FR-AIAST-005 | 多轮对话 | 会话保存最近 20 轮；只追加历史（ctx.llm 约定） | P1 | |
| FR-AIAST-006 | 范围限制 | 与站点无关或要求违规操作（如作弊方法）的问题：拒绝并说明 | P0 | |
| FR-AIAST-007 | 隐私 | 对话只对本人可见；用户可删除对话；保留 30 天 | P0 | |
| FR-AIAST-008 | 限流与预算 | 每用户每日 30 个问题；全站每日预算 | P0 | |
| FR-AIAST-009 | MCP | `ask_site_help`（单轮，返回答案与引用） | P2 | |
| FR-AIAST-010 | 反馈 | 用户对答案评价；管理员看到低评价问题列表，用于补充文档 | P1 | |
| FR-AIAST-011 | 文档可见性 | 只检索提问者等级可见的文档 | P1 | |

## 3. 非功能需求

回答 p95 < 20 s；检索 p99 < 100 ms。

## 4. 可配置项

`profile`（default）、`tool_allowlist`、`max_tool_rounds`（5）、`daily_questions_per_user`（30）、`daily_budget`（10000 次）、`retention_days`（30）、`fallback_contact`（论坛版块链接）。

## 5. 外部接口需求概述

服务无；HTTP `/api/p/ai-assistant/v1/*`；插槽 `home.widgets`（入口）、`nav.main`；页面 `/p/ai-assistant/`；MCP `ask_site_help`。
