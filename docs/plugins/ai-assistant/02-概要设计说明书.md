| 类别 | 内容 |
|---|---|
| 原则 | 检索增强（只依据站点文档）；工具只读且以提问者身份执行；引用可追溯；对话私密 |
| 模块 | `kb`（文档 CRUD、切分、索引贡献）、`retrieve`（`ctx.search.query`）、`agent`（对话循环：检索 → 模型 → 工具 → 模型）、`tools`（白名单工具经 `ctx.mcp_registry` 调用）、`sessions`（对话存储）、`limits`、`feedback` |
| 依赖 | `ctx.llm`（`use`）、`ctx.search`（`register_index`、`query`）、内核 `ctx.mcp_registry`（`tools`、`call`；⊕ WASM 插件需要可用的宿主接口或改为 Native——本插件设为 **Native**，见 DD-AIAST-1） |
| 搜索 | 本插件作为 `assistant_docs` 索引的贡献者与拥有者（`register_index`）；字段：`assistant_title`、`assistant_body`、`assistant_tags`、`assistant_min_class`；可选混合搜索（embedder 由站点配置） |
| HTTP | `POST /v1/ask`（user）、`GET /v1/sessions`、`GET/DELETE /v1/sessions/{id}`、`POST /v1/messages/{id}/feedback`；管理 `GET/POST/PATCH/DELETE /v1/admin/docs`、`GET /v1/admin/feedback` |
| 关键流程 | ask → 限流 → 检索（可见性过滤）→ 构造请求（系统提示 + 片段 + 历史 + 问题 untrusted）→ ctx.llm.complete（带工具定义）→ 若 tool-use：执行白名单工具（principal = 提问者）→ 追加 tool-result → 再次 complete（≤ 5 轮）→ 答案与引用 → 保存 |
| 设计决策 | DD-AIAST-1：`ctx.mcp_registry` 目前只对 Native 开放（services 目录），本插件改为 Native（与 catalog/plugins.md 中的 WASM 不同，评审时更正）；DD-AIAST-2：工具结果按 mcp 网关的输出过滤规则过滤；DD-AIAST-3：问题与片段都作为 untrusted 内容；DD-AIAST-4：对话历史只追加（ctx.llm 约定），会话超过 20 轮开新会话 |
| 平台契约新增 | catalog/plugins.md：ai-assistant 类型改为 Native；`ctx.search.register_index` 允许插件拥有私有索引并处理其可见性；MCP 工具 `ask_site_help` |
| 权限点 | `ai-assistant.use`、`ai-assistant.manage`（已登记） |

需求追溯：FR-001、011 → kb；FR-002 → retrieve；FR-003、006 → agent；FR-004 → tools；FR-005、007 → sessions；FR-008 → limits；FR-009 → MCP；FR-010 → feedback。
