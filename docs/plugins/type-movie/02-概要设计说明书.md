## 1. 设计目标与原则

遵循共用设计全部原则；本插件的重点：按外部 ID 稳定分组、规格字段规范化、原盘与文件结构校验、质量排序。

## 2. 总体结构

| 模块 | 职责 |
|---|---|
| `schema` | field_schema / group_schema 生成（含本地化标签术语键） |
| `normalize` | 规范化、发布名补全、外部 ID 解析（从链接中提取 ID） |
| `grouping` | group_key、canonical_title、canonical_group_title |
| `rules` | 钩子：文件结构、扩展名、标题策略、去重、trump |
| `meta` | 订阅 `group.created` / `metadata.fetched`，更新 Group 字段 |
| `search` | 搜索贡献 |

## 3. 对外接口清单

| 类别 | 内容 |
|---|---|
| 导出 | `content-type`（`info`、`normalize`、`group-key`、`canonical-title`）、`search-contributor` |
| 依赖服务 | `ctx.torrents`（`update_group`；作用域 `write:group`）、optional `ctx.metadata`（`lookup`） |
| 视图 | `torrent.v_torrent_public`、`torrent.v_group_public`，以及共用设计 §9 申请的 `v_torrent_fields`、`v_group_fields` |
| 钩子 | 处理 `torrent.before_upload`（priority 10）、`torrent.before_update`（priority 10） |
| 订阅 | `on_group_created`（`group.created`）、`on_metadata_fetched`（`metadata.fetched`） |
| 延迟任务 | `fetch_metadata` |
| HTTP | `/api/p/type-movie/v1/admin/vocab`（词表）、`/admin/quality`（质量权重）、`/admin/groups/{id}/lock-fields`（锁定不被元数据覆盖的字段） |
| 插槽 | `torrent.detail.info`、`group.detail.header` |
| 权限点 | `type-movie.manage`（已登记） |
| 能力 | `sql`、`kv`；views 如上；scopes `ctx.torrents = ["write:group"]` |

## 4. 数据设计概要

本插件表：`group_meta`（group_id、source、external_id、fetched_at、locked_fields[]、aliases[]）、`trumps`（old、new、reason、state）、`vocab`（站点追加词表）。

## 5. 关键流程

见共用设计 §2（上传）、§8（元数据）。电影特有：

```
normalize(fields):
  ids：从 imdb / tmdb / douban 字段或链接中提取（https://www.imdb.com/title/tt0111161/ → tt0111161）
  若 release_name 非空 → pt-release-parser 补全 resolution/source/video_codec/audio_codecs/hdr/release_group/edition/year
  source = Remux 时 remux = true；source ∈ {BluRay, UHD BluRay} 且 is_full_disc → source_kind = disc
  校验必填：title（或外部 ID）、year、resolution、source、video_codec（原盘除外）
group_key：movie:imdb:<id> / movie:tmdb:<id> / movie:douban:<id> / movie:title:<norm(title)>:<year>
edition_key：sha256(edition ‖ is_3d) 前 16 位
```

## 6. 设计决策

| 编号 | 问题 | 结论与理由 |
|---|---|---|
| DD-TMOV-1 | 分组主键 | IMDb 优先（全球通用、稳定），TMDB 次之，豆瓣再次；同一 Group 可同时持有多个外部 ID（Group 字段），合并由审核员执行（torrent `merge_groups`） |
| DD-TMOV-2 | 原盘与 Remux 的表达 | `source`（片源）与 `release_type`（disc / remux / encode / web / hdtv）分开，避免把 Remux 当作片源 |
| DD-TMOV-3 | MediaInfo 深度校验 | 同步阶段只做快速文本检查；深度一致性交给 mediainfo 插件的 `mediainfo.parsed` 事件 + ai-upload-review，避免钩子超时 |

## 7. 对平台契约的新增

共用设计 §9 全部条目；术语 `type-movie.field.<field>`、`type-movie.edition.<edition>`；错误码见详细设计 §9。
