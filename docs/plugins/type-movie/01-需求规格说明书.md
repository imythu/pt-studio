## 1. 引言

### 1.1 目的

定义电影资源类型插件 `type-movie` 的需求。共用部分见 [../_shared/content-types-common.md](../_shared/content-types-common.md)（下称“共用设计”）。

### 1.2 范围

包含：电影 Group（作品）字段与分组键、种子字段（版本、分辨率、片源、编码、HDR、音轨、字幕、制作组）、标题规范、上传校验、去重与替代规则、搜索字段贡献、元数据联动（TMDB / IMDb / 豆瓣）、上传表单与详情展示。

不包含：剧集（type-tv）、动漫（type-anime）、元数据抓取本身（metadata-*）、MediaInfo 解析（mediainfo）。

### 1.3 术语

| 术语 | 说明 |
|---|---|
| 剪辑版（edition） | 导演剪辑版、加长版、IMAX 等，同一电影的不同版本 |
| Remux | 不重新编码、直接封装蓝光原盘视频音频的资源 |
| Encode | 重新编码的资源 |
| 原盘（Full Disc） | 未修改的蓝光 / DVD 原盘（BDMV / VIDEO_TS） |

### 1.4 参考资料

- 共用设计；docs/plugins/torrent/、docs/plugins/search-meilisearch/
- PTP（PassThePopcorn）公开规则：按 IMDb 分组、Edition、质量与 trump 规则（只借鉴思路）
- UNIT3D：categories / types（Full Disc、Remux、Encode、WEB-DL、WEBRip、HDTV）/ resolutions，TMDB 集成
- NexusPHP：分类、媒介（source）、编码（codec）、音频编码、分辨率、制作组（team）下拉字段；IMDb / 豆瓣链接

## 2. 总体描述

### 2.1 插件定位

WASM，ID `type-movie`，`type_id = "movie"`；导出 `content-type`、`search-contributor`；处理 `torrent.before_upload`、`torrent.before_update`；依赖 `ctx.torrents`（`update_group`）、`ctx.metadata`（optional）。

### 2.2 使用场景

上传者：选择电影类型 → 粘贴 IMDb / TMDB 链接 → 自动拉取片名、年份、海报 → 填写 / 自动识别规格 → 粘贴 MediaInfo → 提交。浏览者：按作品聚合查看所有版本，按分辨率、片源、HDR 筛选。审核员：处理重复与替代提示。

### 2.3 现有开源 PT 程序的做法调研

| 程序 | 做法 | 优点 | 缺点 | 我们的取舍 |
|---|---|---|---|---|
| PTP | 以 IMDb 为作品主键分组；种子按 Edition / 规格排列；严格的 trump 规则 | 浏览体验最好，冗余少 | 规则复杂，依赖大量人工 | **采纳**按外部 ID 分组、Edition、质量排序与 trump 候选；人工部分交给 moderation |
| UNIT3D | 种子平铺，带 TMDB ID；type 与 resolution 为独立表 | 字段规范、TMDB 信息丰富 | 无作品聚合，同片多版本分散 | **采纳**字段集合与 TMDB；**改进**：作品分组 |
| NexusPHP | 种子平铺，字段为站点自定义下拉；IMDb / 豆瓣信息抓取 | 中文站熟悉，豆瓣支持 | 无分组；字段各站不一致 | **采纳**豆瓣作为可选元数据源；字段默认值覆盖常见站点 |

### 2.4 约束

`normalize` 与钩子不得出站（共用设计 §2）；元数据异步获取。

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-TMOV-001 | 类型信息 | `info()` 返回 field_schema 与 group_schema（字段见 §5 详细设计） | P0 | schema 通过元校验 |
| FR-TMOV-002 | 外部 ID | 至少一个外部 ID：`imdb_id`（`tt\d{7,9}`）、`tmdb_id`、`douban_id`；可配置为必填哪一个 | P0 | 缺失时返回 `type-movie.external_id_required` |
| FR-TMOV-003 | 分组 | `group_key` 优先级：imdb → tmdb → douban → 标题+年份 | P0 | 同一 IMDb ID 的种子归入同一 Group |
| FR-TMOV-004 | 规格字段 | 分辨率、片源、Remux 标志、视频编码、HDR、音频编码、音轨语言、字幕语言、制作组、剪辑版、3D | P0 | 枚举值规范化 |
| FR-TMOV-005 | 发布名补全 | 从 `release_name` 解析补全缺失规格字段（共用设计 §3） | P0 | 示例发布名解析正确 |
| FR-TMOV-006 | MediaInfo 校验 | 若 `mediainfo` 字段非空，交叉校验分辨率、编码、HDR（使用 mediainfo 插件的解析结果，经事件异步；同步阶段只做文本快速检查：存在 `Video` 段与 `Width` 行） | P1 | 明显不一致时 `initial_status = pending` 并加标签 `spec_mismatch` |
| FR-TMOV-007 | 标题规范 | 按模板生成规范标题；策略 replace / reject | P0 | |
| FR-TMOV-008 | 原盘规则 | 原盘资源必须包含 BDMV 或 VIDEO_TS 目录结构（检查 `files_sample`） | P1 | 不符合 → `type-movie.disc_structure_invalid` |
| FR-TMOV-009 | 文件规则 | 非原盘资源：主视频文件扩展名白名单（mkv、mp4、m2ts、ts、avi）；禁止的附带文件（exe、lnk、scr 等） | P0 | |
| FR-TMOV-010 | 去重 | 同 Group 同 edition 同规格：拒绝或转人工（配置） | P1 | |
| FR-TMOV-011 | 替代候选 | 质量排序：原盘 > Remux > Encode（按分辨率）> WEB-DL > WEBRip > HDTV；更高者标记 `trump_candidate` | P2 | |
| FR-TMOV-012 | 搜索字段 | 贡献 `movie_imdb_id`、`movie_tmdb_id`、`movie_douban_id`、`movie_year`、`movie_genres`、`movie_countries`、`movie_edition` 等 | P0 | 可按 IMDb ID 精确搜索 |
| FR-TMOV-013 | 元数据联动 | 新 Group 创建后异步拉取元数据，更新 Group 的片名（多语言）、年份、类型、国家、导演、演员、海报、评分、简介 | P1 | 人工编辑过的字段不被覆盖 |
| FR-TMOV-014 | 同义词 | 元数据中的别名（中英文片名、又名）作为该 Group 的搜索同义标题 | P2 | 搜中文名可找到英文名种子 |
| FR-TMOV-015 | 详情展示 | `torrent.detail.info`：规格表；`group.detail.header`：海报、评分、简介；Group 页按 edition 分组列出种子 | P1 | |
| FR-TMOV-016 | 管理配置 | 必填外部 ID、标题模板与策略、扩展名白名单、去重策略、质量权重、自定义词表 | P1 | |

## 4. 非功能需求

| 编号 | 描述 | 指标 |
|---|---|---|
| NFR-TMOV-001 | `normalize` 性能 | p99 < 5 ms |
| NFR-TMOV-002 | 钩子性能 | p99 < 50 ms |
| NFR-TMOV-003 | 安全 | 字段长度上限；不输出 HTML |

## 5. 可配置项与站点术语

设置：`required_external_id`（`any` / `imdb` / `tmdb` / `douban`，默认 any）、`title_template`、`title_policy`（replace / reject）、`video_extensions`、`forbidden_extensions`、`dupe_policy`（reject / pending / allow）、`quality_weights`、`extra_synonyms`。

术语：`type-movie.name`（已登记）、`type-movie.field.<field>`（每字段显示名）、`type-movie.edition.<edition>`（剪辑版名）。

## 6. 外部接口需求概述

导出 `content-type`、`search-contributor`；钩子 `torrent.before_upload`、`torrent.before_update`；订阅 `group.created`、`metadata.fetched`；HTTP `/api/p/type-movie/v1/admin/*`（设置之外的词表、权重管理）；插槽 `torrent.detail.info`、`group.detail.header`、`torrent.upload.type_form`（默认使用 schema 表单，不替换）。
