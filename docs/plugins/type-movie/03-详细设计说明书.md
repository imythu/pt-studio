## 1. 模块详细设计

### 1.1 字段定义

**Group 字段**（`group_schema`，`x-pt-group-level = true`）：

| 字段 | 类型 | 约束 | 来源 |
|---|---|---|---|
| `title` | string | 1～200 | 用户 / 元数据（原语言片名） |
| `title_zh` | string? | ≤ 200 | 元数据（豆瓣 / TMDB zh-CN） |
| `aliases` | string[] | ≤ 20 项 | 元数据 |
| `year` | integer | 1870～当前年 + 2 | 用户 / 元数据 |
| `imdb_id` | string? | `^tt\d{7,9}$` | 用户 |
| `tmdb_id` | integer? | > 0 | 用户 |
| `douban_id` | string? | `^\d{6,10}$` | 用户 |
| `genres` | string[] | 枚举（TMDB 类型 ID 映射为本地键） | 元数据 |
| `countries` | string[] | ISO 3166-1 alpha-2 | 元数据 |
| `languages` | string[] | ISO 639-1 | 元数据 |
| `directors`、`cast` | string[] | ≤ 10 / ≤ 20 | 元数据 |
| `runtime_min` | integer? | | 元数据 |
| `rating_imdb`、`rating_douban`、`rating_tmdb` | number? | 0～10 | 元数据 |
| `poster` | string? | blob 相对路径 | 元数据（转存） |
| `overview` | string? | ≤ 5000 | 元数据 |

**种子字段**（`field_schema`）：

| 字段 | 类型 | 枚举 / 约束 | 筛选 |
|---|---|---|---|
| `release_name` | string | ≤ 255 | — |
| `edition` | string? | `standard`、`directors_cut`、`extended`、`theatrical`、`unrated`、`imax`、`criterion`、`remastered`、`special`、自定义（≤ 40） | facet |
| `release_type` | enum | `disc`、`remux`、`encode`、`web`、`hdtv`、`dvdrip`、`other` | facet |
| `source` | enum | `uhd_bluray`、`bluray`、`hddvd`、`dvd`、`web`、`hdtv`、`tv`、`other` | facet |
| `resolution` | enum | `4320p`、`2160p`、`1080p`、`1080i`、`720p`、`576p`、`480p`、`other` | facet |
| `video_codec` | enum? | `hevc`、`avc`、`av1`、`vc1`、`mpeg2`、`vp9`、`other`（disc 可为空） | facet |
| `hdr` | enum[] | `hdr10`、`hdr10plus`、`dv`、`hlg` | facet |
| `audio_codecs` | enum[] | `truehd_atmos`、`truehd`、`dtsx`、`dtshd_ma`、`dts`、`ddp_atmos`、`ddp`、`dd`、`aac`、`flac`、`lpcm`、`opus`、`other` | facet |
| `audio_languages`、`subtitle_languages` | string[] | ISO 639-1 / 639-2 | facet |
| `is_3d` | bool | | facet |
| `release_group` | string? | `^[A-Za-z0-9._@&-]{1,32}$`（另有 `torrent.release_group.<group>` 术语与 torrent 的 release_group_id） | facet |
| `mediainfo` | string? | ≤ 64 KiB；`x-pt-widget = mediainfo` | — |
| `original_title` | string? | 钩子写入 | — |

### 1.2 normalize

```
normalize(f):
  f = 只保留 field_schema ∪ group_schema 中的键
  imdb_id = extract(f.imdb_id ?? f.imdb_url, r"tt\d{7,9}")；tmdb_id = extract(r"themoviedb\.org/movie/(\d+)")；douban_id = extract(r"movie\.douban\.com/subject/(\d+)")
  if required_external_id == any && 三者皆空 && !(title && year): err type-movie.external_id_required
  if required_external_id == imdb && imdb_id 空: err type-movie.external_id_required{field: imdb_id}
  if f.release_name: p = release_parser::parse(f.release_name, vocab)；对每个规格字段：f.x = f.x ?? p.x
  规范化枚举：vocab 同义词映射（大小写不敏感，去掉 . _ -）；未知值 → 'other' 并记录 warning（不报错）
  release_type 推断：p.flags 含 REMUX → remux；source = web → web；files_sample（不可得，normalize 无文件列表）→ 交给钩子
  year 缺失且 release_name 可解析 → 补全；仍缺失 → err type-movie.year_invalid
  返回 f
```

### 1.3 grouping

```
group_key(f) = f.imdb_id ? "movie:imdb:"+id : f.tmdb_id ? "movie:tmdb:"+id : f.douban_id ? "movie:douban:"+id
               : "movie:title:" + norm(f.title) + ":" + f.year
norm(s) = lowercase(nfkc(s)) 去除标点与空白；简繁转换为简体（opencc 规则子集，内置）
canonical_group_title(f) = f.title_zh ? f.title_zh + " / " + f.title : f.title
canonical_title(f) = render(title_template, f)，默认模板见共用设计 §5
```

### 1.4 rules（钩子 `torrent.before_upload`）

```
if input.type_id != "movie": allow
f = input.fields；files = input.files_sample
1 文件结构：
  if f.release_type == disc: 必须存在路径匹配 `(^|/)BDMV/(index\.bdmv|STREAM/)` 或 `(^|/)VIDEO_TS/`；否则 deny(type-movie.disc_structure_invalid)
  else: 至少一个扩展名 ∈ video_extensions 的文件；存在 forbidden_extensions → deny(type-movie.forbidden_file)
2 MediaInfo 快速检查：f.mediainfo 非空且不含 "Video" 段 → 加标签 spec_mismatch、initial_status = pending
3 标题：c = canonical_title(f)；if similarity(input.title, c) < 0.5:
        title_policy == reject → deny(type-movie.title_nonstandard, details{expected: c})
        否则 modify title = c，fields.original_title = input.title
4 去重（需要 group_id，若 input.group_id 为空则按 group_key 查 v_group_fields）：
  same = SELECT torrent_id FROM torrent.v_torrent_fields
         WHERE group_id = $g AND fields->>'edition_key' = $ek AND fields->>'resolution' = $r
           AND fields->>'source' = $s AND fields->>'release_type' = $t AND torrent_id IN (未删除)
  same 非空：dupe_policy = reject → deny(type-movie.dupe, details{existing_torrent_id})；pending → initial_status = pending + 标签 dupe_suspect
5 trump：rank(f) > max(rank(same_edition_torrents)) → tags += trump_candidate；记录 pending_trumps（种子 ID 在 torrent.created 后补齐）
modify：fields.edition_key = sha256(edition ‖ is_3d)[0..16]
```

`rank(f)`：`quality_weights[release_type] × 100 + resolution_weight + (hdr 非空 ? 5 : 0)`，默认权重 disc 6、remux 5、encode 4、web 3、hdtv 2、dvdrip 1、other 0；分辨率 2160p 4、1080p 3、720p 2、其他 1。

`torrent.before_update`：fields 变化时重复 1～4（不含 trump）。

### 1.5 meta

```
on_group_created(evt{group_id, type_id}): type_id == movie → jobs.schedule_once("fetch_metadata", now, {group_id}, dedupe = group_id)
fetch_metadata(group_id)（tx manual）:
  g = v_group_fields[group_id]；ids = g.fields.{imdb_id, tmdb_id, douban_id}
  for (source, id) in 按配置优先级（tmdb → imdb → douban）:
     r = metadata.lookup(source, id, site.default_locale)；r 为 none → continue
     patch = 映射 r.data 到 Group 字段（只含 x-pt-from-metadata 字段，排除 group_meta.locked_fields）
     zh 片名：额外 lookup(…, "zh-CN")（TMDB）或豆瓣结果
     torrents.update_group(group_id, {fields: patch, expected_version: g.version})；冲突 → 重读重试 1 次
     UPSERT group_meta(group_id, source, external_id, fetched_at, aliases)
  失败（上游错误）→ reschedule（退避，最多 5 次）
on_metadata_fetched(evt{source, external_id, group_id?})：group_id 属于 movie → 调度 fetch_metadata
```

### 1.6 search

`index-schemas()`：

| 索引 | 字段 | 类型 | 属性 |
|---|---|---|---|
| torrents | `movie_imdb_id`、`movie_douban_id` | string | filterable、exact |
| torrents | `movie_tmdb_id` | int | filterable |
| torrents | `movie_year` | int | filterable、sortable |
| torrents | `movie_edition`、`movie_release_type` | string | facet |
| torrents | `movie_genres`、`movie_countries` | string[] | facet |
| groups | `movie_title_zh`、`movie_aliases` | string / string[] | searchable（rank 2） |
| groups | `movie_rating_imdb`、`movie_rating_douban` | float | sortable |

分辨率、片源、编码等通用规格由 search 的 `rel_*` 字段提供（search 03 §1.2），本插件不重复。`title_fields = ["release_name"]`。同义词：`movie_aliases` 由 search 作为文档内的同义标题处理（不进入全局同义词表）。

## 2. 接口详细设计

### 2.1 导出接口

实现 plugin-api 的 `content-type` 与 `search-contributor`，无自有服务 WIT。

### 2.2 事件

不发布事件。订阅 `group.created`、`metadata.fetched`。

### 2.3 钩子

见 §1.4；决策与可修改字段：`title`、`fields`（`edition_key`、`original_title`）、`initial_status`、`tags`。

### 2.4 HTTP API（前缀 `/api/p/type-movie/v1`，均需 `type-movie.manage`）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/PUT | `/admin/vocab` | 站点追加同义词表 `{ "source": {"bdrip": "bluray"}, "audio_codecs": {...} }` |
| GET/PUT | `/admin/quality` | 质量权重 |
| PUT | `/admin/groups/{id}/locked-fields` | `{ "fields": ["title_zh", "overview"] }` |
| POST | `/admin/groups/{id}/refresh` | 立即重新拉取元数据 |
| GET | `/admin/trumps?state=open` | 替代候选列表（moderation 也可读取） |

### 2.5 MCP

无独立工具（`get_torrent`、`search_torrents` 已包含本插件字段）。

## 3. 数据库设计（schema `type_movie`）

```sql
CREATE TABLE type_movie.group_meta (
    group_id       bigint PRIMARY KEY,
    primary_source text,
    external_ids   jsonb NOT NULL DEFAULT '{}',
    fetched_at     timestamptz,
    attempts       integer NOT NULL DEFAULT 0,
    locked_fields  text[] NOT NULL DEFAULT '{}',
    aliases        text[] NOT NULL DEFAULT '{}'
);

CREATE TABLE type_movie.trumps (
    id              bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    group_id        bigint NOT NULL,
    old_torrent_id  bigint NOT NULL,
    new_torrent_id  bigint,
    new_info_hash   text NOT NULL,           -- 钩子阶段只有 hash，torrent.created 后补 new_torrent_id
    reason          text NOT NULL,
    state           text NOT NULL DEFAULT 'open' CHECK (state IN ('open','accepted','rejected')),
    created_at      timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX trumps_open_idx ON type_movie.trumps (state) WHERE state = 'open';

CREATE TABLE type_movie.vocab (
    field  text NOT NULL,
    alias  text NOT NULL,
    value  text NOT NULL,
    PRIMARY KEY (field, alias)
);
```

`trumps.new_torrent_id` 补齐：订阅 `torrent.created`（订阅名 `on_torrent_created`，按 info_hash 匹配）。钩子写入 `trumps` 属于“钩子写入独立提交”，若上传最终失败，`new_torrent_id` 永远为空，`cleanup`（每日）删除 24 小时仍未补齐的记录。

## 4. 配置项

见 SRS §5；`title_template` 校验只允许已知字段名；`video_extensions` 默认 `[mkv, mp4, m2ts, ts, avi, iso]`；`forbidden_extensions` 默认 `[exe, bat, cmd, com, scr, lnk, vbs, js, msi, apk]`。

清单要点：`provides` 无；导出 `content-type`、`search-contributor`；`requires = ["ctx.torrents@^0.1"]`、`optional_requires = ["ctx.metadata@^0.1"]`；`[capabilities] sql, search_contributor = true, views = ["torrent.v_torrent_public", "torrent.v_group_public", "torrent.v_torrent_fields", "torrent.v_group_fields"]`；scopes `ctx.torrents = ["write:group"]`；`[[hooks]]` 两项；订阅 `on_group_created`、`on_metadata_fetched`、`on_torrent_created`；cron `cleanup`（`35 4 * * *`）；`[[jobs]] fetch_metadata`；术语 `type-movie.name` 与各字段 `type-movie.field.*`。

## 5. 前端设计

- 上传表单：schema 自动生成；IMDb / TMDB / 豆瓣字段旁“拉取信息”按钮（调用对应 metadata 插件接口预填 Group 字段）；发布名输入框失焦后本地解析预填规格（前端复用 `pt-release-parser` 的 WASM 构建或接口 `POST /api/p/type-movie/v1/parse-release`）。
- `group.detail.header`：海报、中英文片名、年份、评分、类型、导演、简介。
- `torrent.detail.info`：规格表格（按字段 label 术语）。
- Group 页种子列表按 edition 分组，组内按质量排序。

## 6. 安全设计

外部 ID 严格正则；文本字段长度上限；海报只接受 metadata 插件转存后的 blob 路径（不接受任意 URL）；钩子只读。

## 7. 性能设计

`normalize` 纯计算；钩子中去重查询走 `v_torrent_fields` 上 `(group_id)` 索引（需 torrent 提供）。

## 8. 可观测性

`pt_plugin_type_movie_hook_decisions_total{decision,reason}`、`pt_plugin_type_movie_metadata_fetch_total{source,result}`。

## 9. 错误码表

| 错误码 | HTTP 状态 | 说明 |
|---|---|---|
| `type-movie.external_id_required` | 422 | 缺少外部 ID |
| `type-movie.year_invalid` | 422 | 年份缺失或不合法 |
| `type-movie.field_invalid` | 422 | 字段不合法（`details.errors[]`） |
| `type-movie.disc_structure_invalid` | 422 | 原盘目录结构不符 |
| `type-movie.forbidden_file` | 422 | 含禁止的文件类型 |
| `type-movie.title_nonstandard` | 422 | 标题不规范（策略为 reject） |
| `type-movie.dupe` | 409 | 同规格重复（`details.existing_torrent_id`） |
