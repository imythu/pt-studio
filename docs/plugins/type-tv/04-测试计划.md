## 1. 测试范围与策略

与 type-movie 相同的层次；测试向量 `tests/vectors/tv/*.json`（≥ 60 组，含中文命名、多集、合集、连载）。type-movie 中与机制相同的用例（元数据联动、搜索贡献、cleanup、性能、安全）以参数化方式对本插件复跑。

## 2. 测试环境与数据

剧集 X 第 1 季（tmdb 1399，episode_count 10）；已有单集 S01E01 1080p WEB-DL 与连载季包（E01-E05）。
