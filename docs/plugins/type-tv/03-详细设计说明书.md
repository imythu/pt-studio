## 1. 模块详细设计

### 1.1 字段定义

**Group 字段**：`title`、`title_zh`、`aliases`、`season`（0～999）、`season_name`、`first_air_year`、`tmdb_tv_id`、`imdb_id`、`douban_id`、`tvdb_id`、`networks[]`、`genres[]`、`countries[]`、`episode_count`、`status`（`returning` / `ended` / `canceled`，元数据）、`poster`、`overview`。

**种子字段**：type-movie 的全部规格字段（`release_name`、`release_type`、`source`、`resolution`、`video_codec`、`hdr`、`audio_codecs`、`audio_languages`、`subtitle_languages`、`release_group`、`mediainfo`），不含 `edition`、`is_3d`；另加：

| 字段 | 类型 | 约束 |
|---|---|---|
| `scope` | enum | `season_pack`、`episode`、`episodes`、`complete` |
| `season` | integer | 0～999（complete 为 0） |
| `episode` | integer? | 1～9999 |
| `episode_end` | integer? | > episode |
| `ongoing` | bool | |
| `network` | string? | ≤ 40（如 Netflix、HBO、BBC） |

### 1.2 episodes：文件名集号解析

```
parse_episode(path) -> Option<(season?, episode, episode_end?)>:
  依次尝试：(?i)S(\d{1,3})E(\d{1,4})(?:-?E?(\d{1,4}))? | (?i)\bE(\d{1,4})\b | 第(\d{1,4})集 | \[(\d{1,4})(?:v\d)?\]
check(files_sample, f):
  vids = files where ext ∈ video_extensions（排除 sample 目录与 < 50 MiB 的文件）
  eps = vids.flat_map(parse_episode)
  match f.scope:
    episode  → |vids| ≥ 1 且 eps 全部 = f.episode
    episodes → eps ⊆ [episode, episode_end] 且 |distinct eps| = episode_end − episode + 1
    season_pack → (!ongoing && episode_count 已知) ⇒ |distinct eps 或 vids| ≥ ceil(episode_count × season_pack_min_ratio)
    complete → 不检查集数，只要求 vids ≥ 2
```

`files_sample` 只含前 200 个路径（钩子输入限制）；超过 200 个文件的季包只检查样本中的集号不超出范围。

### 1.3 grouping

```
group_key(f) = "tv:" + (tmdb ? "tmdb:"+tmdb_tv_id : imdb ? "imdb:"+imdb_id : douban ? "douban:"+douban_id
                       : "title:"+norm(title)+":"+first_air_year) + ":s" + pad2(season)
canonical_group_title(f) = (title_zh ? title_zh+" / " : "") + title + (season > 0 ? " 第"+season+"季 / Season "+season : " 全集 / Complete")
```

### 1.4 rules：去重与替代

去重键：`(group_id, scope, season, episode, episode_end, resolution, source, release_type)`。

替代排序在 type-movie 的 `rank` 之上增加“完整度”维度：`complete_rank = scope == season_pack && !ongoing ? 2 : scope == season_pack ? 1 : 0`；比较顺序：同规格下 `complete_rank` 高者替代低者（季包 trump 单集，完结季包 trump 连载季包）；`rank` 用于同完整度下的质量比较。连载季包更新（FR-TTV-010）：新连载季包且 episode 范围更大时，旧连载季包记为被替代。

### 1.5 search

| 索引 | 字段 | 类型 | 属性 |
|---|---|---|---|
| torrents | `tv_scope` | string | facet |
| torrents | `tv_season`、`tv_episode` | int | filterable、sortable |
| torrents | `tv_ongoing` | bool | filterable |
| torrents | `tv_tmdb_id`、`tv_imdb_id`、`tv_douban_id` | int / string | filterable、exact |
| torrents | `tv_network` | string | facet |
| groups | `tv_title_zh`、`tv_aliases`、`tv_season_name` | string | searchable |

## 2. 接口详细设计

导出接口与钩子同 type-movie；HTTP 管理路由前缀 `/api/p/type-tv/v1/admin/*`（vocab、quality、locked-fields、refresh、trumps）。

## 3. 数据库设计（schema `type_tv`）

`trumps`、`vocab` 与 type-movie 相同（schema 改为 `type_tv`）；`group_meta` 多三列：

```sql
CREATE TABLE type_tv.group_meta (
    group_id       bigint PRIMARY KEY,
    primary_source text,
    external_ids   jsonb NOT NULL DEFAULT '{}',
    fetched_at     timestamptz,
    attempts       integer NOT NULL DEFAULT 0,
    locked_fields  text[] NOT NULL DEFAULT '{}',
    aliases        text[] NOT NULL DEFAULT '{}',
    episode_count  integer,
    season_name    text,
    show_status    text CHECK (show_status IN ('returning', 'ended', 'canceled'))
);
```

## 4. 配置项

见 SRS §5；`season_pack_min_ratio` 0.5～1.0。

## 5. 前端设计

Group 页标题“剧名 第 N 季”；季切换标签（同一 `tmdb_tv_id` 的其他季 Group，通过 search `groups` 索引查询）；种子列表按 scope 分组（季包 / 单集），单集按集号排序；上传表单根据 scope 动态显示 episode / episode_end。
