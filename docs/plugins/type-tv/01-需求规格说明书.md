## 1. 引言

### 1.1 目的

定义剧集资源类型插件 `type-tv` 的需求。共用部分见 [../_shared/content-types-common.md](../_shared/content-types-common.md)；与 type-movie 相同的机制（规格字段、元数据联动、去重流程）引用 [../type-movie/03-详细设计说明书.md](../type-movie/03-详细设计说明书.md)。

### 1.2 范围

包含：剧集 Group（按“剧集 + 季”分组）、种子范围（整季包 / 单集 / 多集 / 全集合集）、季集字段、更新中（连载）标志、标题规范、上传校验（季集与文件列表一致）、去重与替代、搜索字段、元数据（TMDB TV / IMDb / 豆瓣）。

不包含：动漫（type-anime 单独处理，因其分组与命名习惯不同）。

### 1.3 术语

| 术语 | 说明 |
|---|---|
| 季包（season pack） | 包含一季全部集的种子 |
| 合集（complete series） | 跨多季的种子 |
| 连载中（ongoing） | 季包尚未完结，后续集会追加（以新种子替换或补充） |

### 1.4 参考资料

- 共用设计；type-movie 文档
- BTN（BroadcasTheNet）公开规则：按剧集 / 季分组、季包优先于单集（只借鉴思路）
- UNIT3D：TV 分类 + TMDB TV ID + season / episode 字段
- NexusPHP：剧集分类，中文站常见“合集”“第 X 季”“更新至 EXX”命名

## 2. 总体描述

WASM，ID `type-tv`，`type_id = "tv"`；导出与依赖同 type-movie。

### 2.1 现有开源 PT 程序的做法调研

| 程序 | 做法 | 优点 | 缺点 | 我们的取舍 |
|---|---|---|---|---|
| BTN | 剧集 → 季 → 集层级；季包替代单集 | 结构清晰 | 依赖专有元数据 | **采纳**剧集 + 季分组、季包 trump 单集；元数据用 TMDB TV |
| UNIT3D | 种子带 season_number / episode_number，平铺 | 字段明确 | 无分组 | **采纳**季集字段；**改进**：分组 |
| NexusPHP 中文站 | 标题中写“第一季 全 10 集”“更新至 E05” | 用户熟悉 | 非结构化 | 发布名与中文名解析（共用设计 §3） |

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-TTV-001 | 类型信息 | `info()` 返回 schema | P0 | |
| FR-TTV-002 | 外部 ID | `tmdb_tv_id`、`imdb_id`（剧集 ID）、`douban_id`、`tvdb_id`（仅记录）至少一个 | P0 | |
| FR-TTV-003 | 分组 | `tv:<scheme>:<id>:s<season>`；合集种子 `season = 0` 表示多季，分组到 `…:s00` | P0 | 同剧同季归同一 Group |
| FR-TTV-004 | 范围字段 | `scope ∈ {season_pack, episode, episodes, complete}`、`season`、`episode`、`episode_end`、`ongoing` | P0 | |
| FR-TTV-005 | 季集校验 | 文件列表中的视频文件数与季集范围一致（单集 1 个、多集 = 集数、季包 ≥ 配置的最少集数）；文件名中可解析到的集号不得超出声明范围 | P1 | 不一致 → `initial_status = pending` + 标签 `episode_mismatch` |
| FR-TTV-006 | 规格字段 | 同 type-movie（分辨率、片源、编码、HDR、音频、字幕、制作组），另加 `network`（播出平台，可选） | P0 | |
| FR-TTV-007 | 标题规范 | 模板含 `S01` / `S01E02` / `S01E02-E05` / `Complete` | P0 | |
| FR-TTV-008 | 去重 | 同 Group、同 scope 范围、同规格重复 | P1 | |
| FR-TTV-009 | 替代 | 已完结季包 trump 同规格单集与连载季包；高质量 trump 低质量 | P2 | |
| FR-TTV-010 | 连载更新 | 上传新的连载季包时，标记旧的同规格连载季包为 `trump_candidate` 的被替代对象 | P2 | |
| FR-TTV-011 | 搜索字段 | `tv_season`、`tv_episode`、`tv_scope`、`tv_ongoing`、`tv_tmdb_id`、`tv_network` 等 | P0 | 可筛选“只看季包” |
| FR-TTV-012 | 元数据 | Group（剧集+季）拉取剧名、季名、季简介、首播年份、集数、海报 | P1 | |
| FR-TTV-013 | 管理配置 | 季包最少集数比例、标题模板、去重策略 | P1 | |

## 4. 非功能需求

同 type-movie（normalize p99 < 5 ms；钩子 p99 < 50 ms；不输出 HTML）。

## 5. 可配置项与站点术语

`required_external_id`、`season_pack_min_ratio`（季包视频文件数 / 元数据集数 ≥ 0.9，元数据不可用时不检查）、`title_template`、`title_policy`、`dupe_policy`、`quality_weights`。术语 `type-tv.name`、`type-tv.field.<field>`、`type-tv.scope.<scope>`。

## 6. 外部接口需求概述

同 type-movie（导出 `content-type`、`search-contributor`；钩子 `torrent.before_upload` / `before_update`；订阅 `group.created`、`metadata.fetched`、`torrent.created`）。
