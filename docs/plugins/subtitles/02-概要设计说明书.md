| 类别 | 内容 |
|---|---|
| 原则 | 文件只存 blob（内容寻址）；数据库只存元数据；下载用预签名 URL；文件检查在内存中完成且有界 |
| 模块 | `upload`（接收、校验、存储）、`sniff`（格式识别）、`archive`（ZIP / 7z 检查，`zip` crate，7z 用 `sevenz-rust`，均为 MIT / Apache）、`encoding`、`catalog`（列表、计数）、`rewards`、`lifecycle` |
| 服务 | `list_for(torrent_id)`（已登记）；⊕ `count_many(torrent_ids)`（列表页标记用） |
| 依赖 | `ctx.torrents`（目标校验）、optional `ctx.bonus`（`award`）、`ctx.moderation`（`submit`） |
| 视图 | 读 `torrent.v_torrent_public`、`torrent.v_group_public`；提供 `subtitles.v_subtitle_public(id, torrent_id, group_id, deleted)` |
| 事件 | 发布 `subtitle.uploaded`、`subtitle.deleted`；订阅 `torrent.deleted`、`moderation.decided`（target 为 subtitle 时）、`user.deleted` |
| 钩子 | 拥有 `subtitle.before_upload` |
| HTTP | `POST /v1/subtitles`（multipart）、`GET /v1/subtitles?target=torrent:5501&lang=`、`GET /v1/subtitles/{id}`、`GET /v1/subtitles/{id}/download`（302 到预签名 URL，计数 +1）、`DELETE /v1/subtitles/{id}`、`GET /v1/admin/subtitles?…` |
| 插槽 | `torrent.detail.tabs`（字幕标签页）、`torrent.detail.actions`（上传字幕按钮）、`torrent.list.columns`（字幕图标） |
| cron | 无（下载计数每次 +1 直接写 PG；高频时用 Redis 累计每 5 分钟落库，见 03） |
| 权限点 | `subtitles.upload`、`subtitles.moderate`（已登记） |
| 设计决策 | DD-SUB-1：下载计数用 Redis HINCRBY + cron `flush_downloads`（每 5 分钟）落库，避免热门字幕行锁争用；DD-SUB-2：压缩包检查采用“只读目录 + 逐项流式解压计数”，超过限额立即中止；DD-SUB-3：Group 级字幕适用于该作品所有种子（如同一电影的不同版本时间轴可能不同，上传时可选 torrent 级更精确） |
| 平台契约新增 | 视图 `subtitles.v_subtitle_public`；服务 `count_many`；术语 `subtitles.language.<code>` |

需求追溯：FR-001、005、006 → upload、catalog；FR-002、003 → sniff、archive；FR-004 → encoding；FR-007 → rewards；FR-008、013 → lifecycle；FR-009 → moderation 联动；FR-010 → 钩子；FR-011 → upload（内容哈希）；FR-012 → MCP。
