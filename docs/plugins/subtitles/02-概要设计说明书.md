## 实现说明（2026-10-17，v0.1.0，开站计划 M3.7）

与本设计的差异（先做种子级，保持无新依赖）：

- 只支持种子级字幕（Group 级 DD-SUB-3 待做）；上传为原始请求体 + 查询参数（`filename`、`lang`、`title`、`anonymous`），不用 multipart：`POST /v1/torrents/{id}/subtitles`。
- 格式：SRT（含 `-->`）/ VTT（`WEBVTT`）/ ASS / SSA（`[Script Info]` 或 `[Events]`）按内容校验并记录编码（utf-8 / utf-16 / legacy，原样保存不转码）；SUP 校验 `PG` 文件头；ZIP 只读中央目录（条目扩展名白名单 srt / ass / ssa / vtt / sup / idx / sub / txt / nfo / ttf / otf、拒绝加密 / zip64 / 绝对路径与 `..`、条目数与声明的解压总量上限），不解压；7z / RAR 不接受（DD-SUB-2 的流式解压计数待做）。
- 语言固定为 `zh-hans`、`zh-hant`、`zh-hans-en`、`zh-hant-en`、`en`、`ja`、`ko`、`other`。
- 文件存 blob `files/<sha256>`（非公开、按引用计数删除）；下载由接口直接返回（`subtitles.download`，`Content-Disposition` 含 UTF-8 文件名、`nosniff`），计数直接写 PG（DD-SUB-1 的 Redis 累计待热点出现时再做）。
- 奖励：设置 `reward_bonus`（默认 0）经 `ctx.ledger` 幂等发放（`subtitles:reward:<id>`）。
- 删除：上传者，或 `subtitles.moderate`（必须填写原因、审计 `subtitles.delete`、通知上传者）；订阅 `torrent.deleted`。
- 服务 `ctx.subtitles`：`count_many {torrent_ids}`、`list_for {torrent_id}`。未实现：`subtitle.before_upload` 钩子、moderation 联动、MCP、列表页字幕图标列。
