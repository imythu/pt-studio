## 1. 模块详细设计

### 1.1 upload

```
upload(u, multipart{file, target, languages[], title?, note?, anonymous}, idem):
  rbac subtitles.upload；target ∈ {torrent:<id>, group:<id>} 且可见（视图；torrent 需 status = approved）
  bytes ≤ max_archive_mb（网关 max_body_kb 先行限制）
  kind = sniff(bytes, filename)；kind = unknown → subtitles.format_invalid
  if kind ∈ {zip, 7z}: archive::check(bytes) → entries（只允许字幕扩展名，可含 .txt / .nfo）
  else: size ≤ max_file_mb
  hash = sha256(bytes)；同目标已有相同 hash（未删除）→ subtitles.duplicate
  hooks.run("subtitle.before_upload", {uploader_id, torrent_id?, language: languages[0], filename, size})
  path = blob.put("subs/" + hex(hash) + "." + ext, bytes)（内容寻址，重复上传不重复存储）
  utf8_path：convert_to_utf8 且 kind 为文本 → 转码后另存
  INSERT subtitles(state = require_review ? 'pending' : 'visible')
  require_review → moderation.submit("subtitle:<id>", "subtitles.new")
  publish subtitle.uploaded；visible 且 reward > 0 → bonus.award(u, reward, "subtitles.upload", "sub:<id>")
```

### 1.2 sniff

| kind | 判定（前 64 KiB，去 BOM） |
|---|---|
| `srt` | 正则 `^\d+\r?\n\d{2}:\d{2}:\d{2}[,.]\d{3} --> \d{2}:\d{2}:\d{2}[,.]\d{3}` 多行匹配 |
| `ass` / `ssa` | 含 `[Script Info]` 且含 `[Events]` 或 `Dialogue:` |
| `vtt` | 以 `WEBVTT` 开头 |
| `sup` | 魔数 `PG`（0x50 0x47）且后续段结构合理（检查前 3 个段的长度字段不越界） |
| `idx` | 含 `# VobSub index file` |
| `sub`（VobSub） | MPEG-PS 起始码 `00 00 01 BA`；必须与 `idx` 同包 |
| `zip` | `PK\x03\x04` |
| `7z` | `7z\xBC\xAF\x27\x1C` |

文本类还必须能以检测到的编码解码，且不含 `\x00`（UTF-16 除外）。

### 1.3 archive::check

```
entries = 读取中央目录（zip）/ 头部（7z）
条目数 ≤ 200；每项：路径规范化（禁止绝对路径、..、驱动器号）、扩展名 ∈ allowed_ext ∪ {txt, nfo}
声明的解压大小之和 ≤ max_unpacked_mb；且逐项流式解压时实际字节计数 ≤ 声明值 + 1 KiB（防伪造头部）
压缩比 > 100 的条目 → 拒绝（压缩炸弹）
嵌套压缩包 → 拒绝
至少一个字幕文件
```

WASM 内存上限（清单 `memory_mb = 192`）可容纳 20 MiB 输入与流式缓冲。

### 1.4 encoding

`chardetng`（MIT / Apache）检测 + `encoding_rs` 解码；UTF-8 输出加 BOM（部分播放器需要）；原文件保留，下载默认原文件，可选 `?utf8=1`。

### 1.5 catalog

- `list_for(torrent_id)`：`SELECT … WHERE (torrent_id = $1 OR group_id = (SELECT group_id FROM torrent.v_torrent_public WHERE id = $1)) AND state = 'visible' ORDER BY languages, downloads DESC`。
- 下载：`HINCRBY dl <id> 1`（Redis，`p:subtitles:dl`）；`flush_downloads`（每 5 分钟）`HGETALL` + `DEL`（RENAME 后处理，避免丢失）→ `UPDATE subtitles SET downloads = downloads + $n`；`GET /download` 返回 302 到 `blob.presign_get(path, ttl = 300 s, filename = 原文件名)`。
- `count_many(torrent_ids ≤ 500)`：按种子与其 Group 计数。

### 1.6 lifecycle

- `torrent.deleted`：该种子级字幕 `state = 'hidden'`；Group 级不受影响。
- `moderation.decided`（target `subtitle:<id>`）：approve → visible（发奖励）；reject → rejected。
- `user.deleted{purge}`：`purge_on_user_delete` → 删除字幕记录（blob 引用计数为 0 时删除文件）；否则 `uploader_id = NULL`。
- 删除：`state = 'deleted'`，blob 保留 30 天（误删恢复）后由 `cleanup` 删除无引用的文件。

## 2. 接口详细设计

### 2.1 服务（WIT `pt:subtitles@0.1.0`）

```wit
package pt:subtitles@0.1.0;

interface subtitles {
  use pt:plugin/types@0.1.0.{plugin-error, user-id, timestamp-ms};

  record subtitle-info {
    id: u64, torrent-id: option<u64>, group-id: option<u64>, languages: list<string>, format: string,
    title: option<string>, uploader-id: option<user-id>, downloads: u64, created-at: timestamp-ms, download-url: string,
  }

  list-for: func(torrent-id: u64) -> result<list<subtitle-info>, plugin-error>;
  count-many: func(torrent-ids: list<u64>) -> result<list<u32>, plugin-error>;
}
```

`uploader-id` 对匿名上传且调用方无 `subtitles.moderate` 时为 none。

### 2.2 事件

| 事件 | 字段 |
|---|---|
| `subtitle.uploaded` | `subtitle_id, torrent_id?, group_id?, uploader_id, language(主语言), languages[], format, anonymous` |
| `subtitle.deleted` | `subtitle_id, torrent_id?, by, reason` |

### 2.3 钩子 `subtitle.before_upload`

输入：`version, actor, uploader_id, torrent_id?, group_id?, language, filename, size, format`；allow / deny；300 ms；deny。

### 2.4 HTTP

**POST `/v1/subtitles`**（multipart：`file`、`target`、`languages`（逗号分隔 BCP 47）、`title`、`note`、`anonymous`；`Idempotency-Key`）→ 201 `{ "id": 501, "state": "visible" }`；错误：422 `subtitles.format_invalid` / `subtitles.archive_invalid` / `subtitles.duplicate`；413 `subtitles.too_large`；404 目标不存在。

**GET `/v1/subtitles?target=torrent:5501&lang=zh-Hans`** → `{ "items": [ subtitle-info … ] }`。

## 3. 数据库设计（schema `subtitles`）

```sql
CREATE TABLE subtitles.subtitles (
    id             bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    torrent_id     bigint,
    group_id       bigint,
    uploader_id    bigint,
    anonymous      boolean NOT NULL DEFAULT false,
    languages      text[] NOT NULL CHECK (array_length(languages, 1) BETWEEN 1 AND 10),
    format         text NOT NULL,
    title          text,
    note           text,
    filename       text NOT NULL,
    size           bigint NOT NULL,
    content_hash   bytea NOT NULL,
    blob_path      text NOT NULL,
    utf8_path      text,
    entries        jsonb,                -- 压缩包内文件列表
    downloads      bigint NOT NULL DEFAULT 0,
    state          text NOT NULL CHECK (state IN ('pending','visible','rejected','hidden','deleted')),
    deleted_reason text,
    created_at     timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT subtitles_target CHECK ((torrent_id IS NULL) <> (group_id IS NULL))
);
CREATE INDEX subtitles_torrent_idx ON subtitles.subtitles (torrent_id) WHERE state = 'visible';
CREATE INDEX subtitles_group_idx ON subtitles.subtitles (group_id) WHERE state = 'visible';
CREATE UNIQUE INDEX subtitles_dupe_idx ON subtitles.subtitles (coalesce(torrent_id, 0), coalesce(group_id, 0), content_hash) WHERE state IN ('pending', 'visible');

CREATE VIEW subtitles.v_subtitle_public WITH (security_barrier = true) AS
SELECT id, torrent_id, group_id, state IN ('deleted', 'rejected', 'hidden') AS deleted FROM subtitles.subtitles;
```

## 4. 配置项

见 SRS §5。清单：`requires = ["ctx.torrents@^0.1"]`、`optional_requires = ["ctx.bonus@^0.1", "ctx.moderation@^0.1"]`；`[capabilities] sql, redis, blob = true`；`[wasm] memory_mb = 192`；`[[hook_points]] subtitle.before_upload`；订阅三项；cron `flush_downloads`（`*/5 * * * *`）、`cleanup`（`50 4 * * *`）；HTTP 上传路由 `max_body_kb = 21504`。

## 5. 前端设计

种子页“字幕”标签：语言旗标、格式、下载数、上传者；上传对话框（目标选择 torrent / 作品、多语言选择、拖拽上传、上传前本地扩展名检查）。

## 6. 安全设计

内容嗅探 + 压缩包检查（路径穿越、炸弹、嵌套）；下载经预签名 URL 且 `Content-Disposition: attachment`、`Content-Type: application/octet-stream`（防止浏览器内联渲染 ASS / VTT 文本中的内容）；匿名上传者对普通用户隐藏。

## 7. 性能设计

上传解析在内存中有界；下载不经插件转发字节；计数批量落库。

## 8. 可观测性

`pt_plugin_subtitles_uploads_total{format,result}`、`pt_plugin_subtitles_downloads_total`、`pt_plugin_subtitles_rejected_total{reason}`。
