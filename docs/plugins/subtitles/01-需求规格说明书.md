## 1. 引言

### 1.1 目的

定义字幕插件 `subtitles` 的需求：用户为种子或作品上传外挂字幕，其他用户下载。

### 1.2 范围

包含：上传（关联种子或 Group）、语言、格式（SRT、ASS / SSA、VTT、SUP、IDX + SUB、ZIP / 7z 包）、校验（大小、扩展名、内容嗅探、压缩包内文件检查、防压缩炸弹）、编码检测与转 UTF-8（文本字幕可选）、存储（blob）、下载计数、上传奖励（bonus）、删除与审核、上传钩子、列表与筛选。

不包含：在线字幕编辑、时间轴调整、机器翻译。

### 1.3 参考资料

- NexusPHP：字幕区（subs 表：torrent 关联、语言、上传者、下载次数，下载需登录）
- UNIT3D：subtitles（torrent 关联、语言、格式校验、anonymous 上传）
- Gazelle：无字幕区

## 2. 总体描述

WASM，ID `subtitles`，缩写 `SUB`；提供 `ctx.subtitles`；拥有钩子 `subtitle.before_upload`；评论目标 `subtitle`（comments）。

| 程序 | 做法 | 优点 | 缺点 | 我们的取舍 |
|---|---|---|---|---|
| NexusPHP | 字幕区独立页面，按种子关联 | 简单 | 文件只检查扩展名；无压缩包检查 | **采纳**关联与计数；**改进**：内容嗅探、压缩包检查 |
| UNIT3D | 按种子关联，语言下拉，匿名 | 字段规范 | — | **采纳**匿名上传与语言字段 |

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-SUB-001 | 上传 | 关联 `torrent:<id>` 或 `group:<id>`；语言（可多选）；标题；说明；匿名 | P0 | |
| FR-SUB-002 | 格式校验 | 扩展名白名单 + 内容嗅探（SRT 时间轴行、ASS `[Script Info]`、VTT `WEBVTT`、SUP `PG` 魔数、IDX 文本头、ZIP / 7z 魔数） | P0 | 伪装文件被拒 |
| FR-SUB-003 | 大小限制 | 单文件 ≤ 10 MiB；压缩包 ≤ 20 MiB；解压总大小 ≤ 100 MiB、文件数 ≤ 200、单文件扩展名白名单 | P0 | 压缩炸弹被拒 |
| FR-SUB-004 | 编码 | 文本字幕检测编码（UTF-8 / UTF-16 / GBK / Big5 / Shift-JIS），可选转为 UTF-8（保留原文件） | P2 | |
| FR-SUB-005 | 下载 | 已登录用户下载；计数 | P0 | |
| FR-SUB-006 | 列表 | 按种子 / Group 列出；按语言筛选；`list_for(torrent_id)` 同时返回 Group 级字幕 | P0 | |
| FR-SUB-007 | 奖励 | 上传成功并通过审核（或无需审核）后，经 `ctx.bonus.award` 发放奖励（可配置，默认 0） | P2 | |
| FR-SUB-008 | 删除 | 上传者删除；版主删除（原因）；种子删除时种子级字幕隐藏 | P0 | |
| FR-SUB-009 | 审核 | 可配置为上传后需审核（交给 moderation，target = `subtitle:<id>`） | P2 | |
| FR-SUB-010 | 钩子 | `subtitle.before_upload` | P0 | |
| FR-SUB-011 | 去重 | 同一目标下内容哈希相同的字幕拒绝 | P1 | |
| FR-SUB-012 | MCP | `list_subtitles`（已登记） | P2 | |
| FR-SUB-013 | 用户删除 | purge：字幕保留（作为社区资源），上传者显示为“已删除用户”；可配置为删除 | P2 | |

## 4. 非功能需求

上传处理 p99 < 1 s（20 MiB 压缩包解析）；下载走 blob 预签名 URL，不经插件转发字节。

## 5. 可配置项与站点术语

`max_file_mb`（10）、`max_archive_mb`（20）、`max_unpacked_mb`（100）、`allowed_ext`、`require_review`（false）、`reward_amount`（0）、`convert_to_utf8`（false）、`purge_on_user_delete`（false）。术语：`subtitles.name`（已登记）、`subtitles.language.<code>`（可选覆盖语言名）。

## 6. 外部接口需求概述

服务 `ctx.subtitles.list_for(torrent_id)`；视图 `subtitles.v_subtitle_public`；事件 `subtitle.uploaded`、`subtitle.deleted`；钩子 `subtitle.before_upload`；HTTP `/api/p/subtitles/v1/*`；插槽 `torrent.detail.tabs`、`torrent.detail.actions`、`torrent.list.columns`（有字幕标记）。
