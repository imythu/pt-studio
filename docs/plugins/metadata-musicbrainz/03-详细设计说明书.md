缓存、图片转存、熔断、表结构同 metadata-tmdb 03（schema `metadata_musicbrainz`）。

## 1. mapper

| MusicBrainz 字段 | 统一模型 |
|---|---|
| release-group `title` | `titles.original`（MusicBrainz 无多语言标题；别名不在发行组上） |
| `artist-credit[]` | `people[]` role artist（`name`、`artist.id` → mbid），`joinphrase` 拼接为 `extra.artist_credit_string` |
| `primary-type`（Album / Single / EP / Broadcast / Other） | `extra.release_type`：album / single / ep / other |
| `secondary-types[]`（Compilation / Soundtrack / Live / Remix / DJ-mix / Mixtape/Street / Interview / Audiobook / Demo） | `extra.release_type` 优先取次要类型映射（compilation、soundtrack、live、remix、mixtape、interview……） |
| `first-release-date` | `release_date`、`year` |
| `genres[].name`（按 count 排序取前 10） | `genres` |
| release `label-info[].label.name`、`catalog-number` | `extra.label`、`extra.catalog` |
| release `media[].format`（CD / Digital Media / 12" Vinyl / SACD / Cassette……） | `extra.media`：cd / web / vinyl / sacd / cassette / dvd / bluray / other |
| release `media[].track-count` 之和 | `extra.track_count` |
| release `barcode`、`date`、`country` | `extra.barcode`、`extra.release_date`、`countries` |
| artist `name`、`aliases[].name`、`type`、`country` | `titles.original`、`titles.aliases`、`extra.artist_type`、`countries` |
| — | `ids.mbid`；`attribution = {source: "musicbrainz", url: "https://musicbrainz.org/<entity>/<mbid>", license_note: "Data from MusicBrainz (CC0)"}` |

## 2. client

- 请求头：`User-Agent: PT-Studio/<ver> ( <contact> )`、`Accept: application/json`；
- 查询转义：Lucene 特殊字符 `+ - && || ! ( ) { } [ ] ^ " ~ * ? : \ /` 前加 `\`；
- 结果 `limit` ≤ 20。

## 3. 接口

**GET `/v1/lookup?id=release-group:<mbid>`**、**GET `/v1/search?q=&type=music`**：格式同共用设计 §8。
