## 1. 引言

定义 MusicBrainz 元数据源插件（含 Cover Art Archive 封面）。共用部分见 [../_shared/metadata-providers-common.md](../_shared/metadata-providers-common.md)。

条款要点：核心数据 CC0；每个应用每秒不超过 1 次请求；必须设置有意义的 User-Agent（含联系方式）；封面图片版权归权利人。

参考：Gazelle/OPS 的 MusicBrainz 关联（发行组、艺人）。

## 2. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-MDMB-001 | 发行组查询 | `lookup("release-group:<mbid>")`：标题、艺人署名、主要类型 / 次要类型、首发日期、标签 | P0 | |
| FR-MDMB-002 | 发行查询 | `lookup("release:<mbid>")`：介质、厂牌、目录号、条码、曲目数（供 type-music 版本字段预填） | P1 | |
| FR-MDMB-003 | 艺人查询 | `lookup("artist:<mbid>")`：名称、别名、类型、国家 | P1 | |
| FR-MDMB-004 | 搜索 | `search(query, "music")`：发行组搜索（Lucene 查询转义） | P0 | |
| FR-MDMB-005 | 封面 | Cover Art Archive front 500px 转存 | P1 | |
| FR-MDMB-006 | 限速 | 全站 ≤ 1 次/秒（含所有副本） | P0 | |
| FR-MDMB-007 | User-Agent | `PT-Studio/<ver> (<site.name>; <contact>)`，contact 必须配置 | P0 | 未配置联系方式时插件不可用 |
| FR-MDMB-008 | 缓存 | 30 天；发行组 90 天（变化少） | P0 | |

## 3. 可配置项

静态：`contact`（邮箱或 URL，必填）、`api_host`（`musicbrainz.org`，可改为自建镜像）、`caa_host`（`coverartarchive.org`）。运行时：`rate_per_sec`（1，自建镜像可调高）。

## 4. 外部接口需求概述

导出 `metadata-provider`；HTTP `/api/p/metadata-musicbrainz/v1/lookup`、`/search`；`metadata.fetched`；cron `refresh_stale`。
