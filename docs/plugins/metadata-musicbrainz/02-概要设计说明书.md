## 1. 设计目标

严格遵守 1 次/秒；支持自建 MusicBrainz 镜像（站点数据量大时推荐）以放宽限速。

## 2. 结构与接口

| 类别 | 内容 |
|---|---|
| 模块 | `client`（UA、限速、重试）、`mapper`、`cache`、`images`（CAA） |
| 导出 | `metadata-provider`；`info()`：`{source: "musicbrainz", type-ids: ["music"], id-pattern: "^(release-group|release|artist):[0-9a-f-]{36}$|musicbrainz\\.org/(release-group|release|artist)/([0-9a-f-]{36})"}` |
| 能力 | `sql`、`redis`、`blob`；`http_outbound = ["musicbrainz.org", "coverartarchive.org", "archive.org"]`（CAA 重定向到 archive.org） |

## 3. 关键流程

```
lookup("release-group:<id>"): GET /ws/2/release-group/<id>?inc=artist-credits+genres+tags&fmt=json
lookup("release:<id>"):       GET /ws/2/release/<id>?inc=labels+media+artist-credits+release-groups&fmt=json
lookup("artist:<id>"):        GET /ws/2/artist/<id>?inc=aliases&fmt=json
封面：GET https://coverartarchive.org/release-group/<id>/front-500（跟随重定向，主机须在允许列表）
search: GET /ws/2/release-group?query=<escaped>&limit=<n>&fmt=json
```

限速：Redis 固定窗口 `rl:<sec>` 上限 1；等待 ≤ 3 秒，否则返回缓存 / service_unavailable。503（MusicBrainz 超限返回 503）→ 退避 2 s。

## 4. 设计决策

| 编号 | 问题 | 结论 |
|---|---|---|
| DD-MDMB-1 | 一次请求获取更多数据 | 使用 `inc=` 参数，避免多次请求 |
| DD-MDMB-2 | 自建镜像 | 支持 `api_host` 覆盖；镜像时 `rate_per_sec` 可调高 |

## 5. 对平台契约的新增

`config:` 形式的出站主机（同 metadata-douban 02 §7），用于自建镜像。

## 6. 需求追溯

FR-001～004 → client、mapper；FR-005 → images；FR-006、007 → client；FR-008 → cache。
