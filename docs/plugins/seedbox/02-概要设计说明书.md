## 1. 设计目标与原则

1. **不进热路径**：判定按需查询 + Redis 缓存，tracker 完全不感知盒子（NexusPHP announce 时判断 IP 的改进）。
2. **策略外置**：本插件只回答“是不是盒子”并提供站点策略标志，奖惩由使用方插件决定。
3. **IP 最小化**：IP 段只在本插件 schema 中保存（申报者同意），判定缓存只存布尔值，事件不含 IP。

## 2. 总体结构

```
用户申报 ─► registrations(pending) ─► 管理员审核 ─► approved
anticheat / hnr / bonus ─ctx.seedbox.is_seedbox(_many)─► 缓存 sb:<uid>:<tid>
                                                     └miss─► tracker.peers(tid)（含 IP，需 peer.ip）
                                                            过滤 user_id == uid → IP ∈ 已批准 CIDR？
cron detect（可选）─► 抽样 peers ─► ASN 数据中心 ∧ 无申报 ─► seedbox.detected
```

| 模块 | 职责 |
|---|---|
| `registry` | 申报、审核、修改、删除、重叠检测 |
| `matcher` | CIDR 匹配（前缀树） |
| `resolver` | `is_seedbox` 判定与缓存 |
| `detector` | 自动识别（可选） |
| `policy` | 策略标志 |

## 4. 数据设计概要

`boxes`（user_id、state、provider、note、expires_at）、`box_ranges`（box_id、cidr）、`detections`（user_id、asn、prefix_hmac、torrent_id、first_seen、last_seen、state）。Redis：`sb:<uid>:<tid>`（判定缓存，1 h）、`ranges:<uid>`（用户已批准 CIDR 列表缓存）。

## 5. 关键流程

```
is_seedbox(uid, tid):
  if !has_grant(peer.ip): return false
  c = GET sb:<uid>:<tid>；命中 → 返回
  ranges = 用户已批准 CIDR（缓存 ranges:<uid>，审核变化时删除）；为空 → SET sb… "0"；return false
  peers = tracker.peers(tid)（含 user_id 与 ip）→ 过滤 user_id == uid
  r = any(peer.ip ∈ ranges)；SET sb:<uid>:<tid> r EX 3600；return r
```

`tracker.peers(tid)` 对大 swarm 返回量大：请 tracker-bridge 提供 `peers_of_user_on_torrent(uid, tid)`（§7）；合入前按 `peers(tid)` 过滤。

## 6. 设计决策

| 编号 | 问题 | 结论与理由 |
|---|---|---|
| DD-SBOX-1 | 判定时机 | 按需 + 缓存：大多数用户没有盒子（ranges 为空直接 false），开销集中在少数申报用户 |
| DD-SBOX-2 | 按 IP 的倍率 | 不做：accounting 无 IP 维度；远期提案：tracker-bridge 把已批准 CIDR 下发给 pt-tracker，流量事件携带 `peer_class = seedbox` 标志（§7） |
| DD-SBOX-3 | 自动识别是否处罚 | 不处罚，只发布事件供管理员复核（误判风险高：VPN、家宽托管） |
| DD-SBOX-4 | ASN 数据 | DB-IP ASN Lite（CC BY 4.0），站点自行下载，不随仓库分发（与 identity 的 GeoIP 处理一致） |

## 7. 对平台契约的新增

服务 `is_seedbox_many`、`policy`（anticheat A-12 已提出）；事件 `seedbox.reviewed`、`seedbox.removed`；请 tracker-bridge 提供 `peers_of_user_on_torrent(user_id, torrent_id)`（需 `peer.ip`）；远期：流量事件 `peer_class` 字段（pt-tracker、tracker-bridge、accounting 三方设计）。
