## 1. 模块详细设计

### 1.1 registry

```
create_box(uid, req{ranges[1..=5], provider, note}):
  require rbac(uid, seedbox.register_own)
  每个 CIDR：解析（ipnet）；IPv4 前缀 ≥ 24、IPv6 ≥ 48；不得为私有 / 保留地址段（RFC 1918、ULA、回环、组播）
  用户已有 ranges 总数 + 新增 ≤ max_ranges_per_user
  INSERT boxes(state = require_review ? 'pending' : 'approved')；INSERT box_ranges
  overlap = 与其他用户 approved / pending 的 CIDR 重叠（PG `inet && inet` 运算，GiST 索引）→ 记录到 boxes.overlap_note（仅管理员可见）
  publish seedbox.registered{user_id, record_id, state}（不含 IP）
review(box_id, approve, reason, expires_at?)：state → approved / rejected；DEL ranges:<uid>；DEL sb:<uid>:*（用 SCAN 前缀删除，键数有限）；publish seedbox.reviewed
update：修改 ranges → state 回到 pending（require_review 时）；同上清缓存
delete：DELETE boxes/box_ranges（IP 立即删除）；清缓存；publish seedbox.removed
expire（cron）：approved 且 expires_at ≤ now → state = expired；清缓存
```

### 1.2 matcher

用户 CIDR 数 ≤ 5，直接线性匹配（`ipnet::IpNet::contains`）；`ranges:<uid>` 缓存为 JSON 字符串数组，TTL 1 h。

### 1.3 resolver

```
is_seedbox_many(pairs ≤ 500):
  if !grant(peer.ip): return 全 false
  keys = sb:<uid>:<tid>；MGET
  miss 按 uid 分组：ranges 为空的 uid → 全部 false（写缓存）
  其余：对每个 (uid, tid)：tracker.peers_of_user_on_torrent(uid, tid)（未合入时 peers(tid) 过滤）
  写缓存（SET EX 3600，pipeline）
```

`tracker.peers` 返回的 IP 只在本次调用内存中使用，不写日志、不落库。

### 1.4 detector（可选）

```
detect（cron，tx manual）:
  if !detect.enabled || !grant(peer.ip) || asn_db 不可用: return
  抽样：从 accounting 不可得 → 改为从 tracker.peers 对“最近 1 小时 swarm_stats 变化的种子”抽样（kv 维护最近 traffic.swarm_stats_updated 中的种子 ID 环形缓冲，最多 5000 个；本插件订阅该事件 ⊕）
  for peer in 样本（≤ sample_per_hour）:
     asn = asn_db.lookup(peer.ip)；asn ∉ 数据中心列表（内置 + 设置追加）→ continue
     if 用户有 approved box 且 IP 命中 → continue
     prefix_hmac = HMAC(hmac_key, /24 或 /48 前缀)
     UPSERT detections(user_id, asn, prefix_hmac, torrent_id, last_seen = now)
     首次 → publish seedbox.detected{user_id, torrent_id, rule: "datacenter_asn", asn}
```

ASN 查询使用 `maxminddb` crate（Apache-2.0 / MIT）在 WASM 中读取 blob 中的 MMDB（`blob.get("asn.mmdb")`，管理员上传）。

### 1.5 policy

`policy()` 返回设置中的 `{hnr_exempt, bonus_factor, anticheat_speed_relax}`；使用方各自决定是否采纳（hnr 的豁免规则字段 `is_seedbox`、bonus 公式中的 `seedbox_factor`、anticheat 的 `ctx.is_seedbox` 乘数）。

## 2. 接口详细设计

### 2.1 服务接口（WIT `pt:seedbox@0.1.0`）

```wit
package pt:seedbox@0.1.0;

interface seedbox {
  use pt:plugin/types@0.1.0.{plugin-error, user-id, timestamp-ms};

  record seedbox-record { id: u64, state: string, provider: string, range-count: u8, expires-at: option<timestamp-ms> }
  record seedbox-policy { hnr-exempt: bool, bonus-factor: f64, anticheat-speed-relax: bool, detection-available: bool }

  is-seedbox: func(user: user-id, torrent-id: u64) -> result<bool, plugin-error>;
  is-seedbox-many: func(pairs: list<tuple<user-id, u64>>) -> result<list<bool>, plugin-error>;
  registered: func(user: user-id) -> result<list<seedbox-record>, plugin-error>;
  policy: func() -> result<seedbox-policy, plugin-error>;
}
```

### 2.2 事件载荷（版本 1）

| 事件 | 字段 |
|---|---|
| `seedbox.registered` | `user_id, record_id, state` |
| `seedbox.reviewed` | `user_id, record_id, approved, reviewer_id` |
| `seedbox.removed` | `user_id, record_id, cause(user/expired/admin/user_deleted)` |
| `seedbox.detected` | `user_id, torrent_id, rule, asn` |

### 2.3 HTTP API

**POST `/v1/me/boxes`** `{ "ranges": ["203.0.113.0/24"], "provider": "某云", "note": "…" }` → 201 `{ "id": 5, "state": "pending" }`；错误 422 `seedbox.range_invalid` / `seedbox.too_many_ranges`。

**GET `/v1/me/boxes`** → 本人可见完整 CIDR。

**POST `/v1/admin/boxes/{id}/review`** `{ "approve": true, "reason": "", "expires_at": null }` → 204；响应前端展示 `overlap_note`。

**GET `/v1/admin/detections?state=open`** → `{ "items": [ { "user_id": 1, "asn": 13335, "torrent_id": 5501, "first_seen": "…", "last_seen": "…" } ] }`（不含 IP）。

## 3. 数据库设计（schema `seedbox`）

```sql
CREATE TABLE seedbox.boxes (
    id            bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    user_id       bigint NOT NULL,
    state         text NOT NULL CHECK (state IN ('pending','approved','rejected','expired')),
    provider      text NOT NULL,
    note          text NOT NULL DEFAULT '',
    overlap_note  text,
    review_reason text,
    reviewer_id   bigint,
    expires_at    timestamptz,
    created_at    timestamptz NOT NULL DEFAULT now(),
    updated_at    timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX boxes_user_idx ON seedbox.boxes (user_id);
CREATE INDEX boxes_state_idx ON seedbox.boxes (state) WHERE state = 'pending';

CREATE TABLE seedbox.box_ranges (
    box_id  bigint NOT NULL REFERENCES seedbox.boxes (id) ON DELETE CASCADE,
    cidr    cidr NOT NULL,
    PRIMARY KEY (box_id, cidr)
);
CREATE INDEX box_ranges_gist_idx ON seedbox.box_ranges USING gist (cidr inet_ops);

CREATE TABLE seedbox.detections (
    user_id      bigint NOT NULL,
    asn          integer NOT NULL,
    prefix_hmac  bytea NOT NULL,
    torrent_id   bigint NOT NULL,
    state        text NOT NULL DEFAULT 'open' CHECK (state IN ('open','dismissed','registered')),
    first_seen   timestamptz NOT NULL,
    last_seen    timestamptz NOT NULL,
    PRIMARY KEY (user_id, asn, prefix_hmac)
);
```

`detections` 保留 90 天（`expire` 清理 `last_seen` 过旧的记录）。

### 3.1 Redis（前缀 `p:seedbox:`）

| 键 | 类型 | TTL | 说明 |
|---|---|---|---|
| `sb:<uid>:<tid>` | STRING("0"/"1") | 3600 s | 判定缓存 |
| `ranges:<uid>` | STRING(JSON) | 3600 s | 已批准 CIDR |
| `recent_torrents` | LIST | 2 h | 自动识别抽样候选（LPUSH + LTRIM 5000） |

## 4. 配置项

见 SRS §5。清单：`requires = ["ctx.tracker@^0.1", "ctx.users@^0.1"]`；`[capabilities] sql, redis, blob = true, sensitive_optional = ["peer.ip"]`；订阅 `user.deleted`、`traffic.swarm_stats_updated`（仅 detect.enabled 时有意义，始终声明）；cron `detect`、`expire`。

## 5. 前端设计

设置页“我的盒子”：申报表单（CIDR 校验提示）、状态、删除；后台：待审核列表（重叠提示）、疑似盒子列表（复核：忽略 / 联系用户）。

## 6. 安全设计

IP 段访问控制（本人与 `seedbox.manage`）；事件、日志、缓存不含 IP；删除即清除；私有地址段拒绝；`peer.ip` 授权由站点决定，未授权降级。

## 7. 性能设计

绝大多数用户无申报：`ranges:<uid>` 空值缓存直接返回 false；有申报用户的判定每 (uid, tid) 每小时最多一次 peers 查询。

## 8. 可观测性

`pt_plugin_seedbox_checks_total{cache=hit/miss,result}`、`pt_plugin_seedbox_boxes{state}`、`pt_plugin_seedbox_detections_total`。

## 9. 错误码表

| 错误码 | HTTP 状态 | 说明 |
|---|---|---|
| `seedbox.range_invalid` | 422 | CIDR 无效、前缀过短或为私有地址段 |
| `seedbox.too_many_ranges` | 422 | 超过上限 |
| `seedbox.box_not_found` | 404 | |
| `seedbox.not_pending` | 409 | 审核非 pending 记录 |
