## 1. 测试范围与策略

| 层次 | 内容 | 工具 |
|---|---|---|
| 单元 | 码派生 / 规范化 / Crockford 容错、持有者规范化、FIFO 消耗、余额计算、连坐规则匹配（深度、窗口、分组去重）、周期边界判定、游标编解码 | `cargo test`（wasm32-wasip2 目标 + 原生目标双跑）、`proptest` |
| 插件集成 | 真实 PG + 内核 testkit 宿主加载 invite.wasm：钩子、事件订阅（inbox）、cron / 延迟任务、服务调用、HTTP 路由；stub identity（触发 `user.before_register` 并发布 `user.registered`）、stub levels / anticheat / shop / notify | `pt-testkit`、testcontainers |
| 契约 | `pt:invites` WIT 兼容；事件载荷、钩子输入（`invite.before_issue`）、MCP 输入输出按 JSON Schema 校验；OpenAPI → TS SDK 编译、`oasdiff` | `wasm-tools`、`jsonschema`、`openapi-typescript` |
| 跨插件 | 与真实 identity：注册钩子顺序（registration-policy 5 → invite 10）、`user.registered` 载荷；与 shop：购买 / 退款幂等 | testkit |
| 前端 | 我的邀请页、注册页邀请码字段、树页、后台设置规则编辑器 | Vitest、Playwright |
| 性能 | 钩子、校验接口、树查询、周期发放、日汇总 | k6、testkit 基准 |
| 安全 | 枚举、越权、明文码泄漏扫描、并发抢码 | 自动化 + 敏感扫描器 |

**通用断言**：每个产生事件 / 日志 / 审计 / MCP 输出 / 错误响应的用例，用“敏感扫描器”对已知明文邀请码、邮箱、邮箱 HMAC 做子串搜索，必须 0 命中（码尾除外）。

## 2. 测试环境与数据

- PostgreSQL 17；内核 testkit（WASM 运行时、冻结 / 快进 `time`、确定性 `random`）；`secret` 使用固定测试值。
- 用户：A（class 3，注册 60 天，active）、N（注册 5 天）、P（pending）、L（leech_disabled）、X（banned）、M（moderator，具 `invite.tree.read`、`invite.penalties.moderate`、`invite.penalty.exempt`）、AD（admin，`invite.manage`、`invite.quota.bypass`）。
- stub：`t-identity`（可按脚本发起注册：调用钩子管线、可配置在 invite 之后拒绝、发布 `user.registered`；可发布 `user.status_changed`、`user.deleted`）、`t-levels`（`invite.before_issue` 处理者可 allow/deny，发布 `level.promoted`）、`t-anticheat`（发布 `anticheat.case_resolved`）、`t-shop`（作用域 `write:quota`）、`t-regp`（作用域 `write:issue`）、`t-noscope`、`t-notify`（记录 `send` 调用）。
- 性能数据：50 万用户；邀请树：一棵 10 万节点子树（深度 6）、其余随机；150 万邀请、600 万批次。
