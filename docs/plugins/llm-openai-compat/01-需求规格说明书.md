## 1. 引言

定义 `ctx.llm` 的“OpenAI 兼容接口”提供方插件 `llm-openai-compat`，用于接入自建或第三方的兼容服务（vLLM、Ollama、llama.cpp server、LM Studio、各类网关），尤其是站点不希望把数据发往外部时的本地模型。接口见 [../_shared/llm-interface-common.md](../_shared/llm-interface-common.md)。

范围：Chat Completions（`POST {base}/v1/chat/completions`）、Embeddings（`POST {base}/v1/embeddings`）、工具调用（function tools）、结构化输出（`response_format`，按服务能力降级）、多端点（对话与嵌入可指向不同服务）、能力探测与配置声明、重试、计量与配额、敏感兜底、不可信内容标记。

不包含：流式；图像输入；各服务的专有扩展参数（可经 profile 的 `extra_body` 透传，默认不允许）。

## 2. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-LLMO-001 | complete | 映射到 Chat Completions | P0 | |
| FR-LLMO-002 | profile | 每个 profile：`base_url`、`api_key`（可空）、`model`、`max_tokens`、能力声明（`tools`、`json_schema`、`json_object`） | P0 | |
| FR-LLMO-003 | 工具 | `tools[{type: "function", function: {name, description, parameters}}]`；`tool_choice` auto / none；不支持工具的服务返回 `unsupported` | P0 | |
| FR-LLMO-004 | 结构化输出 | 能力为 json_schema → `response_format: {type: "json_schema", json_schema: {name, schema, strict: true}}`；仅 json_object → `{type: "json_object"}` + 在系统提示中给出 schema；都不支持 → 提示词约束；三种情况都做本地 schema 校验，失败重试 1 次 | P0 | |
| FR-LLMO-005 | 嵌入 | `embed` → `/v1/embeddings`（`input[]`，≤ 128 条 / 批）；`purpose` 为 query 时可按 profile 配置添加前缀（部分嵌入模型需要“query: ”前缀） | P0 | |
| FR-LLMO-006 | effort 映射 | `effort` 映射为 `temperature`（low 0.2 / medium 0.5 / high 0.7，可配置）与可选的 `reasoning_effort`（服务支持时） | P2 | |
| FR-LLMO-007 | 重试 | 429 / 5xx / 网络错误重试 2 次（`retry-after`） | P0 | |
| FR-LLMO-008 | 计量与配额 | 同 llm-claude（`usage.prompt_tokens`、`completion_tokens`；服务未返回时按字符数估算并标记 estimated） | P0 | |
| FR-LLMO-009 | 敏感兜底与不可信内容 | 同共用设计 | P0 | |
| FR-LLMO-010 | 内网地址 | 允许 `base_url` 指向内网（本地模型的常见部署），但必须在 `site.toml` 中显式列出（出站白名单），且不受 webhook 的 SSRF 规则影响 | P0 | |

## 3. 非功能需求

插件开销 < 5 ms；key 不进日志；不记录提示词与输出。

## 4. 可配置项

```toml
[plugin.llm-openai-compat.profiles]
default = { base_url = "http://10.0.0.20:8000", model = "qwen-xx-instruct", max_tokens = 4096, caps = ["tools", "json_schema"] }
embed   = { base_url = "http://10.0.0.21:11434", model = "bge-m3", kind = "embedding", dims = 1024 }
```

## 5. 外部接口需求概述

服务 `ctx.llm`；事件 `llm.usage_recorded`；HTTP `/api/p/llm-openai-compat/v1/admin/usage`、`/admin/test`、`/admin/probe`（能力探测）。
