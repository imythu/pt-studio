## 1. 引言

### 1.1 目的

定义论坛插件 `forum` 的需求。

### 1.2 范围

包含：分区与版块（层级两级）、版块权限（可见 / 发帖 / 回帖 按等级与角色）、主题与回复、置顶（版块内 / 全局公告）、精华、锁定、移动 / 合并 / 拆分主题、投票、订阅、未读追踪、引用与编辑历史、版主（全站版主与版块版主）、关联主题（种子 / 求种讨论帖，`link_topic`）、搜索贡献（forum 索引）、反垃圾（复用 comments 规则）。

不包含：实时聊天（chatbox，不在本期）、站内信。

### 1.3 参考资料

- Gazelle：forums / forums_topics / forums_posts、`forums_last_read_topics`（按主题记录最后阅读帖子）、投票（forums_polls）、版块 MinClassRead / MinClassWrite / MinClassCreate
- UNIT3D：forums 层级（category / forum）、permissions 表（按 group 的 read / reply / start topic）、topic subscription、“未读”与 thanks
- NexusPHP：论坛、版主、置顶 / 精华 / 锁定、帖子编辑记录

## 2. 总体描述

WASM，ID `forum`，缩写 `FORUM`；提供 `ctx.forum`；拥有钩子 `forum.before_post`；搜索贡献者（`forum` 索引）；渲染使用 `pt-markup`。

### 2.1 现有开源 PT 程序的做法调研

| 程序 | 做法 | 优点 | 缺点 | 我们的取舍 |
|---|---|---|---|---|
| Gazelle | 版块按 class 设最低读 / 写 / 发帖等级；按主题记录最后阅读帖子 ID 计算未读 | 未读准确 | 用户 × 主题表很大；“全部标为已读”需写大量行 | **采纳**按主题记录 + 版块级“全部已读时间戳”（避免批量写） |
| UNIT3D | 按用户组设置读 / 回 / 发权限 | 灵活 | 权限表随组数 × 版块数膨胀 | **改进**：版块权限用“最低等级 + 角色列表”，等级由 levels 提供 |
| NexusPHP | 版主可置顶、精华、锁定 | 功能齐全 | — | 采纳 |

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-FORUM-001 | 分区与版块 | 管理员创建分区、版块（名称术语键 `forum.board.<id>`、描述、排序、图标） | P0 | |
| FR-FORUM-002 | 版块权限 | 每个版块：可见、回帖、发主题分别配置最低等级与 / 或角色白名单；隐藏版块对无权用户不可见（404） | P0 | |
| FR-FORUM-003 | 发主题 | 标题（≤ 150）+ 正文；可附投票 | P0 | |
| FR-FORUM-004 | 回复 | 回复、引用、@提醒 | P0 | |
| FR-FORUM-005 | 编辑与删除 | 作者在窗口内编辑（默认 24 小时）；版主随时；编辑历史；软删 | P0 | |
| FR-FORUM-006 | 置顶 / 公告 | 版块置顶、全局公告（显示在所有版块顶部） | P1 | |
| FR-FORUM-007 | 精华 / 锁定 | 精华标记；锁定后不能回复 | P1 | |
| FR-FORUM-008 | 移动 / 合并 / 拆分 | 版主移动主题到其他版块、合并两个主题、从某楼起拆分为新主题 | P1 | |
| FR-FORUM-009 | 投票 | 单选 / 多选、截止时间、是否公开投票者、投票后可见结果 | P2 | |
| FR-FORUM-010 | 订阅 | 订阅主题；新回复通知（合并：同一主题 1 小时内最多通知一次） | P1 | |
| FR-FORUM-011 | 未读 | 版块列表与主题列表显示未读；“全部标为已读”（版块级与全站级） | P0 | |
| FR-FORUM-012 | 版主 | 全站版主（`forum.moderate`）与版块版主（版块配置的用户列表） | P0 | |
| FR-FORUM-013 | 关联主题 | `create_topic` / `link_topic(target, topic_id)`：种子、求种的讨论帖 | P2 | 种子页显示“讨论帖”链接 |
| FR-FORUM-014 | 搜索 | 主题标题与帖子正文进入 forum 索引（权限过滤：用户只能搜到可见版块） | P1 | |
| FR-FORUM-015 | 反垃圾 | 频率、重复、新用户限制（与 comments 相同的规则与默认值） | P0 | |
| FR-FORUM-016 | 钩子 | 发帖前 `forum.before_post` | P0 | |
| FR-FORUM-017 | 感谢 | 对帖子感谢 | P2 | |
| FR-FORUM-018 | 用户删除 | purge 时清空正文、保留占位 | P1 | |
| FR-FORUM-019 | 统计 | 版块主题数、帖子数、最后发帖 | P0 | |

## 4. 非功能需求

| 编号 | 描述 | 指标 |
|---|---|---|
| NFR-FORUM-001 | 版块列表（含未读） | p99 < 80 ms |
| NFR-FORUM-002 | 主题页（25 帖） | p99 < 60 ms |
| NFR-FORUM-003 | 未读存储 | 只为“打开过的主题”存行；全部已读 O(1) |
| NFR-FORUM-004 | 容量 | 帖子 ≤ 5000 万行 |

## 5. 可配置项与站点术语

`edit_window_hours`（24）、`posts_per_page`（25）、`topics_per_page`（50）、`subscription_digest_minutes`（60）、反垃圾参数（同 comments）。术语：`forum.name`、`forum.board.<board_id>`（已登记）、`forum.category.<id>`、`forum.sticky`、`forum.featured`、`forum.announcement`。

## 6. 外部接口需求概述

服务 `ctx.forum`（`create_topic`、`get_topic`、`link_topic`）；事件 `forum.topic_created`、`forum.post_created`、`forum.post_updated`、`forum.post_deleted`（已登记）及新增 `forum.topic_moved`、`forum.topic_locked`；钩子 `forum.before_post`；HTTP `/api/p/forum/v1/*`；插槽 `nav.main`、`home.announcements`、`forum.post.footer`（由其他插件注入）；搜索 `forum` 索引。
