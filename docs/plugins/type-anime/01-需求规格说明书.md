## 1. 引言

### 1.1 目的

定义动漫资源类型插件 `type-anime` 的需求。共用部分见 [../_shared/content-types-common.md](../_shared/content-types-common.md)；季集处理复用 [type-tv](../type-tv/03-详细设计说明书.md) 的 `episodes` 模块。

### 1.2 范围

包含：作品 Group（按 Bangumi / AniDB 条目分组，一部番剧的每一季在 Bangumi 中是独立条目）、作品类型（TV、剧场版、OVA、OAD、WEB、特别篇）、字幕组（发布组）、字幕形式（内封 / 内嵌 / 外挂）与语言（简 / 繁 / 简繁 / 日 / 英）、范围（单集 / 合集 / 全集）、动漫圈命名习惯解析（`[字幕组] 标题 - 01 [1080p][简繁内封]`）、去重与替代、搜索字段、元数据（Bangumi、AniDB 仅记录 ID）。

不包含：动漫音乐（归 type-music）、漫画与轻小说（归 type-generic 的 ebook）。

### 1.3 术语

| 术语 | 说明 |
|---|---|
| 字幕组 | 制作字幕并发布资源的组织，相当于影视的 release group |
| 内封 / 内嵌 / 外挂 | 字幕作为可切换轨道封装 / 烧录进画面 / 单独文件 |
| BDRip | 动漫圈对蓝光压制的称呼；`BDMV` 为原盘 |

### 1.4 参考资料

- 共用设计、type-tv
- Bangumi（bgm.tv）条目结构；AniDB
- 动漫 BT 站（如 Nyaa、动漫花园）的命名习惯与字幕组标签（只借鉴命名规则）
- NexusPHP 系动漫站：字幕组、字幕语言下拉字段

## 2. 总体描述

WASM，ID `type-anime`，`type_id = "anime"`；导出、钩子、订阅同 type-movie。

### 2.1 现有开源 PT 程序的做法调研

| 程序 | 做法 | 优点 | 缺点 | 我们的取舍 |
|---|---|---|---|---|
| NexusPHP 动漫站 | 平铺；字幕组、字幕语言为下拉 | 字段贴合圈内习惯 | 无作品聚合 | **采纳**字段；**改进**：按 Bangumi 条目分组 |
| Nyaa / 动漫花园（公开 BT 站） | 标题即元数据，字幕组标签 | 命名高度规范 | 非结构化 | **采纳**命名解析规则 |

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-TANI-001 | 类型信息 | `info()` | P0 | |
| FR-TANI-002 | 外部 ID | `bangumi_id`（必填，可配置）、`anidb_id`、`tmdb_id`（剧场版可用） | P0 | |
| FR-TANI-003 | 分组 | `anime:bgm:<bangumi_id>`；无 Bangumi ID 时 `anime:title:<规范名>:<year>` | P0 | |
| FR-TANI-004 | 作品类型 | `tv`、`movie`、`ova`、`oad`、`web`、`special` | P0 | |
| FR-TANI-005 | 范围 | `episode`、`episodes`、`batch`（一季全集）、`complete`（多季）、`movie`（剧场版单体） | P0 | |
| FR-TANI-006 | 字幕字段 | `fansub_groups[]`（可多个联合字幕组）、`subtitle_mode`（softsub / hardsub / external / none）、`subtitle_languages[]`（zh-Hans、zh-Hant、ja、en……） | P0 | |
| FR-TANI-007 | 规格字段 | 分辨率、片源（BD / Web / TV / DVD）、视频编码、位深（8bit / 10bit）、音频编码、`release_type`（raw / sub / bdmv / bdrip） | P0 | |
| FR-TANI-008 | 命名解析 | 解析 `[字幕组] 标题 - 01v2 [1080p][简繁内封]`、`[字幕组][标题][01-12][BDRip][1080p]` 等 | P0 | 测试向量通过 |
| FR-TANI-009 | 季集校验 | 复用 type-tv 规则（集号与文件一致） | P1 | |
| FR-TANI-010 | 标题规范 | `[{fansub_groups}] {title} - {episode_tag} [{resolution}][{subtitle_tag}]`（可改为影视风格） | P0 | |
| FR-TANI-011 | 去重 | 同 Group、同字幕组、同范围、同分辨率、同字幕形式 | P1 | |
| FR-TANI-012 | 替代 | 同字幕组的 v2 替代 v1；合集替代单集（同字幕组同规格）；BDRip 不替代 Web（可并存） | P2 | |
| FR-TANI-013 | 搜索 | `anime_bangumi_id`、`anime_kind`、`anime_fansub_groups`、`anime_subtitle_mode`、`anime_subtitle_languages`、`anime_scope`、`anime_episode`、`anime_bit_depth` | P0 | |
| FR-TANI-014 | 元数据 | Bangumi：中文名、日文名、放送开始日期、话数、类型、封面、简介、评分 | P1 | |
| FR-TANI-015 | 字幕组词表 | 管理员维护字幕组名称与别名（如“喵萌奶茶屋 / Nekomoe kissaten”），用于规范化与筛选 | P1 | |

## 4. 非功能需求

同 type-movie。

## 5. 可配置项与站点术语

`required_external_id`（bangumi / any）、`title_style`（anime / scene）、`title_policy`、`dupe_policy`、`fansub_vocab`、`quality_weights`。术语 `type-anime.name`、`type-anime.field.<field>`、`type-anime.kind.<kind>`、`type-anime.subtitle_mode.<mode>`。

## 6. 外部接口需求概述

同 type-movie；元数据源为 metadata-bangumi。
