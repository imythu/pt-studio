## 1. 设计目标与原则

与 type-movie / type-tv 相同；差异：以 Bangumi 条目为作品（每季一个条目，天然对应 type-tv 的“剧集 + 季”），字幕组与字幕形式是一等字段，命名解析针对动漫圈格式。

## 2. 总体结构

模块：`schema`、`normalize`（含 `anime_name` 解析器）、`grouping`、`rules`（复用 type-tv 的 `episodes`）、`fansub`（字幕组词表）、`meta`（Bangumi）、`search`。`episodes` 模块以源码级共享（同一 crate `pt-episodes`，建议与 type-tv 共用）。

## 3. 对外接口清单

同 type-movie（ID / 前缀替换为 `type-anime` / `anime_`）；另加管理路由 `/api/p/type-anime/v1/admin/fansubs`（字幕组词表）；权限点 `type-anime.manage`。

## 4. 数据设计概要

`group_meta`、`trumps`、`vocab`（同 type-movie）；`fansubs`（id、canonical_name、aliases[]、active）。

## 5. 关键流程

```
anime_name::parse(s):
  tokens = 提取方括号 / 圆括号 / 【】中的片段；剩余部分为标题与集号
  fansub_groups = 第一个括号片段按 & / ＆ / × 拆分，经 fansubs 词表规范化
  episode：" - 01"、"[01]"、"第01话"、"01v2"（version = 2）、"[01-12]"（episodes / batch）
  resolution：1080p / 1080P / 1920x1080；subtitle：简繁内封 / 简体内嵌 / CHS / CHT / GB / BIG5 / 外挂
  source：BDRip / BD / Web-DL / WebRip / TVRip；bit_depth：10bit / Hi10P / Ma10p
group_key: anime:bgm:<id>
rules：type-tv episodes 校验；去重键 (group_id, fansub_groups 排序后, scope, episode 范围, resolution, subtitle_mode)
trump：同字幕组、同集、version 更高 → 替代；batch ⊇ 单集（同字幕组同规格）→ 替代
```

## 6. 设计决策

| 编号 | 问题 | 结论与理由 |
|---|---|---|
| DD-TANI-1 | 分组主键 | Bangumi：中文社区覆盖最全，且每季独立条目；AniDB 只记录 |
| DD-TANI-2 | 标题风格 | 默认保留动漫圈风格（方括号），可切换为影视风格 |
| DD-TANI-3 | v2 | 视为同一集的修正版，替代 v1（同字幕组） |

## 7. 对平台契约的新增

共用设计 §9；共享 crate `pt-episodes`（与 type-tv）；术语 `type-anime.kind.<kind>`、`type-anime.subtitle_mode.<mode>`。
