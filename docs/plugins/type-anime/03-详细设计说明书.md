## 1. 模块详细设计

### 1.1 字段定义

**Group 字段**：`title`（原名，通常为日文）、`title_zh`、`title_en`、`aliases[]`、`bangumi_id`（整数）、`anidb_id`、`tmdb_id`、`kind`（tv / movie / ova / oad / web / special）、`air_date`（YYYY-MM-DD）、`year`、`episode_count`、`studios[]`、`genres[]`、`cover`、`summary`、`rating_bangumi`。

**种子字段**：

| 字段 | 类型 | 枚举 / 约束 |
|---|---|---|
| `release_name` | string | ≤ 255 |
| `fansub_groups` | string[] | 1～5 项；`raw` 资源可为空 |
| `release_type` | enum | `raw`、`sub`、`bdmv`、`bdrip`、`dvd` |
| `scope` | enum | `episode`、`episodes`、`batch`、`complete`、`movie` |
| `episode`、`episode_end` | integer? | |
| `version` | integer | 1～9（v2 = 2） |
| `source` | enum | `bd`、`web`、`tv`、`dvd`、`other` |
| `resolution`、`video_codec`、`audio_codecs` | 同 type-movie | |
| `bit_depth` | enum | `8bit`、`10bit` |
| `subtitle_mode` | enum | `softsub`、`hardsub`、`external`、`none` |
| `subtitle_languages` | string[] | `zh-Hans`、`zh-Hant`、`ja`、`en`、`other` |

### 1.2 anime_name 解析器

| 模式（按优先级） | 示例 | 结果 |
|---|---|---|
| `^\[(?<g>[^\]]+)\]\s*(?<t>.+?)\s+-\s+(?<e>\d{1,4})(?:v(?<v>\d))?(?:\s|\[|$)` | `[喵萌奶茶屋] 某番 - 05v2 [1080p][简繁内封]` | g、t、episode 5、version 2 |
| `^\[(?<g>[^\]]+)\]\[(?<t>[^\]]+)\]\[(?<e1>\d{1,4})-(?<e2>\d{1,4})\]` | `[字幕组][某番][01-12][BDRip]` | batch / episodes |
| `第(?<e>\d{1,4})[话話集]` | `某番 第05话` | episode |
| 剧场版关键词 `剧场版|劇場版|Movie|The Movie` | | kind = movie，scope = movie |

字幕标签映射：`简繁内封 → softsub [zh-Hans, zh-Hant]`、`简体内嵌 / CHS / GB → hardsub [zh-Hans]`（`内嵌` 为 hardsub，`内封` 为 softsub）、`繁體 / CHT / BIG5 → zh-Hant`、`外挂 → external`、`日字 / 中日双语 → + ja`。

`batch` 判定：范围覆盖 1～episode_count（元数据可用时），否则 `episodes`。

### 1.3 fansub 词表

`fansubs(id, canonical_name, aliases[])`；规范化时按别名（大小写、全半角不敏感）映射到 canonical；未收录的字幕组原样保留并计入“未知字幕组”统计，管理员可一键加入词表。

### 1.4 rules

去重与替代见 HLD §5；`raw` 资源去重键中的 `fansub_groups` 为空集合。

### 1.5 search

| 索引 | 字段 | 类型 | 属性 |
|---|---|---|---|
| torrents | `anime_fansub_groups` | string[] | facet、searchable |
| torrents | `anime_subtitle_mode`、`anime_release_type`、`anime_scope`、`anime_bit_depth` | string | facet |
| torrents | `anime_subtitle_languages` | string[] | facet |
| torrents | `anime_episode` | int | filterable、sortable |
| torrents | `anime_bangumi_id` | int | filterable |
| groups | `anime_title_zh`、`anime_title_en`、`anime_aliases` | string | searchable |
| groups | `anime_kind` | string | facet |
| groups | `anime_air_date` | timestamp | sortable |

`title_fields = ["release_name"]`（search 的 `rel_*` 解析对动漫格式只能提取分辨率与编码；字幕组等由本插件字段提供）。

## 2. 接口详细设计

同 type-movie；管理路由增加 `GET/PUT /v1/admin/fansubs`、`GET /v1/admin/fansubs/unknown`（未知字幕组统计）。

## 3. 数据库设计（schema `type_anime`）

`group_meta`（同 type-tv，含 `episode_count`）、`trumps`、`vocab`；另：

```sql
CREATE TABLE type_anime.fansubs (
    id              bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    canonical_name  text NOT NULL UNIQUE,
    aliases         text[] NOT NULL DEFAULT '{}',
    active          boolean NOT NULL DEFAULT true
);
CREATE INDEX fansubs_aliases_idx ON type_anime.fansubs USING gin (aliases);

CREATE TABLE type_anime.unknown_fansubs (
    name        text PRIMARY KEY,
    seen_count  integer NOT NULL DEFAULT 1,
    last_seen   timestamptz NOT NULL DEFAULT now()
);
```

## 4. 配置项

见 SRS §5。

## 5. 前端设计

Group 页显示中日文名、放送日期、话数、封面；种子按字幕组分组，组内按集号排序，合集置顶；筛选：字幕组、字幕形式、语言。
