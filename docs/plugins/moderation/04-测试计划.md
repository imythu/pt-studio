# moderation 测试计划

| 项 | 内容 |
|---|---|
| 文档编号 | TP-MOD |

集成测试使用真实 torrent 插件（状态机）与 search 插件（可见性）。

| 编号 | 关联需求 | 步骤 | 预期结果 |
|---|---|---|---|
| TC-MOD-001 | FR-001 | uploader 角色上传 | initial_status = approved |
| TC-MOD-002 | FR-001 | 新发布者上传（candidate 启用 / 未启用） | candidate / pending |
| TC-MOD-003 | FR-001 | type-movie 已设 pending（spec_mismatch），uploader 角色 | 仍为 pending（不能放宽） |
| TC-MOD-004 | FR-002 | torrent.created(pending) 重复投递 | 队列一条 |
| TC-MOD-005 | FR-003 | 两个审核员先后认领 | 第二人 409 `moderation.claimed_by_other`；10 分钟后可认领 |
| TC-MOD-006 | FR-004 | 通过 / 拒绝 / 要求修改 | 状态迁移；决定日志；通知；needs_edit 后上传者编辑 → 回到队列 |
| TC-MOD-007 | FR-004 | 决定时种子已被删除 | 409 `moderation.stale` |
| TC-MOD-008 | FR-005 | 理由模板 | 通知中包含模板文本（术语） |
| TC-MOD-009 | FR-006 | 批量 50 个 | 结果逐项返回 |
| TC-MOD-010 | FR-007 | 候选投票达阈值 | candidate_resolve 迁移（actor = plugin:moderation，before_status_change 允许） |
| TC-MOD-011 | FR-007 | 上传者给自己投票 / 新号投票 | 403 |
| TC-MOD-012 | FR-007 | 候选超时，candidate_timeout 两次 | 只迁移一次 |
| TC-MOD-013 | FR-008 | ai.upload_reviewed 到达 | 队列显示 AI 结论，优先级提升；状态不自动改变 |
| TC-MOD-014 | FR-009 | 普通用户搜索 | 只看到 approved；审核员看到全部；候选区页面只看到 candidate |
| TC-MOD-015 | FR-010 | block / mask / review 三类词，在评论、帖子、改名、字幕文件名中 | 拒绝（不回显词）/ 替换 / 允许并入复核 |
| TC-MOD-016 | FR-010 | 全角、零宽字符变体 | 规范化后命中 |
| TC-MOD-017 | FR-011 | 决定日志快照 | 含标题、上传者、原状态 |
| TC-MOD-018 | FR-013 | 积压超过阈值，backlog_check 两次 | 告警一次（同一积压周期内不重复） |
| TC-MOD-019 | FR-014 | subtitles 调用 submit；审核员 decide | 发布 moderation.decided；不调用 torrent |
| TC-MOD-020 | FR-015 | MCP 列表与决定（确认不可关闭） | 正确 |
| TC-MOD-021 | FR-016 | 撤回审核 | approved → pending，重新入队 |
| TC-MOD-022 | DD-4 | 发布者经 torrent 编辑接口把 pending 改 approved | 403 `moderation.approval_required` |
| TC-MOD-023 | NFR-001 | 敏感词 10 万条，20000 字文本 | p99 < 5 ms |
| TC-MOD-024 | NFR-001 | search.before_query | p99 < 5 ms |
| TC-MOD-025 | 重复执行 | claim_expire、订阅 user.deleted / torrent.deleted 重复执行 | 无副作用 |

覆盖：FR-001～016 对应 001～021；NFR 对应 023、024。通过准则：可见性（014）与防绕过（022）必须通过。
