## 1. 测试范围与策略

| 层次 | 内容 | 工具 |
|---|---|---|
| 单元 | 谓词求值（含 ratio = ∞）、评估算法（升级、警告、降级、保护期、one_step、覆盖层）、预设生成 | `cargo test` |
| 集成 | 插件 + testkit + PG；真实 identity（set_class、set_class_roles、限制）与 accounting 视图（测试数据直接写基表） | `pt-testkit` |
| 契约 | WIT、事件 schema、OpenAPI、MCP | `xtask contract-check` |
| 性能 | 30 万用户全量评估；5 万脏用户增量 | testkit |

## 2. 测试环境与数据

- NexusPHP 预设；用户 u1（新注册）、u2（age 30d、上传 60 GiB、ratio 1.2）、u3（power_user，ratio 0.9）、u4（veteran，180 天未登录）、mod1（moderator，180 天未登录）。
