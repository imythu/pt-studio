## 1. 引言

### 1.1 目的

定义出站 Webhook 插件 `webhook` 的需求：管理员配置端点订阅站点事件，事件发生时以签名的 HTTP POST 推送给外部系统（站务机器人、统计系统、Discord / Slack 频道等）。

### 1.2 范围

包含：端点管理（URL、密钥、订阅的事件类型、过滤条件、启用状态）、事件白名单（只有允许外发的事件类型可订阅）、载荷脱敏（匿名发布者、举报者、敏感字段）、HMAC-SHA256 签名、重试与指数退避、失败告警与自动停用、投递日志、测试发送、Discord / Slack 格式转换（可选）。

不包含：入站 Webhook；用户级 Webhook（只对管理员开放）。

### 1.3 参考资料

- 平台事件目录（docs/platform/catalog/events.md）与载荷约定（“面向外部的投递必须先判断 anonymous”）
- GitHub / Stripe Webhook 签名惯例（`timestamp.body` 的 HMAC，防重放）
- UNIT3D：无通用 Webhook（有 IRC / Telegram 公告）

## 2. 总体描述

WASM，ID `webhook`，缩写 `WHOOK`；无服务；订阅白名单中的事件；出站 HTTP 到管理员配置的主机。

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-WHOOK-001 | 端点管理 | 名称、URL（https；可配置允许的主机列表）、密钥（生成，仅显示一次）、事件类型列表、过滤（谓词，如 `type_id = movie`）、格式（json / discord / slack）、启用 | P0 | |
| FR-WHOOK-002 | 事件白名单 | 可订阅事件：`torrent.created`、`torrent.status_changed`、`request.created`、`request.filled`、`forum.topic_created`、`promotion.started`、`promotion.ended`、`moderation.decided`、`report.created`（仅计数信息）、`user.registered`（仅计数，无用户名，可配置）、`search.index_rebuilt`、`webhook.*` 除外 | P0 | 非白名单事件不可选 |
| FR-WHOOK-003 | 脱敏 | 匿名种子不含 uploader_id；`report.*` 去掉 reporter_id；载荷只保留白名单字段；可选附加种子标题与链接（经 torrent 视图读取） | P0 | |
| FR-WHOOK-004 | 签名 | 头 `X-PT-Signature: t=<unix>,v1=<hex(HMAC_SHA256(secret, t + "." + body))>`、`X-PT-Event`、`X-PT-Delivery`（UUID） | P0 | 接收方可验证 |
| FR-WHOOK-005 | 重试 | 非 2xx / 超时（10 s）→ 指数退避重试（1 m、5 m、30 m、2 h、6 h，共 6 次） | P0 | |
| FR-WHOOK-006 | 自动停用 | 连续失败 50 次或 24 小时全部失败 → 停用并通知管理员（`webhook.delivery_failed` 事件） | P1 | |
| FR-WHOOK-007 | 投递日志 | 每次投递：状态码、耗时、重试次数、响应前 1 KiB（不含请求头密钥），保留 14 天 | P1 | |
| FR-WHOOK-008 | 测试 | 发送测试事件 | P1 | |
| FR-WHOOK-009 | 格式转换 | discord：`{content, embeds[]}`；slack：`{text, blocks[]}` | P2 | |
| FR-WHOOK-010 | 顺序 | 同一端点按事件发生顺序尽力投递（不保证严格有序；载荷含 `occurred_at` 与事件 ID） | P2 | |
| FR-WHOOK-011 | 防 SSRF | 拒绝私有地址、回环、链路本地、元数据地址（解析 DNS 后检查）；只允许 443 或配置端口 | P0 | |

## 4. 非功能需求

单端点 50 事件/秒；投递不阻塞事件处理（订阅只写投递队列）。

## 5. 可配置项

`allowed_hosts`（空 = 任意公网主机）、`max_endpoints`（20）、`timeout_secs`（10）、`disable_after_failures`（50）。

## 6. 外部接口需求概述

HTTP `/api/p/webhook/v1/admin/endpoints[...]`、`/deliveries`、`/test`；事件 `webhook.delivery_failed`（已登记）。
