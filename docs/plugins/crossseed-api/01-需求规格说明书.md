## 1. 引言

### 1.1 目的

定义辅种接口插件 `crossseed-api` 的需求：让用户的辅种工具（IYUU Plus、cross-seed、自动辅种脚本等）用本地已有种子的内容指纹查询本站是否有相同内容的种子，并下载本站版本做种。

### 1.2 背景

PT 站发布种子时会改写 `info` 字典（`private = 1`、`source` 字段），因此同一份内容在不同站点的 info_hash 不同；但 `pieces` 字段（各分块的 SHA-1）不变。辅种工具因此用 `SHA-1(pieces)`（即 torrent 插件的 `content_fp`）跨站匹配。NexusPHP 等站点为辅种工具提供了“按 pieces hash 查询种子”的接口；IYUU 以其服务端汇总各站数据，客户端再向各站下载。

### 1.3 范围

包含：按内容指纹（v1 `pieces` 的 SHA-1）批量查询本站种子；按 info_hash（v1 / v2）查询（同站重复做种场景）；返回种子 ID 与下载链接（通过 rss 的下载接口与 feed key，不暴露 passkey）；鉴权（个人 API token，作用域 `crossseed`）；限流与配额；隐私（只返回用户可见的种子）；IYUU 兼容层（按 IYUU 当前对接规范实现，部署前核实，见 03 §3）。

不包含：IYUU 服务端；向第三方主动推送本站数据（若站点与 IYUU 合作需要提供站点数据，由站点决定并另行实现授权的导出接口，默认关闭）。

### 1.4 参考资料

- docs/plugins/torrent/03（`content_fp = SHA-1(pieces)`）
- NexusPHP：辅种接口（按 pieces hash 查询种子 ID）
- IYUU Plus（官方文档 doc.iyuu.cn、api.iyuu.cn）：客户端提取 info_hash，经 IYUU 服务端匹配其他站点的种子

## 2. 总体描述

WASM，ID `crossseed-api`，缩写 `XSEED`；无服务；依赖 `ctx.auth`（API token 鉴权）、`ctx.torrents`（批量读取与可见性）；只读视图 ⊕ `torrent.v_torrent_fingerprint`。

| 程序 | 做法 | 优点 | 缺点 | 我们的取舍 |
|---|---|---|---|---|
| NexusPHP | 按 pieces hash 查询，返回种子 ID；下载链接带 passkey | 被主流辅种工具支持 | 下载链接带 passkey；限流较弱 | **采纳**指纹查询；**改进**：下载链接改用可吊销的 feed key；严格限流 |

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-XSEED-001 | 指纹查询 | `POST /v1/lookup {pieces_sha1: [hex40, … ≤ 500]}` → 每个指纹对应的本站种子（ID、标题、体积、下载链接） | P0 | |
| FR-XSEED-002 | info_hash 查询 | 同上，参数 `info_hash_v1[]` / `info_hash_v2[]`（含历史 hash：种子文件替换前的 hash，`v_torrent_hash_history`） | P1 | |
| FR-XSEED-003 | 鉴权 | 个人 API token（作用域 `crossseed`）；`Authorization: Bearer` 或 `?token=`（兼容） | P0 | |
| FR-XSEED-004 | 下载链接 | 指向 rss 下载接口（`/api/p/rss/v1/dl/{id}?k=<feed_key>`）；未启用 rss 时只返回种子 ID 与站点详情链接 | P0 | |
| FR-XSEED-005 | 可见性 | 只返回 approved 且用户有权下载的种子 | P0 | |
| FR-XSEED-006 | 限流与配额 | 每 token 每分钟 10 次请求、每日 50000 个指纹 | P0 | |
| FR-XSEED-007 | 用户条件 | 站点可要求最低等级才能使用（`crossseed-api.use` 权限点的默认角色） | P1 | |
| FR-XSEED-008 | IYUU 兼容 | 兼容层路由（按 IYUU 对接规范的请求 / 响应格式；部署前核实） | P2 | |
| FR-XSEED-009 | 审计 | 记录每 token 的查询量（不记录具体指纹） | P1 | |

## 4. 非功能需求

批量 500 个指纹 p99 < 100 ms（索引查询）；不泄露不可见种子是否存在。

## 5. 可配置项

`max_batch`（500）、`rate_per_min`（10）、`daily_quota`（50000）、`iyuu_compat`（false）。

## 6. 外部接口需求概述

HTTP `POST /api/p/crossseed-api/v1/lookup`；IYUU 兼容路由（启用时）；设置页提示用户使用个人 API token。
