## 1. 测试范围与策略

| 层次 | 内容 | 工具 |
|---|---|---|
| 单元 | 谓词求值、规则校验、续期计算（extend/latest）、SVG 净化、头衔清洗 | `cargo test` |
| 集成 | 插件 + 内核 testkit + PG + Redis + blob；identity / terms / notify 桩 | `pt-testkit` |
| 契约 | WIT `pt:medals@0.1.0`、事件 schema、OpenAPI、MCP schema | `xtask contract-check` |
| 性能 | `show_many` 100 用户；事件计数 500 事件/秒；统计评估 30 万用户 | k6、testkit 事件注入 |
| 安全 | SVG 攻击样本、头衔注入、越权 | 集成 |

## 2. 测试环境与数据

- 物品：M1（medal、可佩戴、永久、reject）、M2（medal、30 天、extend）、M3（badge、限量 2）、T1（title）、T2（title）。
- 用户：u1～u5（active）、u9（deleted）。
- 成就规则：R1（torrent.created、非匿名、≥ 1 GiB，count ≥ 3 → M1）、R2（stat：uploaded ≥ 10 TiB → M3）、R3（checkin.checked_in，repeatable，count ≥ 2 → M2）。
