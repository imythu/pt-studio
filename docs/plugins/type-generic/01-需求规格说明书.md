## 1. 引言

### 1.1 目的

定义通用资源类型插件 `type-generic` 的需求：让站点**不写代码**即可新增简单资源类型（游戏、软件、电子书、有声书、课程、纪录片合集、体育赛事、综艺等），每种“子类型（kind）”的字段、分组、标题模板、文件规则都由管理员在后台配置。共用部分见 [../_shared/content-types-common.md](../_shared/content-types-common.md)。

### 1.2 范围

包含：kind 定义（字段 schema 子集、可选分组键、标题模板、文件规则、元数据源绑定）、内置的 4 个预设 kind（game、software、ebook、course）、校验、搜索字段、元数据联动（IGDB 用于 game）。

不包含：需要复杂规则（如 log 检查、季集校验）的类型——这些应写成专门插件。

### 1.3 术语

| 术语 | 说明 |
|---|---|
| kind | type-generic 下的子类型；对外 `type_id = "generic"`，种子字段 `kind` 区分 |

### 1.4 参考资料

- 共用设计
- UNIT3D：categories 可配置 + 类型字段有限（`meta` 绑定 IGDB 等）
- NexusPHP：后台自定义分类与少量自定义字段（“种子扩展字段”插件）
- Arcadia：内容无关的组织方式（只借鉴思路）

## 2. 总体描述

WASM，ID `type-generic`，`type_id = "generic"`；导出、钩子、订阅同 type-movie。

### 2.1 现有开源 PT 程序的做法调研

| 程序 | 做法 | 优点 | 缺点 | 我们的取舍 |
|---|---|---|---|---|
| NexusPHP | 分类后台可配，扩展字段通过插件 | 灵活 | 扩展字段没有校验与筛选 | **采纳**后台配置；**改进**：字段有类型、校验、筛选与搜索属性 |
| UNIT3D | categories 带“是否为游戏 / 音乐 / 影视”标志 | 简单 | 类型能力受限于标志 | **采纳**按 kind 绑定元数据源 |

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-TGEN-001 | kind 管理 | 管理员创建 / 编辑 / 停用 kind：标识（`^[a-z][a-z0-9_]{1,31}$`）、名称（术语 `type-generic.kind.<kind>`）、图标、字段列表、分组键字段、标题模板、文件规则、元数据源 | P0 | 新 kind 立即出现在上传类型选择中 |
| FR-TGEN-002 | 字段类型 | 支持 string（长度、正则）、integer / number（范围）、enum（选项列表）、multi-enum、bool、date、url（仅 https）、external-id（绑定元数据源） | P0 | |
| FR-TGEN-003 | 字段属性 | 必填、默认值、显示名（术语）、筛选（facet / range）、搜索（searchable / exact）、是否 Group 级 | P0 | |
| FR-TGEN-004 | 分组 | 可选：指定一个或多个字段组成分组键（如游戏按 IGDB ID，电子书按 ISBN）；不指定则不分组 | P1 | |
| FR-TGEN-005 | 标题模板 | 每个 kind 一个模板；策略 replace / reject / none | P1 | |
| FR-TGEN-006 | 文件规则 | 允许的扩展名、禁止的扩展名、最少 / 最多文件数 | P1 | |
| FR-TGEN-007 | 预设 | 内置 game、software、ebook、course 四个预设，可修改或停用 | P0 | |
| FR-TGEN-008 | 字段变更兼容 | 删除字段不影响已有种子（旧字段保留在 fields 中但不再显示 / 搜索）；修改枚举时提供旧值映射 | P1 | |
| FR-TGEN-009 | 搜索 | 每个 kind 的字段以 `generic_<kind>_<field>` 贡献到索引；kind 本身为 `generic_kind` facet | P0 | |
| FR-TGEN-010 | 元数据 | external-id 字段绑定的元数据源（如 game → IGDB）在 Group 创建后拉取 | P2 | |
| FR-TGEN-011 | 限制 | 每个 kind 字段数 ≤ 30；kind 总数 ≤ 50（索引字段数受控） | P0 | 超限拒绝 |

## 4. 非功能需求

normalize p99 < 5 ms（字段定义缓存在本插件 kv，按版本号失效）；索引字段总数受控（≤ 50 × 30 = 1500，实际 search 会合并同名字段）。

## 5. 可配置项与站点术语

所有配置通过 kind 管理接口；术语 `type-generic.name`、`type-generic.kind.<kind>`、`type-generic.field.<kind>.<field>`、`type-generic.option.<kind>.<field>.<value>`（动态，经 terms.define）。

## 6. 外部接口需求概述

导出、钩子、订阅同 type-movie；HTTP `/api/p/type-generic/v1/kinds`（user，读取启用的 kind）与 `/v1/admin/kinds[/{kind}]`（`type-generic.manage`）。
