## 1. 测试范围与策略

单元（kind 定义校验、compile、normalize、模板渲染、group_key）；集成（上传、search 字段、kind 变更后重建）；机制复用；安全（正则大小、URL 协议、字段注入）。

## 2. 测试数据

四个预设 kind；自定义 kind `audiobook`（title、author、narrator、duration_hours、format）。
