## 1. 模块详细设计

### 1.1 kind 定义格式（`schemas/kind.v1.json`）

```json
{
  "schema": 1,
  "kind": "game",
  "name_zh": "游戏", "name_en": "Games",
  "icon": "icon:gamepad",
  "fields": [
    { "key": "title", "type": "string", "required": true, "max_len": 200, "group_level": true, "search": "searchable",
      "label_zh": "名称", "label_en": "Title" },
    { "key": "igdb_id", "type": "external_id", "source": "igdb", "group_level": true, "search": "exact" },
    { "key": "platform", "type": "enum", "required": true, "filter": "facet",
      "options": [ { "value": "windows", "label_zh": "Windows" }, { "value": "macos" }, { "value": "linux" },
                   { "value": "switch" }, { "value": "ps5" }, { "value": "ps4" }, { "value": "xbox" }, { "value": "other" } ] },
    { "key": "release_kind", "type": "enum", "options": [ { "value": "iso" }, { "value": "repack" }, { "value": "portable" }, { "value": "dlc" }, { "value": "update" } ], "filter": "facet" },
    { "key": "version", "type": "string", "max_len": 40 },
    { "key": "languages", "type": "multi_enum", "options": [ { "value": "zh-Hans" }, { "value": "zh-Hant" }, { "value": "en" }, { "value": "ja" }, { "value": "other" } ], "filter": "facet" },
    { "key": "year", "type": "integer", "min": 1970, "max": 2100, "group_level": true, "filter": "range" }
  ],
  "group_fields": ["igdb_id"],
  "group_fallback_fields": ["title", "year"],
  "title_template": "{title} {version?v| }[{platform}] {release_kind?[|]}",
  "title_policy": "replace",
  "files": { "allowed_extensions": [], "forbidden_extensions": ["lnk", "scr"], "min_files": 1, "max_files": 100000 },
  "metadata_source": "igdb"
}
```

| 约束 | 值 |
|---|---|
| `fields` | 1～30 个；`key` 为 `^[a-z][a-z0-9_]{0,31}$`，保留 `kind`、`release_name`、`description` |
| `type` | `string`（`max_len` ≤ 2000、`pattern` 可选，经 `regex` crate 编译并限制大小 ≤ 1 KiB，禁止回溯类特性由 crate 天然保证）、`integer`、`number`、`enum`（选项 ≤ 100）、`multi_enum`、`bool`、`date`、`url`（仅 https，≤ 500）、`external_id`（`source` 必须为已启用的元数据源，ID 格式取该源 `id-pattern`） |
| `filter` | `facet`（enum / multi_enum / bool / string 短字段）、`range`（数值 / 日期）、`none` |
| `search` | `searchable`（string）、`exact`、`none` |
| `group_fields` | 引用 `group_level = true` 的字段；为空则不分组 |

预设 kind：`game`（上例）、`software`（title、version、platform、license：free / freeware / shareware / commercial、architecture）、`ebook`（title、authors、isbn（exact、分组）、format：epub / pdf / mobi / azw3 / djvu / cbz、language、publisher、year）、`course`（title、provider、instructor、language、level、duration_hours）。

### 1.2 compile

```
compile(def) -> CompiledKind {
  json_schema: {type: object, required: [...], properties: {key: 映射(type, 约束, x-pt-label-term, x-pt-widget, x-pt-filter, x-pt-search, x-pt-group-level)}, additionalProperties: false}
  terms: [type-generic.kind.<kind>, type-generic.field.<kind>.<key>, type-generic.option.<kind>.<key>.<value>…]
  search_fields: [{name: "generic_" + kind + "_" + key, type, filterable, sortable, searchable, exact, label_term}]
  title_tpl: 解析后的模板（只允许引用已定义字段）
}
```

`info()` 的 `field-schema`：`{ "type": "object", "required": ["kind"], "properties": {"kind": {"enum": [active kinds]}}, "oneOf": [每个 kind 的 schema（附 `properties.kind.const`）] }`。

### 1.3 normalize

```
kind = fields.kind；k = compiled(kind)（kv 缓存 compiled_<kind>@<ver>；版本号 kv "schema_ver"）；不存在 / 停用 → type-generic.kind_invalid
f = 只保留 k 的字段 + kind；枚举值按 vocab 映射旧值；string trim + NFC；校验失败 → type-generic.field_invalid{errors}
external_id：按源的 id-pattern 从链接中提取
```

### 1.4 grouping

```
group_key(f) = if k.group_fields 全部有值: "generic:" + kind + ":" + join(norm(v), ":")
               elif k.group_fallback_fields 全部有值: "generic:" + kind + ":t:" + join(norm(v), ":")
               else None
```

### 1.5 rules（钩子）

文件规则：`allowed_extensions` 非空时至少一个文件匹配；`forbidden_extensions` 命中即拒绝；文件数在 `[min_files, max_files]`（钩子输入 `file_count`）。标题策略同共用设计 §5。去重：只在有 group_key 时，同 Group 同（全部 `filter = facet` 的字段值）视为重复，按 `dupe_policy`（kind 级设置，默认 pending）。

### 1.6 search

`index-schemas()` 返回 `torrents` 与 `groups` 两个索引的字段：`generic_kind`（facet）+ 每个 active kind 的 `search_fields`。kind 变化后：`ctx.search.refresh_schema("type-generic")`（若 search 支持，见 02 §7），否则后台提示管理员在 search 后台执行重建。

### 1.7 字段变更兼容

| 变更 | 处理 |
|---|---|
| 新增字段 | 立即生效；旧种子该字段为空 |
| 删除字段 | 定义中标记 `deprecated = true`，不再出现在表单与筛选；旧值保留在 fields 中，不再进入索引 |
| 枚举改值 | 管理员提供 `old → new` 映射，写入 `vocab`；normalize 与 to-document 时映射 |
| 修改 group_fields | 只影响新上传；已有 Group 不迁移（提示管理员可用 torrent 的合并功能） |

## 2. 接口详细设计

**GET `/api/p/type-generic/v1/kinds`** → `{ "items": [ { "kind": "game", "name": "游戏", "icon": "icon:gamepad", "schema": { … compiled json_schema … } } ] }`

**POST `/v1/admin/kinds`**：请求为 §1.1 定义 → 201；校验错误 422 `type-generic.kind_definition_invalid`（`details.errors[]`）。**PATCH / DELETE `/v1/admin/kinds/{kind}`**（DELETE = 停用；有种子时不能物理删除）。**PUT `/v1/admin/kinds/{kind}/value-map`** `{ "field": "platform", "map": { "win": "windows" } }`。

## 3. 数据库设计（schema `type_generic`）

```sql
CREATE TABLE type_generic.kinds (
    kind        text PRIMARY KEY,
    definition  jsonb NOT NULL,
    compiled    jsonb NOT NULL,
    version     integer NOT NULL DEFAULT 1,
    active      boolean NOT NULL DEFAULT true,
    preset      boolean NOT NULL DEFAULT false,
    updated_at  timestamptz NOT NULL DEFAULT now()
);
CREATE TABLE type_generic.vocab (
    kind   text NOT NULL,
    field  text NOT NULL,
    alias  text NOT NULL,
    value  text NOT NULL,
    PRIMARY KEY (kind, field, alias)
);
```

`group_meta` 同 type-movie（schema `type_generic`）。

## 4. 配置项

无静态配置；运行时设置：`max_kinds`（50）、`max_fields_per_kind`（30）。

## 5. 前端设计

上传：先选 kind，再按 compiled schema 渲染表单；Group 页与详情页按字段列表通用渲染（label 走术语）；后台 kind 编辑器：字段表格（类型、约束、筛选、搜索、Group 级）、模板编辑器（插入字段按钮、实时预览）、文件规则。
