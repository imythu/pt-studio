## 1. 测试范围与策略

| 层次 | 内容 | 工具 |
|---|---|---|
| 单元 | 哈希链、开奖抽号（均匀性、无重复、拒绝采样边界）、奖金分配与尾差、彩池分配、seed 加解密 | `cargo test`、统计检验 |
| 交叉验证 | Rust 实现与 `tools/lottery-verify.py` 对同一测试向量输出一致 | CI 脚本 |
| 集成 | 插件 + testkit + PG + 真实 ledger；drand 桩（可配置成功 / 超时） | `pt-testkit` |
| 故障注入 | 扣款任务、开奖任务、派奖任务中途崩溃 | testkit |
| 性能 | 100 万张票开奖与派奖；购票 100 次/秒 | testkit、k6 |

## 2. 测试环境与数据

- 模板 L1：每日 12:00 开奖、开售 24 h、票价 100、每人限购 100、min_tickets 10、返奖 800‰、奖级 1×500‰ / 5×300‰ / 50×200‰、滚存。
- 用户：u1～u50（余额充足，注册 > 7 天）、u60（注册 2 天）、u61（余额 50）。
- 竞猜 K1：2 个选项，返奖 900‰，不允许多选项。
