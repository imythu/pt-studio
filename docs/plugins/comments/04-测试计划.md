## 1. 范围与策略

`pt-markup` 单元测试 + XSS 测试集（OWASP XSS Filter Evasion Cheat Sheet 全部条目、HTML5 Security Cheatsheet、自建 BBCode 边界用例 ≥ 200 条）+ 模糊测试（cargo-fuzz：渲染输出必须通过“只含白名单元素与属性”的检查器）；插件集成测试；性能测试。

## 3. 通过准则

XSS 测试集与模糊测试必须全部通过；其余 P0 / P1 通过；性能达标。
