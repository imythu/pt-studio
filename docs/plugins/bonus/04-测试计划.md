## 1. 测试范围与策略

| 层次 | 内容 | 工具 |
|---|---|---|
| 单元 | 表达式词法/解析/静态检查/求值（proptest 生成随机 AST 与数值）、分档编译、规则版本选择、金额取整与封顶、部分合并 | `cargo test`、`proptest` |
| 插件集成 | 真实 PG + testkit 宿主加载 `bonus.wasm`；stub `ctx.ledger`（记录调用、可注入错误与幂等行为）或真实 ledger；stub accounting（发布快照、`seeding_now`、`swarm_stats`）、identity（`users.get`）、terms（记录 `define`）、torrent、rbac、medals | `pt-testkit`、testcontainers |
| 跨插件 | 与真实 ledger、accounting、terms：完整“快照 → 用户小时 → 入账 → 余额” | testkit |
| 契约 | WIT 兼容；事件载荷（`bonus.hourly_settled`、`bonus.awarded`）与订阅事件 schema；OpenAPI；MCP 输入输出 schema | `wasm-tools`、jsonschema、`oasdiff` |
| 性能 | 快照处理吞吐与延迟、表达式求值基准、入账周期耗时 | criterion、k6（事件注入） |
| 安全 | 表达式恶意输入、权限、作用域、reason 伪造 | 单元 + 集成 |

## 2. 测试环境与数据

- PostgreSQL 17、Redis 7；内核 testkit；时间可冻结（`ctx.time`）。
- 数据集 D1：1 万用户 × 80 种子的快照（多种体积、存活时间、做种人数），其中 1% 用户 > 1000 个种子（触发多部分）；D2：NexusPHP 公式的离线参考结果（独立 Python 脚本按公开公式计算，不使用其源码）；D3：UNIT3D 风格分档的离线参考。
- 用户状态：active、banned、leech_disabled、pending、deleted 各若干。
