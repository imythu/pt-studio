## 1. 设计目标与原则

1. 用“Group + edition_key + 种子”三层表达 Gazelle 的四层（艺人 / 专辑 / 版本 / 格式）：艺人是 Group 字段，版本是种子字段的组合键。
2. log 检查是纯函数，但耗时较长，放在异步阶段；结果写入本插件表并通过 `ctx.torrents.set_tags` 打标签（`log_100`、`log_issues`）。
3. trump 只产生候选，由 moderation 决定。

## 2. 总体结构

模块：`schema`、`normalize`（艺人名规范化、发行类型、版本字段）、`grouping`、`rules`（文件校验、去重、trump）、`logcheck`（log 解析与评分）、`meta`（MusicBrainz）、`search`。

## 3. 对外接口清单

| 类别 | 内容 |

| 权限点 | `type-music.manage` |

## 4. 数据设计概要

`group_meta`、`trumps`、`vocab`（同 type-movie），另加 `log_results`（torrent_id、log_index、software、score、issues JSON、checked_at、checker_version）。

## 5. 关键流程

```
normalize:
  artists：[{name, role, mbid?}]；name 规范化（NFC、去首尾空白；"Various Artists" 统一）
  release_type 同义词映射；original_year（Group）与 edition_year（种子）分开
  format/encoding：FLAC + 24bit → encoding = lossless_24；MP3 + V0 → encoding = v0
  edition_key = sha256(media ‖ edition_year ‖ norm(label) ‖ norm(catalog) ‖ norm(edition_title))[0..16]
group_key: music:mbrg:<mbid> | music:title:<norm(主艺人)>:<norm(album)>:<original_year>
rules（钩子）:
  音频扩展名 ∈ format 的扩展名集合（FLAC→flac，MP3→mp3，ALAC→m4a，DSD→dsf/dff，……），且音频文件数 ≥ 1
  has_log ⇒ 存在 .log；has_cue ⇒ 存在 .cue；media = CD 且 format 无损 且 !has_log → tags += no_log
  logs[] 只检查数量与大小（≤ 5、≤ 512 KiB），内容在 check_logs 中处理
  去重键：(group_id, edition_key, format, encoding, has_log, log_score 档位)
check_logs（torrent.created 后）:
  for log in fields.logs: r = logcheck::score(log)；INSERT log_results
  torrent 级 log_score = min(各 log 分数)；torrents.set_tags(+ log_<score 档位> / log_issues)
  更新 trump 判定（同版本内比较）
```

## 6. 设计决策

| 编号 | 问题 | 结论与理由 |
|---|---|---|
| DD-TMUS-1 | 艺人是否独立实体 | 不独立建表：艺人页通过 search `groups` 索引的 `music_artists`（含 MBID）聚合；艺人别名来自 MusicBrainz。好处是核心无需新增实体；代价是艺人简介等信息需从元数据实时获取 |
| DD-TMUS-2 | log 分数的权威性 | 本插件给出“估算分数”，规则公开、可复算；与 OPS / RED 的官方 log checker 分数不保证一致；站点可接入独立的 `log-checker` 插件（未来）覆盖 |
| DD-TMUS-3 | log 文本存储 | log 文本放在 torrent 的 `fields.logs`（由 torrent 存储，受其大小上限约束）；若 torrent 字段上限不够，请 torrent 提供附件存储（§7） |

## 7. 对平台契约的新增

共用设计 §9；torrent：`fields` 大小上限需 ≥ 2.6 MiB（5 × 512 KiB log）或提供种子附件（blob）接口 `ctx.torrents.attachments`（推荐后者）；作用域 `write:tags`；标签键 `log_100`、`log_95`、`log_issues`、`no_log`、`trump_candidate` 需在 torrent 标签目录中登记；术语 `type-music.release_type.<type>`、`type-music.artist_role.<role>`。
