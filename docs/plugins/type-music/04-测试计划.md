## 1. 测试范围与策略

单元（规范化、format/encoding 组合、edition_key、log 评分规则）；log 测试向量 `tests/vectors/music/logs/*.log` + 期望分数（≥ 30 份，覆盖 EAC 各版本、XLD、whipper、UTF-16 / GBK 编码、篡改、非安全模式、CRC 不一致）；集成（torrent 上传、check_logs、search）；机制复用用例参数化复跑。

## 2. 测试环境与数据

Group：某艺人某专辑（MBID 已知）；已有种子 A：CD FLAC lossless 无 log；B：WEB FLAC lossless_24。
