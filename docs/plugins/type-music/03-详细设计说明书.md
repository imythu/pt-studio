## 1. 模块详细设计

### 1.1 字段定义

**Group 字段**：`album`（1～250）、`album_aliases[]`、`artists[]`（`{name, role, mbid?}`，1～50 项）、`release_type`、`original_year`、`mb_release_group_id`（UUID）、`genres[]`（≤ 10，元数据标签）、`cover`（blob 路径）、`description`。

**种子字段**：

| 字段 | 类型 | 枚举 / 约束 |
|---|---|---|
| `media` | enum | `cd`、`web`、`vinyl`、`sacd`、`dvd`、`bluray`、`cassette`、`dat`、`soundboard`、`other` |
| `edition_year` | integer? | 1877～当前年 + 1 |
| `edition_label` | string? | ≤ 80 |
| `edition_catalog` | string? | ≤ 80 |
| `edition_title` | string? | ≤ 80（如 “Deluxe Edition”、“2011 Remaster”） |
| `format` | enum | `flac`、`mp3`、`aac`、`alac`、`dsd`、`opus`、`ac3`、`dts`、`wavpack`、`ape`、`other` |
| `encoding` | enum | `lossless`、`lossless_24`、`320`、`v0`、`v1`、`v2`、`256`、`192`、`other` |
| `has_log`、`has_cue`、`scene` | bool | |
| `log_score` | integer? | 0～100，由 `check_logs` 写入（上传者不可填） |
| `logs` | string[] | ≤ 5 项，各 ≤ 512 KiB |
| `release_name` | string? | ≤ 255 |

format 与 encoding 的合法组合表：`flac / alac / wavpack / ape → lossless | lossless_24`；`dsd → lossless`；`mp3 → 320 | v0 | v1 | v2 | 256 | 192 | other`；`aac / opus → 320 | 256 | 192 | other`；违反 → `type-music.format_encoding_invalid`。

### 1.2 logcheck

**输入**：log 文本（自动检测编码：UTF-16 LE BOM、UTF-8、GBK 回退）。

**识别与评分规则**（扣分制，满分 100，规则表随插件版本发布，`checker_version` 记录在结果中）：

| 规则 | 检测 | 扣分 |
|---|---|---|
| 软件 | EAC（`Exact Audio Copy V`）、XLD（`X Lossless Decoder version`）、whipper、CUERipper | 未知软件：分数不计算（null），标记 `unknown_ripper` |
| 读取模式 | EAC：`Read mode : Secure`；XLD：`Ripper mode : XLD Secure Ripper` | 非安全模式 −20 |
| 读取偏移 | `Read offset correction` 非零或在已知驱动表中（内置常见驱动表，可在后台扩展） | 偏移为 0 且驱动非 0 偏移 −5 |
| 缺陷与校验 | `Copy CRC` 与 `Test CRC` 不一致 | 每轨 −20 |
| 测试拷贝 | 无 `Test CRC` | −10 |
| 音频缓存 | `Defeat audio cache : No` | −10 |
| 静音 / 空隙 | `Gap handling` 未检测 | −5 |
| AccurateRip | 全部 `Accurately ripped` | 加入问题列表但不扣分；`not present in database` 不扣分 |
| 错误 | `Suspicious position`、`Timing problem`、`Missing samples` | 每处 −5（每轨最多 −20） |
| 篡改 | 日志校验和（EAC `==== Log checksum`、XLD 签名）缺失 | −15（不验证签名算法——实现需要逆向，超出范围，记录为“未校验”） |
| 归一化 / 压缩 | `Normalize to` 出现 | −30 |

分数下限 0。输出 `{software, version, score, issues: [{code, track?, message_term}], checker_version}`。

### 1.3 rules（钩子）

```
音频扩展名映射：flac→[flac]；mp3→[mp3]；aac→[m4a, aac]；alac→[m4a]；dsd→[dsf, dff]；opus→[opus]；ac3→[ac3]；dts→[dts]；wavpack→[wv]；ape→[ape]
audio = files_sample where ext ∈ map[format]；audio 为空 → deny(type-music.no_audio_files)
has_log 且无 .log 文件 → deny(type-music.log_missing)；has_cue 且无 .cue → deny(type-music.cue_missing)
fields.log_score 由上传者提供 → 删除（modify fields）
media == cd 且 format 无损 且 !has_log → tags += no_log
去重：same = v_torrent_fields where group_id, edition_key, format, encoding 相同 且 !scene
  same 中存在 has_log = has_log 且（log_score 未知或 ≥ 本种子可能的最高分）→ dupe_policy 处理
trump 候选：本种子 has_log 而 same 中存在 !has_log 的同格式 → 记录候选（最终在 check_logs 后确认）
```

### 1.4 check_logs（延迟任务，`torrent.created` 后调度）

```
f = v_torrent_fields[torrent_id]；if f.type_id != music or !f.has_log: return
results = f.logs.map(logcheck::score)
score = results 中非 null 的最小值；全部 null → None
INSERT log_results（每个 log 一行）ON CONFLICT (torrent_id, log_index) DO UPDATE
torrents.update(torrent_id, {fields: {log_score: score}})   // ⊕ 需要 torrent 允许插件更新 fields 中的受保护键，见 §7
torrents.set_tags(torrent_id, 现有标签 ∪ {log_100 | log_95+ | log_issues})（幂等：集合运算）
trump 确认：同版本同格式 same 中，score > 对方分数（或对方无 log）→ trumps 写入
```

### 1.5 search

| 索引 | 字段 | 类型 | 属性 |
|---|---|---|---|
| torrents | `music_format`、`music_encoding`、`music_media` | string | facet |
| torrents | `music_has_log`、`music_has_cue`、`music_scene` | bool | filterable |
| torrents | `music_log_score` | int | filterable、sortable |
| torrents | `music_edition_year` | int | filterable |
| torrents | `music_label`、`music_catalog` | string | searchable、exact（catalog） |
| groups | `music_artists`（名称）、`music_artist_mbids` | string[] | searchable / filterable |
| groups | `music_release_type` | string | facet |
| groups | `music_original_year` | int | filterable、sortable |

`title_fields = []`（音乐不使用影视发布名解析）。同义词：艺人别名（MusicBrainz aliases）作为文档内同义名。

## 2. 接口详细设计

导出与钩子同 type-movie。

**POST `/v1/log-check`**（上传前预检，不落库）请求 `{ "log": "<文本>" }`（≤ 512 KiB）→ `{ "software": "EAC", "version": "1.6", "score": 95, "issues": [ { "code": "no_test_copy", "message": "未进行测试拷贝" } ], "checker_version": 1 }`。

## 3. 数据库设计（schema `type_music`）

`group_meta`、`trumps`、`vocab` 同 type-movie；另：

```sql
CREATE TABLE type_music.log_results (
    torrent_id       bigint NOT NULL,
    log_index        smallint NOT NULL,
    software         text,
    software_version text,
    score            smallint,
    issues           jsonb NOT NULL DEFAULT '[]',
    checker_version  integer NOT NULL,
    checked_at       timestamptz NOT NULL DEFAULT now(),
    PRIMARY KEY (torrent_id, log_index)
);
```

## 4. 配置项

见 SRS §5；`formats` / `encodings` 只能在内置枚举中启用 / 停用（不能新增值，避免规则表失配）。

## 5. 前端设计

Group 页：艺人（角色分组）、专辑名、原始年份、封面；种子按版本（年份 / 厂牌 / 目录号 / 版本名 / 介质）分组，组内列出格式；log 分数徽标（颜色分档），点击查看问题列表。上传：艺人编辑器（多行、角色下拉、MBID 自动补全）、log 粘贴框（实时预检）。
