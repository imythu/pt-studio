## 1. 引言

定义内容 AI 审核插件 `ai-moderation` 的需求：对评论、论坛帖子等公开用户内容做异步分类（垃圾广告、辱骂、仇恨、色情、违法、自我伤害、泄露个人信息），疑似违规时自动生成举报交给人工处理。**不自动删除内容**；不审核站内信（私密内容）。

范围：订阅 `comment.created`、`forum.post_created`（及可选的 `forum.topic_created`）；取正文（经授权接口）；本地预过滤（廉价规则，不调用模型）；模型分类（结构化输出）；阈值与动作（标记 + 生成举报）；服务 `classify(text, context)`；钩子 `comment.before_create` 的本地规则处理（只做廉价检查，不调用模型）；预算与统计；误报反馈。

参考：moderation 的敏感词（确定性）与本插件互补：敏感词处理明确的词，本插件处理语义层面的违规。

## 2. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-AIMOD-001 | 触发 | 订阅评论与帖子创建事件；按配置抽样（默认全量，新用户内容优先） | P0 | |
| FR-AIMOD-002 | 取正文 | 经 comments / forum 的授权读取接口（作用域）获取纯文本 | P0 | |
| FR-AIMOD-003 | 本地预过滤 | 链接数、重复字符、已知垃圾域名列表；命中高置信规则直接标记（不调用模型） | P1 | |
| FR-AIMOD-004 | 模型分类 | 输出：`categories[]`（spam、harassment、hate、sexual、illegal、self_harm、personal_info、other）及各自 `score`（0～1）、`rationale`（≤ 200 字） | P0 | |
| FR-AIMOD-005 | 阈值与动作 | 任一类别分数 ≥ `report_threshold`（默认 0.8）→ 发布 `ai.content_flagged` 并以系统身份创建举报（`ctx.reports.create`，理由映射）；≥ `review_threshold`（0.5）→ 只记录供抽查 | P0 | |
| FR-AIMOD-006 | 服务 | `classify(text, context)`（其他插件同步调用——只能在非钩子调用中使用） | P1 | |
| FR-AIMOD-007 | 钩子 | `comment.before_create`：只执行 FR-003 的本地规则（高置信垃圾直接拒绝，返回 `ai-moderation.spam_detected`） | P2 | 默认关闭 |
| FR-AIMOD-008 | 预算 | 每日模型调用上限，超出后只做本地规则 | P0 | |
| FR-AIMOD-009 | 反馈 | 举报处理结果（`report.resolved`：invalid / resolved）回流统计每类准确率 | P1 | |
| FR-AIMOD-010 | 隐私 | 不发送作者身份给模型；不处理站内信 | P0 | |

## 3. 非功能需求

单条分类 p95 < 10 s（异步）；事件处理不阻塞发帖。

## 4. 可配置项

`sources`（comment、forum_post）、`sample_rate`（1.0）、`new_user_days`（30，新用户内容总是审核）、`report_threshold`（0.8）、`review_threshold`（0.5）、`daily_model_budget`（20000）、`profile`（cheap）、`spam_domains`、`hook_enabled`（false）。

## 5. 外部接口需求概述

服务 `ctx.ai_moderation.classify`；事件 `ai.content_flagged`；订阅 `comment.created`、`forum.post_created`、`report.resolved`；HTTP `/api/p/ai-moderation/v1/admin/flags`、`/admin/stats`；无用户界面。
