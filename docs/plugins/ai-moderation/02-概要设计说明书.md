| 类别 | 内容 |
|---|---|
| 原则 | 只建议、不删除；举报进入人工流程；本地规则先于模型；私密内容不审核 |
| 模块 | `intake`（订阅、抽样、调度）、`fetch`（取正文）、`local`（本地规则）、`classifier`（模型调用）、`actions`（标记与举报）、`feedback`（准确率统计）、`budget` |
| 依赖 | `ctx.llm`（`use`、`profile:cheap`）、`ctx.reports`（`create`，作用域 `write`，系统举报者 ⊕）、`ctx.comments` 与 `ctx.forum` 的正文读取（⊕ 需要 `get_raw(id)` 服务方法与作用域 `read:raw`） |
| 事件 | 发布 `ai.content_flagged`；订阅见 SRS §5 |
| 钩子 | 处理 `comment.before_create`（priority 40，默认关闭，只做本地规则） |
| 延迟任务 | `classify_item`（dedupe = target） |
| 设计决策 | DD-AIMOD-1：系统举报者——reports 需要支持 `reporter_id = None`（系统 / 插件举报，记录 `reporter_plugin`）；DD-AIMOD-2：分数阈值可按类别覆盖（如 personal_info 0.6）；DD-AIMOD-3：结果只存类别与分数，不存正文副本 |
| 平台契约新增 | comments / forum 服务 `get_raw(id) -> {plain_text, author_id, target}`（作用域 `read:raw`）；reports `create` 接受系统举报者；`ai.content_flagged` 载荷增加 `report_case_id?` |
| 权限点 | `ai-moderation.manage`（已登记） |

需求追溯：FR-001、008 → intake、budget；FR-002 → fetch；FR-003、007 → local；FR-004、006 → classifier；FR-005 → actions；FR-009 → feedback；FR-010 → fetch（只取文本）、classifier（不发送身份）。
