## 1. 测试范围与策略

| 层次 | 内容 | 工具 |
|---|---|---|
| 单元测试 | bencode 解码 / 编码 / 拼接；parser 各项校验；normalizer 策略；状态机迁移表；签名令牌；可见性函数；文件名清洗 | `cargo nextest`、`proptest`（编码往返、拼接不改变 info 字节） |
| 模糊测试 | `decode`、`parse`、`normalize`、`splice_root` | `cargo fuzz`（libFuzzer），种子语料含 BEP 52 测试向量与真实种子 |
| 集成测试 | 内核 + torrent + `t-identity-stub`（可编程 `ctx.users`/`ctx.rbac`）+ `t-type-stub`（可编程 `content-type`）+ 可编程钩子处理者 `t-hooks-torrent`；PG 17、Redis 7.4、MinIO（testcontainers） | `pt-testkit` |
| 契约测试 | `pt:torrents@0.1.0` WIT 解析与四种调用组合；OpenAPI 片段与路由一致；事件 / 钩子 schema 校验；视图列与 LLD 一致 | `wasm-tools`、`xtask` |
| 兼容测试 | 生成的种子被真实客户端加载、info_hash 与库中一致、announce 地址正确 | qBittorrent 4.6 / 5.0、Transmission 4.0、Deluge 2.1、rTorrent 0.9.8（容器内无界面运行） |
| 性能测试 | 下载吞吐与延迟、上传解析耗时、`get_many` | `oha`、`criterion` |
| 安全测试 | 路径穿越、畸形种子、passkey 泄漏扫描、匿名泄漏、签名伪造、权限越权、XSS | 专项用例 + 日志扫描脚本 |

## 2. 测试环境与数据

- CI：Linux x86_64；PG 17、Redis 7.4、MinIO 最新稳定版。
- 性能：8 核 32 GB × 1（内核副本）+ 独立 PG、MinIO。
- 测试数据：
  - `fixtures/torrents/`：v1 单文件、v1 多文件、v1 含 BEP 47 填充、纯 v2、hybrid（libtorrent 2.0 生成）、BEP 52 规范测试向量；畸形样本 40 个（未排序键、重复键、前导零、深嵌套 100 层、超长字符串前缀、尾随字节、pieces 长度错误、`..` 路径、NUL 路径、Windows 保留名、重名文件、hybrid 不一致、piece layers 缺失）。
  - 10 万文件种子（生成器脚本）、10 MiB 种子。
  - 用户：普通、uploader、moderator、admin、`leech_disabled`、`banned`、`pending`、无 passkey 用户。
  - 2 个资源类型桩：`movie`（分组键 = imdb_id）、`generic`（不分组）。
