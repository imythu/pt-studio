## 1. 引言

定义 IMDb 元数据源插件。共用部分见 [../_shared/metadata-providers-common.md](../_shared/metadata-providers-common.md)。

**合规前提**：IMDb 没有公开免费 API；其 Non-Commercial Datasets 仅限个人非商业使用，且条款明确不得用于建立电影信息数据库；IMDb 网站禁止爬取。因此本插件**不从 IMDb 获取任何数据**，只提供：

- IMDb ID 识别与校验（从链接中提取 `tt\d{7,9}`）；
- 规范外链（`https://www.imdb.com/title/<tt>/`）；
- 通过 `ctx.metadata` 委托 TMDB 的 `/find`（metadata-tmdb 已启用时）把 IMDb ID 映射为 TMDB 条目并返回其数据（数据来源标注为 TMDB）；
- 可选：站点配置的第三方授权服务端点（例如站点已取得授权的商业数据服务），约定接口同 metadata-douban 的代理方式（默认关闭）。

参考：NexusPHP 的 IMDb 抓取插件（爬取网页，已不建议使用）；UNIT3D 通过 TMDB 的外部 ID 获取 IMDb 关联。

## 2. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-MDIMDB-001 | ID 识别 | `info().id-pattern` 识别链接与纯 ID | P0 | |
| FR-MDIMDB-002 | 校验 | `lookup` 对非法 ID 返回 `id_invalid` | P0 | |
| FR-MDIMDB-003 | 委托 TMDB | metadata-tmdb 可用时，`lookup(tt)` 返回 TMDB 数据（`ids.imdb` = tt，attribution 为 TMDB） | P0 | |
| FR-MDIMDB-004 | 无委托时 | 返回最小数据 `{ids.imdb, attribution: {source: imdb, url}}` | P0 | |
| FR-MDIMDB-005 | 授权端点（可选） | 配置后从站点授权服务获取，默认关闭，需风险确认 | P2 | |
| FR-MDIMDB-006 | 外链 | 前端展示 IMDb 外链 | P0 | |

## 3. 非功能需求

无出站访问 imdb.com；委托调用受 metadata-tmdb 的限速与缓存约束。

## 4. 可配置项

`delegate_to`（`tmdb` / `none`，默认 tmdb）、`licensed_endpoint`（可选）、`licensed_enabled`（false）。

## 5. 外部接口需求概述

导出 `metadata-provider`（`search` 不支持，返回空列表）；HTTP `/api/p/metadata-imdb/v1/lookup`。
