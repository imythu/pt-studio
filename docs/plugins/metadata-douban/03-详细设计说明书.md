client、cache、images、限速、熔断、表结构与 metadata-tmdb 03 相同（schema `metadata_douban`，限速默认 1 次/秒）。

## 1. 代理接口约定（站点自行实现）

**GET `{proxy_base_url}/subject/{id}`** → 200：

```json
{ "id": "1292052", "type": "movie",
  "title": "肖申克的救赎", "original_title": "The Shawshank Redemption", "aka": ["刺激1995"],
  "year": 1994, "pubdate": "1994-09-10",
  "imdb": "tt0111161",
  "genres": ["剧情", "犯罪"], "countries": ["美国"], "languages": ["英语"],
  "directors": ["弗兰克·德拉邦特"], "casts": ["蒂姆·罗宾斯", "摩根·弗里曼"],
  "durations_min": 142, "episodes_count": null,
  "rating": { "value": 9.7, "count": 3000000 },
  "poster_url": "https://img.example.com/view/photo/l/public/p480747492.jpg",
  "summary": "…" }
```

404：条目不存在；429：限流（带 Retry-After）；其他 5xx：上游错误。

**GET `{proxy_base_url}/search?q=&type=movie|tv|book&limit=20`** → `{ "items": [ { "id", "type", "title", "year", "poster_url" } ] }`；不支持时 404。

## 2. mapper

| 代理字段 | 统一模型 |
|---|---|
| `title` | `titles.localized["zh-CN"]` |
| `original_title` | `titles.original` |
| `aka` | `titles.aliases` |
| `imdb` | `ids.imdb`（格式校验 `tt\d{7,9}`） |
| `genres`（中文） | 映射表（剧情→drama、喜剧→comedy、动作→action、爱情→romance、科幻→scifi、动画→animation、悬疑→mystery、惊悚→thriller、恐怖→horror、犯罪→crime、纪录片→documentary、战争→war、奇幻→fantasy、冒险→adventure、家庭→family、历史→history、音乐→music、歌舞→musical、传记→biography、运动→sport、西部→western、武侠→wuxia、古装→costume）；未知保留为 `other` |
| `countries`（中文） | ISO 3166 映射表（美国→US、中国大陆→CN、中国香港→HK、中国台湾→TW、日本→JP、韩国→KR、英国→GB、法国→FR……），未知丢弃 |
| `rating` | `ratings.douban` |
| `poster_url` | 主机 ∈ `image_hosts` 才转存 |
| `summary` | `overview["zh-CN"]`（去除 HTML 标签） |
| — | `attribution = {source: "douban", url: "https://movie.douban.com/subject/<id>/", license_note: "数据来源：豆瓣"}` |

## 3. consent

**POST `/v1/admin/enable`** `{ "ack": true, "statement_version": 1 }` → 写 kv `consent`、设置 `enabled = true`、审计；声明文本（前端展示）：“豆瓣未提供公开 API。启用本插件意味着站点自行部署并对代理服务的合规性负责。”

## 9. 错误码表

| 错误码 | HTTP 状态 | 说明 |
|---|---|---|
| `metadata-douban.not_enabled` | 503 | 未启用或未确认风险 |
| `metadata-douban.not_configured` | 503 | 未配置代理 |
| `metadata-douban.id_invalid` | 422 | |
| `metadata-douban.not_found` | 404 | |
| `metadata-douban.upstream_error` | 502 | 代理错误 |
| `metadata-douban.search_unsupported` | 501 | 代理不支持搜索 |
