## 1. 引言

定义豆瓣元数据源插件。共用部分见 [../_shared/metadata-providers-common.md](../_shared/metadata-providers-common.md)。

**合规前提**：豆瓣官方 API 已不对普通开发者开放，现有第三方方案多为爬取移动端接口或网页，存在服务条款与法律风险。因此本插件：

- **默认关闭**；
- **不内置任何爬取逻辑**，只调用站点自行部署、自行承担责任的“豆瓣代理端点”（约定接口见详细设计 §2），例如站点自建的兼容服务；
- 启用时管理员必须在后台确认风险声明（写审计）。

范围：电影 / 剧集 / 图书条目的查询与搜索（经代理）；中文标题、豆瓣评分、简介、海报转存；与 IMDb ID 的交叉（代理返回时）。

参考：NexusPHP 的豆瓣插件（历史上调用官方 API，官方关闭后各站改用自建代理）。

## 2. 总体描述

WASM，ID `metadata-douban`，`source = "douban"`，`type_ids = ["movie", "tv", "generic"]`；`id-pattern`：`(movie|book)\.douban\.com/subject/(\d+)` 与纯数字。

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-MDDOUBAN-001 | 风险确认 | 启用前须提交风险确认；未确认时 lookup 返回 `metadata-douban.not_enabled` | P0 | |
| FR-MDDOUBAN-002 | 代理端点 | 静态配置 `proxy_base_url`（https）与可选 `proxy_token` | P0 | |
| FR-MDDOUBAN-003 | 查询 | `lookup("<subject_id>")` → 统一模型 | P0 | |
| FR-MDDOUBAN-004 | 搜索 | `search(query, type)`（代理支持时） | P1 | 代理返回 404 时视为不支持 |
| FR-MDDOUBAN-005 | 缓存与限速 | 缓存 30 天；限速默认 1 次/秒（可配置，避免对代理与上游造成压力） | P0 | |
| FR-MDDOUBAN-006 | 图片 | 海报转存（代理返回的图片 URL 主机须在允许列表） | P1 | |
| FR-MDDOUBAN-007 | 署名 | 展示“数据来源：豆瓣”及条目链接 | P1 | |

## 4. 非功能需求

同共用设计；代理不可用时只返回缓存。

## 5. 可配置项与术语

静态：`proxy_base_url`、`proxy_token`（secret）、`image_hosts`（允许转存的图片主机）。运行时：`enabled`（false）、`rate_per_sec`（1）、`cache_days`（30）。

## 6. 外部接口需求概述

导出 `metadata-provider`；HTTP `/api/p/metadata-douban/v1/lookup`、`/search`、`POST /admin/enable`（风险确认）；`metadata.fetched`；cron `refresh_stale`。
