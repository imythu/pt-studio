## 1. 模块详细设计

### 1.2 summary

```
resolution：height（取 Video #1）→ ≥ 2000 → 2160p（宽度 ≥ 3800 时）；≥ 1000 → 1080p；≥ 700 → 720p；≥ 560 → 576p；否则 480p
            （对宽银幕：优先用宽度判断：w ≥ 3800 → 2160p，w ≥ 1900 → 1080p，w ≥ 1260 → 720p）
video_codec：format ∈ {HEVC} → hevc；{AVC} → avc；{AV1} → av1；{VC-1} → vc1；{MPEG Video} 且 version 2 → mpeg2
hdr：hdr_format 含 "Dolby Vision" → dv；含 "SMPTE ST 2094" 或 "HDR10+" → hdr10plus；含 "SMPTE ST 2086" 或 "HDR10" → hdr10；transfer_characteristics = HLG → hlg
bit_depth：数字
audio_codecs：每个 Audio 段：format（MLP FBA + Atmos 元数据 → truehd_atmos；MLP FBA → truehd；DTS XLL → dtshd_ma；DTS XLL X → dtsx；E-AC-3 + JOC → ddp_atmos；E-AC-3 → ddp；AC-3 → dd；AAC；FLAC；PCM → lpcm；Opus）+ channels + language
subtitle_languages：Text 段 language（ISO 639 归一化）
container：General.format（Matroska → mkv、MPEG-4 → mp4、BDAV → m2ts）
duration_secs：General.duration 解析（"2 h 16 min"、"2小时16分钟"、"02:16:03.123"）
```

### 1.3 sanitize

```
for (seg, key, value) where key ∈ {complete_name} 或 value 匹配路径正则（^[A-Za-z]:\\|^\\\\|^/）:
   value = basename(value)（同时处理 / 与 \ 分隔符）
另：value 中出现 "C:\Users\<name>\"、"/home/<name>/"、"/Users/<name>/" 的片段一律替换为 "…/"
sanitized_text：在原文本上按行替换（保持原格式）
```

### 1.4 bdinfo

识别 `DISC INFO:`、`PLAYLIST REPORT:`、`VIDEO:`、`AUDIO:`、`SUBTITLES:` 段；视频行 `MPEG-H HEVC Video  51520 kbps  2160p / 23.976 fps / 16:9 / Main 10 @ Level 5.1 @ High / 10 bits / HDR10 / BT.2020`；音频行 `Dolby TrueHD/Atmos Audio  English  4285 kbps  7.1 / 48 kHz …`；Quick Summary 格式（`Video: …`、`Audio: …`）同样支持。

### 1.5 compare

```
compare(summary, fields) -> [{field, declared, detected}]:
  resolution、video_codec、hdr（集合比较：声明的 HDR 必须 ⊆ 检测到的）、audio_codecs（声明的主音轨必须在检测结果中）、bit_depth（声明 10bit 时）
  未知（检测为空）不计入差异
```

### 1.6 nfo

```
decode(bytes):
  UTF-8 BOM / UTF-16 BOM → 对应解码
  合法 UTF-8 且无 0x80–0x9F 控制区异常 → UTF-8
  含 CP437 框线字符高频字节（0xB0–0xDF 占比 > 2%）→ CP437（内置映射表）
  否则尝试 GBK（encoding_rs），失败回退 CP437
去除 \x00–\x08、\x0B、\x0C、\x0E–\x1F；长度 ≤ 128 KiB
```

## 2. 接口详细设计

### 2.1 服务（WIT `pt:mediainfo@0.1.0`）

```wit
package pt:mediainfo@0.1.0;

interface mediainfo {
  use pt:plugin/types@1.0.0.{plugin-error, json};

  record audio-track { codec: string, channels: option<string>, language: option<string>, title: option<string> }
  record media-summary {
    container: option<string>, resolution: option<string>, width: option<u32>, height: option<u32>,
    video-codec: option<string>, hdr: list<string>, bit-depth: option<u8>, frame-rate: option<string>,
    duration-secs: option<u32>, audio: list<audio-track>, subtitle-languages: list<string>,
  }
  record media-info { format: string, summary: media-summary, sections: json, sanitized-text: string, warnings: list<string> }
  record nfo { text: string, encoding: string }
  record diff { field: string, declared: string, detected: string }

  parse: func(text: string) -> result<media-info, plugin-error>;
  parse-nfo: func(base64: string) -> result<nfo, plugin-error>;
  compare: func(summary: media-summary, fields: json) -> result<list<diff>, plugin-error>;
}
```

### 2.2 事件

`mediainfo.parsed`：`torrent_id, summary{resolution, video_codec, audio_codecs[], subtitles[], hdr[], bit_depth}, diffs_count`。

### 2.3 HTTP

**POST `/v1/parse`** `{ "text": "…" }` → `{ "format": "text", "summary": {…}, "sanitized_text": "…", "warnings": [] }`；413 `mediainfo.too_large`。**GET `/v1/torrents/{id}`** → 存储的解析结果与 diffs（对种子可见者开放）。

## 3. 数据库设计（schema `mediainfo`）

```sql
CREATE TABLE mediainfo.results (
    torrent_id    bigint PRIMARY KEY,
    text_hash     bytea NOT NULL,
    format        text NOT NULL,
    summary       jsonb NOT NULL,
    sections      jsonb NOT NULL,
    diffs         jsonb NOT NULL DEFAULT '[]',
    parser_version integer NOT NULL,
    parsed_at     timestamptz NOT NULL DEFAULT now()
);
```

`torrent.updated` 中 `fields` 变化且 `text_hash` 不同才重新解析；`torrent.deleted`（订阅）删除结果。

## 5. 前端设计

`torrent.detail.info`：规格表（视频、音频轨列表、字幕语言）+ 可展开的脱敏原文；差异以警告条显示（仅审核员与发布者可见）。上传：粘贴后实时预览摘要。
