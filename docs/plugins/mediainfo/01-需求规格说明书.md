## 1. 引言

### 1.1 目的

定义 MediaInfo / BDInfo / NFO 解析插件 `mediainfo` 的需求：把上传者粘贴的 MediaInfo 文本（或 BDInfo 报告）解析为结构化字段，供资源类型插件交叉校验、搜索与 AI 审核使用；脱敏其中的本地路径；正确解码 NFO。

### 1.2 范围

包含：MediaInfo 文本（默认视图，英文与常见中文本地化标签）、MediaInfo JSON（`--Output=JSON`）、BDInfo（Quick Summary 与完整报告）、NFO（CP437 / UTF-8 / GBK 解码）的解析；路径与用户名脱敏；规格摘要；与种子字段的一致性比较；异步解析已上传种子并发布 `mediainfo.parsed`。

不包含：运行 MediaInfo 程序（只解析文本）；视频文件本身的分析。

### 1.3 参考资料

- UNIT3D：MediaInfo 解析器（`MediaInfo` 类把文本解析为 general / video / audio / text 段，用于展示与校验）、BDInfo 展示
- NexusPHP：MediaInfo 文本原样展示
- MediaInfo 官方输出格式

## 2. 总体描述

WASM，ID `mediainfo`，缩写 `MINFO`；提供 `ctx.mediainfo`；订阅 `torrent.created`、`torrent.updated`；发布 `mediainfo.parsed`。

| 程序 | 做法 | 我们的取舍 |
|---|---|---|
| UNIT3D | 服务端解析文本为数组，模板展示规格表 | **采纳**分段解析与规格摘要；**改进**：脱敏路径、结构化结果供其他插件校验、支持 BDInfo 与中文标签 |
| NexusPHP | 原样展示 | 不采用 |

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-MINFO-001 | 文本解析 | 解析 General / Video / Audio / Text / Menu 段，提取关键字段 | P0 | 测试向量通过 |
| FR-MINFO-002 | JSON 解析 | 解析 MediaInfo JSON 输出 | P1 | |
| FR-MINFO-003 | BDInfo 解析 | 解析 BDInfo 报告（Disc Title、Playlist、Video、Audio、Subtitles） | P1 | |
| FR-MINFO-004 | 本地化标签 | 支持中文（简体 / 繁体）MediaInfo 标签（如“完整名称”“宽度”“格式”） | P1 | |
| FR-MINFO-005 | 脱敏 | `Complete name` 等字段中的目录部分只保留文件名；去除 Windows 用户目录、`/home/<user>`、`/Users/<user>`、UNC 路径主机名 | P0 | 输出不含原始目录 |
| FR-MINFO-006 | 规格摘要 | 输出 resolution、video_codec、hdr、bit_depth、frame_rate、duration、audio_codecs（含声道与语言）、subtitle_languages、container | P0 | |
| FR-MINFO-007 | 一致性比较 | `compare(summary, fields)`：与种子字段（分辨率、编码、HDR、音轨）比较，返回差异列表 | P1 | |
| FR-MINFO-008 | NFO 解码 | 检测编码（BOM / UTF-8 合法性 / CP437 字符画特征 / GBK），转为 UTF-8；去除控制字符 | P1 | 字符画正确显示 |
| FR-MINFO-009 | 异步解析 | 订阅 `torrent.created`（以及 `torrent.updated` 中 mediainfo 字段变化），解析并发布 `mediainfo.parsed`；结果存本插件表 | P0 | |
| FR-MINFO-010 | 预览接口 | `POST /v1/parse`（上传前预览） | P1 | |
| FR-MINFO-011 | 大小限制 | 文本 ≤ 256 KiB；超过拒绝 | P0 | |

## 4. 非功能需求

解析 64 KiB 文本 p99 < 20 ms；不出站；输出不含 HTML（前端以纯文本 / 表格渲染）。

## 5. 可配置项

`max_text_kb`（256）、`strip_paths`（true，不建议关闭）。

## 6. 外部接口需求概述

服务 `ctx.mediainfo.parse(text)`、`parse_nfo(text)`、⊕ `compare(summary, fields)`；事件 `mediainfo.parsed`；HTTP `POST /api/p/mediainfo/v1/parse`、`POST /v1/parse-nfo`、`GET /v1/torrents/{id}`；插槽 `torrent.detail.info`（规格表）、`torrent.upload.extra`（预览）。
