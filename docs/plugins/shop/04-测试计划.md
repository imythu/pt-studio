## 1. 测试范围与策略

| 层次 | 内容 | 工具 |
|---|---|---|
| 单元 | 价格计算（递增、闭式求和、溢出）、周期键、状态机转移表、错误归类 | `cargo test` |
| 集成 | 插件 + 内核 testkit + PG；**真实** ledger 插件；各适配器下游使用真实插件或可注入失败的桩 | `pt-testkit` |
| 故障注入 | 在状态机每一步之后注入崩溃 / 超时 / 下游失败 | testkit 故障注入点 |
| 契约 | WIT、事件 schema、OpenAPI、MCP | `xtask contract-check` |
| 性能 | 下单受理、并发限量商品 | k6 |

## 2. 测试环境与数据

- 币种 `bonus`；用户 u1 余额 100000、u2 余额 100、u3（banned）、u4（受赠者）。
- 商品：I1 upload_credit（10 GiB/件，10000/件，qty ≤ 10，每日限 5）；I2 invite_quota（1 个/件，30000，库存 3）；I3 rename（50000）；I4 medal（M1）；I5 vip（30 天/件）；I6 makeup_card；I7 promo_card；I8 hnr_removal；I9 递增价格（base 100、step 50、max 300）。
