## 1. 引言

定义 TMDB（The Movie Database）元数据源插件。共用部分见 [../_shared/metadata-providers-common.md](../_shared/metadata-providers-common.md)（下称“共用设计”）。

范围：电影、剧集、剧集单季的查询与搜索；多语言标题与简介；海报与背景图转存；交叉 ID（IMDb、TVDB）；评分；类型映射；署名展示。

参考：TMDB API v3 文档与使用条款（非商业免费，须署名；约 40 次/秒限速）；UNIT3D 的 TMDB 集成（拉取片名、海报、演员、类型、关键词）。

## 2. 总体描述

WASM，ID `metadata-tmdb`，`source = "tmdb"`，支持 `type_ids = ["movie", "tv", "anime"]`；`id-pattern` 识别 `themoviedb.org/(movie|tv)/(\d+)` 与纯数字 ID（需配合类型）。

| 程序 | 做法 | 我们的取舍 |
|---|---|---|
| UNIT3D | 上传时同步调用 TMDB，结果存 movies / tv 表 | 改为异步 + 缓存；只存归一化结果 |
| NexusPHP | 无 TMDB（IMDb 抓取插件为主） | 以 TMDB 作为默认影视源 |

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-MDTMDB-001 | 电影查询 | `lookup("movie:<id>")` 返回统一模型（共用设计 §2） | P0 | |
| FR-MDTMDB-002 | 剧集查询 | `lookup("tv:<id>")`、`lookup("tv:<id>:s<n>")`（单季：季名、集数、首播日期、海报） | P0 | |
| FR-MDTMDB-003 | 通过外部 ID 查找 | `lookup("imdb:tt…")` 使用 TMDB `/find` 接口映射到 TMDB 条目 | P1 | |
| FR-MDTMDB-004 | 多语言 | 按请求 locale 获取标题与简介；同时获取站点默认语言与英文 | P0 | |
| FR-MDTMDB-005 | 图片 | 转存海报（w500）与背景（w1280） | P1 | |
| FR-MDTMDB-006 | 搜索 | `search(query, type)`（电影 / 剧集），≤ 20 条 | P0 | |
| FR-MDTMDB-007 | 缓存 | 共用设计 §3 | P0 | |
| FR-MDTMDB-008 | 限速 | 令牌桶 30 次/秒（低于官方限制） | P0 | |
| FR-MDTMDB-009 | 署名 | 详情页展示 TMDB 标志与声明（前端组件 `<Attribution source="tmdb">`） | P0 | |
| FR-MDTMDB-010 | 配置 | API key（v3）或 Read Access Token（v4 Bearer），代理主机覆盖 | P0 | 未配置时不可用 |

## 4. 非功能需求

缓存命中 lookup p99 < 20 ms；未命中 p99 < 2 s（上游）；不在日志中输出 key。

## 5. 可配置项与站点术语

静态：`api_key` 或 `access_token`（secret）、`api_host`（`api.themoviedb.org`）、`image_host`（`image.tmdb.org`）、`commercial_ack`（bool，站点声明自己为非商业或已获授权）。运行时：`cache_days`（30）、`languages_extra`（[]）。

## 6. 外部接口需求概述

导出 `metadata-provider`；HTTP `/api/p/metadata-tmdb/v1/lookup`、`/search`；事件 `metadata.fetched`；cron `refresh_stale`。
