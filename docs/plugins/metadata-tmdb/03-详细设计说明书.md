## 1. 模块详细设计

### 1.1 client

- 鉴权：优先 `Authorization: Bearer <access_token>`；否则 `?api_key=`（不写入日志：日志中 URL 查询参数整体脱敏）。
- 令牌桶：Redis Lua 脚本（`p:metadata-tmdb:rl`，容量 30，每秒补充 30）；WASM 插件经 `redis.call("EVAL")` 不允许（命令白名单禁止 EVAL）→ 改用 `INCR` + `EXPIRE` 的固定窗口计数（键 `rl:<unix_sec>`，上限 30，TTL 2 s），超限时等待到下一秒（最多 2 次）。
- 重试：429 → 读 `Retry-After`（缺省 1 s），最多 2 次；5xx → 指数退避 200 ms、800 ms；超时 5 s。
- 熔断：kv `breaker` 记录连续失败次数，≥ 10 次开启 5 分钟。

### 1.2 mapper

| TMDB 字段 | 统一模型 |
|---|---|
| `title` / `name`（按 locale） | `titles.localized[locale]` |
| `original_title` / `original_name` | `titles.original` |
| `translations.translations[].data.title` | `titles.localized[<iso_639_1>-<iso_3166_1>]`（只保留站点语言集合） |
| `alternative_titles`（不 append，避免数据量） | — |
| `release_date` / `first_air_date` | `release_date`、`year` |
| `external_ids.imdb_id`、`tvdb_id` | `ids.imdb`、`ids.tvdb` |
| `genres[].id` | `genres`（映射表：28→action、12→adventure、16→animation、35→comedy、80→crime、99→documentary、18→drama、10751→family、14→fantasy、36→history、27→horror、10402→music、9648→mystery、10749→romance、878→scifi、10770→tv_movie、53→thriller、10752→war、37→western；TV 类型 10759→action_adventure、10762→kids、10763→news、10764→reality、10765→scifi_fantasy、10766→soap、10767→talk、10768→war_politics） |
| `production_countries[].iso_3166_1` / `origin_country` | `countries` |
| `spoken_languages[].iso_639_1` / `original_language` | `languages` |
| `credits.crew`（job = Director / Screenplay / Writer） | `people[]` role director / writer |
| `credits.cast[0..20]` | `people[]` role cast |
| `runtime` / `episode_run_time[0]` | `runtime_min` |
| `number_of_episodes`、季 `episodes.length` | `episode_count` |
| `vote_average`、`vote_count` | `ratings.tmdb` |
| `poster_path`、`backdrop_path` | `images.poster`、`images.backdrop`（转存） |
| `overview` | `overview[locale]` |
| `status`（TV） | `extra.status`（Returning Series → returning、Ended → ended、Canceled → canceled） |
| — | `attribution = {source: "tmdb", url: "https://www.themoviedb.org/<type>/<id>", license_note: "This product uses the TMDB API but is not endorsed or certified by TMDB."}` |

### 1.3 images

`GET https://image.tmdb.org/t/p/w500<poster_path>`；校验 `Content-Type` 与大小 ≤ 2 MiB；`blob.put("images/<sha256>.jpg")`；同一 `poster_path` 的转存结果缓存在 kv（`img:<path_hash>` → blob 路径），避免重复下载。

### 1.4 cache 与 refresh_stale

TTL：`release_date` 在 90 天内或 TV `status = returning` → 7 天；否则 `cache_days`。`refresh_stale`：`SELECT … WHERE fetched_at < now() - ttl AND last_used_at > now() - interval '90 days' ORDER BY last_used_at DESC LIMIT 2000`，逐个 lookup（受限速约束，单次运行 ≤ 10 分钟）。

## 2. 接口详细设计

### 2.1 导出 `metadata-provider`

- `info()`：`{source: "tmdb", type-ids: ["movie", "tv", "anime"], id-pattern: "^(movie|tv):\\d+(:s\\d+)?$|^imdb:tt\\d{7,9}$"}`。
- `lookup` 返回 `lookup-result{source, external-id（规范化后，如 imdb:… 映射为 movie:603）, data, fetched-at}`。
- `search(query, type_id, limit)`：`GET /3/search/movie` 或 `/3/search/tv`（anime → tv）。

### 2.2 事件

`metadata.fetched`：`source = "tmdb", external_id, type_id, group_id = None`。

### 2.3 HTTP API

**GET `/v1/lookup?id=movie:603&locale=zh-CN`** →

```json
{ "source": "tmdb", "external_id": "movie:603", "stale": false,
  "data": { "kind": "movie",
            "titles": { "original": "The Matrix", "localized": { "zh-CN": "黑客帝国", "en-US": "The Matrix" }, "aliases": [] },
            "year": 1999, "release_date": "1999-03-30", "ids": { "tmdb": 603, "imdb": "tt0133093" },
            "genres": ["action", "scifi"], "countries": ["US"], "languages": ["en"],
            "people": [ { "name": "Lana Wachowski", "role": "director" } ],
            "runtime_min": 136, "ratings": { "tmdb": { "value": 8.2, "votes": 25000 } },
            "images": { "poster": "images/9a1f….jpg" },
            "overview": { "zh-CN": "…" },
            "attribution": { "source": "tmdb", "url": "https://www.themoviedb.org/movie/603", "license_note": "This product uses the TMDB API but is not endorsed or certified by TMDB." } } }
```

**GET `/v1/search?q=matrix&type=movie`** → `{ "items": [ { "external_id": "movie:603", "title": "黑客帝国", "original": "The Matrix", "year": 1999, "poster": "images/…" } ] }`

## 3. 数据库设计（schema `metadata_tmdb`）

```sql
CREATE TABLE metadata_tmdb.cache (
    external_id   text NOT NULL,
    locale        text NOT NULL,
    data          jsonb,
    not_found     boolean NOT NULL DEFAULT false,
    content_hash  bytea,
    fetched_at    timestamptz NOT NULL,
    last_used_at  timestamptz NOT NULL DEFAULT now(),
    PRIMARY KEY (external_id, locale)
);
CREATE INDEX cache_refresh_idx ON metadata_tmdb.cache (fetched_at) WHERE NOT not_found;
```

Redis（`p:metadata-tmdb:`）：`rl:<sec>`（2 s）、`s:<hash>`（搜索缓存 1 h）。kv：`breaker`、`img:<hash>`。

## 4. 配置项

见 SRS §5。

## 5. 前端设计

署名组件放在 Group 页元数据区域底部；上传表单 TMDB 字段旁“拉取”按钮调用 `/v1/lookup` 或 `/v1/search`（下拉选择结果）。

## 6. 安全设计

key 只在静态配置；URL 日志脱敏；转存图片校验类型与大小；HTTP 接口限流并要求登录。

## 7. 性能设计

append_to_response 每条目 1～2 次请求；缓存命中率目标 > 95%。

## 8. 可观测性

`pt_plugin_metadata_tmdb_requests_total{endpoint,status}`、`pt_plugin_metadata_tmdb_cache_hits_total`、`pt_plugin_metadata_tmdb_breaker_open`。

## 9. 错误码表

| 错误码 | HTTP 状态 | 说明 |
|---|---|---|
| `metadata-tmdb.not_configured` | 503 | 未配置 API key |
| `metadata-tmdb.id_invalid` | 422 | ID 格式错误 |
| `metadata-tmdb.not_found` | 404 | 条目不存在 |
| `metadata-tmdb.upstream_error` | 502 | 上游错误（熔断时返回缓存或此错误） |
