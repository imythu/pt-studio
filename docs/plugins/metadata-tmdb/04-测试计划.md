## 1. 策略

回放测试（录制的 TMDB 响应 `tests/fixtures/tmdb/`）；限速与熔断用可控的 HTTP 桩；不在 CI 中访问真实 TMDB。

## 2. 测试用例

| 编号 | 关联需求 | 步骤 | 预期结果 |
|---|---|---|---|
| TC-MDTMDB-001 | FR-001 | lookup movie:603（回放） | 统一模型字段与期望一致；类型映射正确 |
| TC-MDTMDB-002 | FR-002 | lookup tv:1399、tv:1399:s01 | 季名、集数、海报正确 |
| TC-MDTMDB-003 | FR-003 | lookup imdb:tt0133093 | 映射为 movie:603 |
| TC-MDTMDB-004 | FR-004 | locale = zh-CN 与 en-US | localized 含两种语言 |
| TC-MDTMDB-005 | FR-005 | 海报转存；同一 poster_path 二次 lookup | 只下载一次；blob 路径为 images/<sha256> |
| TC-MDTMDB-006 | FR-005 | 图片响应为 text/html 或 > 2 MiB | 不转存，images.poster 为空 |
| TC-MDTMDB-007 | FR-006 | search "matrix" | ≤ 20 条简要结果 |
| TC-MDTMDB-008 | FR-007 | 两次 lookup（缓存期内） | 第二次不请求上游 |
| TC-MDTMDB-009 | FR-007 | 上游 5xx 且有过期缓存 | 返回 stale = true 的数据 |
| TC-MDTMDB-010 | FR-007 | 不存在的 ID | not_found 负缓存 1 天 |
| TC-MDTMDB-011 | FR-008 | 3 个副本并发 200 次 lookup（不同 ID） | 上游请求速率 ≤ 30 次/秒 |
| TC-MDTMDB-012 | FR-008 | 上游返回 429 + Retry-After: 1 | 等待后重试成功 |
| TC-MDTMDB-013 | 熔断 | 连续 10 次失败 | 熔断 5 分钟，期间只返回缓存 |
| TC-MDTMDB-014 | FR-009 | 前端 Group 页 | 显示 TMDB 署名 |
| TC-MDTMDB-015 | FR-010 | 未配置 key | lookup 返回 `metadata-tmdb.not_configured`（503） |
| TC-MDTMDB-016 | 安全 | 检查日志 | 不含 api_key / token |
| TC-MDTMDB-017 | 事件 | 数据变化 / 未变化的 lookup | 只在变化时发布 metadata.fetched |
| TC-MDTMDB-018 | 重复执行 | refresh_stale 执行两次 | 第二次无上游请求（已刷新） |
| TC-MDTMDB-019 | 安全 | 未登录调用 /v1/lookup；超过 30 次/分钟 | 401；429 |
| TC-MDTMDB-020 | 钩子约束 | 在钩子调用链中触发 lookup | 宿主拒绝出站（`kernel.capability_denied`），返回缓存或错误 |
