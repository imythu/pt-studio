## 1. 测试范围与策略

| 层次 | 内容 | 工具 |
|---|---|---|
| 单元测试 | `calendar`（时区、夏令时）、`reward`（曲线、里程碑、随机）、连签重算 | `cargo test`（宿主 target，纯函数） |
| 集成测试 | 插件 + 内核 testkit + PG + Redis + ledger 桩（可注入失败） | `pt-testkit` |
| 契约测试 | WIT `pt:checkin@0.1.0` 与目录签名、事件 schema、OpenAPI 片段、MCP schema | `xtask contract-check` |
| 性能测试 | 0 点高峰 30 次/秒 × 10 分钟；状态查询 2000 次/秒 | k6 |
| 安全测试 | 越权、重复提交、限流 | 集成测试 |

## 2. 测试环境与数据

- PostgreSQL 17、Redis 7.4，内核 testkit（可控时钟、可控站点时区、可控随机数）。
- ledger 桩：记录调用；可配置为成功、超时、`ledger.currency_not_allowed`。
- 用户：u1（active）、u2（leech_disabled）、u3（banned）、u4（pending）、u5（注册于测试日前 3 天）。
- 默认设置：base 10、step 2、cap 100、里程碑 7/30、随机关闭、补签窗口 7 天、每月 3 次。
