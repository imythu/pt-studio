| 类别 | 内容 |
|---|---|
| 模块 | `auth`（Twitch 令牌）、`client`（Apicalypse、限速）、`mapper`、`cache`、`images` |
| 导出 | `metadata-provider` |
| 能力 | `sql`、`redis`、`blob`；`http_outbound = ["id.twitch.tv", "api.igdb.com", "images.igdb.com"]` |
| 关键流程 | 令牌：`POST https://id.twitch.tv/oauth2/token?client_id&client_secret&grant_type=client_credentials` → `{access_token, expires_in}` → Redis `tok`（TTL = expires_in − 300）；401 时清除并重取一次。查询：`POST https://api.igdb.com/v4/games`，头 `Client-ID`、`Authorization: Bearer`，体 `fields name,alternative_names.name,first_release_date,platforms,genres.name,themes.name,involved_companies.company.name,involved_companies.developer,involved_companies.publisher,total_rating,total_rating_count,cover.image_id,summary,slug; where id = <id>;` |
| 设计决策 | 令牌存 Redis 私有前缀（WASM 插件可用）；令牌获取加分布式锁（kv compare_and_set）防止多副本同时刷新 |
| 平台契约新增 | 无 |

需求追溯：FR-001 → auth；FR-002、003、006 → client、mapper；FR-004 → images；FR-005 → client。
