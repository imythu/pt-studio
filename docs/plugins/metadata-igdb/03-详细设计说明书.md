## 1. auth

```
token():
  t = redis.GET("tok")；有 → return
  if !kv.compare_and_set("tok_lock", None, now+10s)：等待 200 ms 后重读 tok（最多 5 次）
  r = POST id.twitch.tv/oauth2/token（client_id、client_secret、grant_type=client_credentials）
  redis.SET("tok", r.access_token, EX = r.expires_in − 300)；kv.delete("tok_lock")
```

令牌与 secret 不写日志；HTTP 客户端日志对 `Authorization`、查询参数中的 `client_secret` 脱敏。

## 2. mapper

| IGDB 字段 | 统一模型 |
|---|---|
| `name` | `titles.original` |
| `alternative_names[].name` | `titles.aliases` |
| `first_release_date`（Unix 秒） | `release_date`、`year` |
| `platforms[]`（ID） | `extra.platforms`：6→windows、14→macos、3→linux、130→switch、167→ps5、48→ps4、169→xbox（Series X/S）、49→xbox（One）、其他→other |
| `genres[].name`、`themes[].name` | `genres`（小写下划线化） |
| `involved_companies[]`（developer / publisher 标志） | `people[]` role developer / publisher |
| `total_rating`（0～100）、`total_rating_count` | `ratings.igdb`（value / 10） |
| `cover.image_id` | `images.cover`（`t_cover_big` 转存） |
| `summary` | `overview["en"]` |
| `slug` | `extra.slug` |
| — | `ids.igdb`；`attribution = {source: "igdb", url: "https://www.igdb.com/games/<slug>", license_note: "Data provided by IGDB"}` |

## 3. Apicalypse 安全

搜索文本：去除控制字符，`"` → `\"`，长度 ≤ 100；ID 必须为数字；slug 必须匹配 `^[a-z0-9-]{1,100}$`（slug 查询 `where slug = "<slug>";`）。
