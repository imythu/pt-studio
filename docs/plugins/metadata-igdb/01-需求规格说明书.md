## 1. 引言

定义 IGDB（Internet Game Database，Twitch 运营）元数据源插件，服务 type-generic 的 `game` kind。共用部分见 [../_shared/metadata-providers-common.md](../_shared/metadata-providers-common.md)。

条款要点：需要 Twitch 开发者应用的 Client ID 与 Client Secret，用 OAuth client credentials 获取应用访问令牌；速率 4 次/秒；请求使用 Apicalypse 查询语言（`POST /v4/games`，请求体为查询文本）。

参考：UNIT3D 的 IGDB 集成（游戏分类拉取封面、平台、类型、发行日期）。

## 2. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-MDIGDB-001 | 令牌 | 用 client credentials 获取应用令牌，存入 Redis 私有前缀（TTL = 令牌有效期 − 5 分钟，到期前自动刷新），多副本共享同一令牌 | P0 | |
| FR-MDIGDB-002 | 游戏查询 | `lookup("<game_id>")`：名称、别名、首发日期、平台、类型、主题、开发商 / 发行商、评分、封面、简介 | P0 | |
| FR-MDIGDB-003 | 搜索 | `search(query, "generic")`（Apicalypse `search "<q>"; fields …; limit n;`，查询文本转义双引号） | P0 | |
| FR-MDIGDB-004 | 封面 | `images.igdb.com/igdb/image/upload/t_cover_big/<image_id>.jpg` 转存 | P1 | |
| FR-MDIGDB-005 | 限速 | ≤ 3 次/秒（官方 4 次/秒留余量）；并发请求 ≤ 4 | P0 | |
| FR-MDIGDB-006 | 平台映射 | IGDB 平台 ID → type-generic game 的 platform 选项（windows、macos、linux、switch、ps5、ps4、xbox……） | P1 | |

## 3. 可配置项

静态：`client_id`、`client_secret`（secret）。运行时：`rate_per_sec`（3）、`cache_days`（30）。

## 4. 外部接口需求概述

导出 `metadata-provider`（`type_ids = ["generic"]`，`id-pattern`：`igdb\.com/games/([a-z0-9-]+)` 的 slug 或纯数字 ID——slug 需额外一次查询转换为 ID）；HTTP `/api/p/metadata-igdb/v1/lookup`、`/search`；`metadata.fetched`；cron `refresh_stale`。
