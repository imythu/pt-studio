本文是前端视觉与交互的唯一依据。宿主页面与插件前端都只用 `@pt-studio/ui-kit` 的组件与令牌，不自带颜色、字体与媒体查询。

## 1. 视觉方向

- 题材：《葬送的芙莉莲》。保留 `web/assets/frieren/` 的全部插画，只用在首页卷首、个人页封面、登录类整页、空状态与默认头像；数据区域保持克制。
- 不使用图标库与站点 logo 图形。导航、按钮、状态全部用文字表达；品牌只有字标「PT *Studio*」。
- 两套主题：昼（银白晨雾）与夜（苍月之夜）。跟随系统，可在顶栏切换并记住。

### 1.1 颜色令牌（`themes/tokens.css`）

| 令牌 | 用途 |
|---|---|
| `--bg` `--surface` `--sunk` | 页面底色、面板、凹陷区（表头、输入框） |
| `--ink` `--ink-2` `--muted` | 正文、次要文字、说明文字 |
| `--line` `--line-2` | 分割线、控件边框 |
| `--gold` / `--gold-soft` | 主强调（法衣金边）：当前项、优惠「免费」、魔力值 |
| `--emerald` / `--emerald-soft` | 上传、做种、成功 |
| `--moon` / `--moon-soft` | 链接、信息 |
| `--ember` / `--ember-soft` | 下载、断种、危险 |

语义色（成功 / 警告 / 危险 / 信息）与强调色分开使用；组件内不出现字面颜色。

### 1.2 字体

字体全部自托管（CSP `font-src 'self'`），放在 `web/assets/fonts/`，按 unicode-range 分片按需加载：

| 角色 | 字体 | 用途 |
|---|---|---|
| 展示 | ZCOOL XiaoWei | 页面标题、面板标题，克制使用 |
| 数字 | Cormorant Garamond | 大号统计数字、评分、字标；强制等高数字（`lnum`） |
| 等宽 | JetBrains Mono | 体积、人数、哈希、代码；表格数字列 |
| 正文 | 系统中文字体（PingFang SC / Microsoft YaHei / Noto Sans CJK） | 其余全部文字 |

## 2. 外壳

| 宽度 | 结构 |
|---|---|
| > 1000px | 左侧常驻栏：字标、我的数据卡（上传、下载、分享率、魔力、做种 / 下载数、H&R）、导航（插件导航插槽在内）；右侧顶栏：搜索（`/` 或 Ctrl+K 打开快速搜索）、昼夜、发布 |
| ≤ 1000px | 左栏收进「菜单」抽屉；顶栏下方显示一行我的数据条 |
| ≤ 760px | 顶栏一行（菜单、字标、搜索、昼夜）；底部标签栏：首页、种子、发布、消息、我的 |
| 后台 `/admin/*` | 左栏换成后台导航，顶部「管理后台 · 返回前台」 |
| 未登录 | 无左栏与标签栏的整页（登录、注册、找回密码等） |

## 3. 布局模式

页面里任何「两块并排」的结构，必须选用下列模式之一；模式由 ui-kit 组件实现，页面不得自行写媒体查询。

| 编号 | 模式 | 适用 | 窄屏行为 | 组件 |
|---|---|---|---|---|
| P1 | 次要控件折叠 | 调整列表的筛选、排序、视图 | 常用条件一行（快捷开关 + 排序）；高级条件收进「筛选」按钮：桌面在列表上方展开并记住状态，≤ 760px 为底部抽屉；已选条件显示为可删除标签 | `FilterBar` `Advanced` `ActiveFilters` |
| P2 | 主从两级 | 列表 + 选中项详情 | 宽屏左右并排；≤ 900px 一次只显示一级，详情顶部「返回」 | `MasterDetail` |
| P3 | 关键信息前置 | 侧栏含决定性信息 | ≤ 1240px 在正文前显示关键信息条，侧栏同名卡片隐藏；辅助卡片排到正文后 | `KeyFacts` `Side`（`priority`） |
| P4 | 创建与编辑进抽屉 | 按钮触发的表单 | 不常驻页面；桌面右侧滑出，≤ 760px 底部升起，底部固定操作按钮 | `Sheet` |
| P5 | 手机主操作固定 | 页面只有一个主要动作 | ≤ 760px 固定在标签栏上方，其余动作收进「更多」 | `MobileBar` |

### 3.1 实现约束

- R6：页面级布局尺寸只能经 CSS 变量传入组件（如 `--md-l`），不写内联 `grid-template-columns`。
- R7：抽屉、浮层、底部操作栏经 React Portal 挂到 `document.body`；页面容器不使用 transform、filter 或保持生效的动画（它们会改变 fixed 元素的定位与层叠）。
- R8：每个页面用 `data-primary` 标记主要内容区。
- R9：新增两栏结构必须选定 P1–P5 之一。

## 5. 文案

- 从用户角度命名（「通知」而不是「notify 插件」）；按钮写明动作，完成后提示结果（「发布」→「已发布」）。
- 错误说明原因与解决办法，不道歉。
- 结构性编号、角标只在内容确实有顺序时使用。

## 6. 布局自动检查

`web/tests/layout.mjs`（Playwright）以管理员登录，在 360×740、390×844、1100×900、1440×900 下逐个打开宿主页面与插件页面，任一项不满足即失败：

1. 页面不横向滚动；
2. 手机宽度下 `data-primary` 区域顶部位于首屏 62% 高度以内；
3. 主从页面窄屏只显示一级；
4. 打开的抽屉完整落在屏幕内，底部按钮不被其他层遮挡；`MobileBar` 可点击；
5. 无脚本错误与 CSP 违规。
