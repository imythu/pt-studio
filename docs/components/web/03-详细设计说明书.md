## 3. `@pt-studio/slots`

### 3.1 manifest

```ts
interface FrontendManifest {
  site: { name: string; default_locale: string; locales: string[]; themes: string[]; terms_version: number };
  shared: Record<string, string>;                 // 与 import map 一致，供插件校验版本
  plugins: Array<{
    id: string; version: string; entry: string;   // "/static/plugins/<id>/<hash12>/index.js"
    slots: string[]; routes: string[]; settings_ui: 'schema' | 'custom' | 'none';
    slots_api: string;                            // 依赖的 @pt-studio/slots 版本范围
  }>;
  features: Record<string, boolean>;
}
```

### 3.2 插件入口契约

```ts
import type { PluginFrontend } from '@pt-studio/slots';
export default {
  slots: { 'user.profile.stats': { component: BonusStat, order: 100 } },
  routes: [{ path: '/p/bonus/*', component: BonusPages }],
  settings: BonusSettings,          // settings_ui = custom 时
  onInit?: (api) => void,
} satisfies PluginFrontend;
```

### 3.3 Slot 组件

```tsx
export function Slot<N extends SlotName>({ name, ctx, fallback }: { name: N; ctx: SlotContext<N>; fallback?: ReactNode }) {
  const entries = useSlotEntries(name);            // manifest 中注册此插槽的插件，按 order、插件 ID 排序
  const kind = SLOT_KINDS[name];                   // list | single | tabs | columns（由 slots 目录生成）
  // 每个插件入口模块经 loader.import(entry) 懒加载（同一入口全局缓存一次）
  // 每个组件：<PluginBoundary plugin={id}> <Suspense fallback={<Skeleton/>}> <C ctx={ctx} api={apiFor(id)}/> </Suspense> </PluginBoundary>
}
```

- `PluginBoundary`：捕获错误，渲染“插件 X 加载失败”（仅员工可见详情），上报 `/api/kernel/v1/client-errors`（限流）。
- 插件入口加载失败（版本不兼容、404）：跳过该插件，不影响页面。
- 类型 `SlotName` / `SlotContext<N>` 由 `tools/gen-slots.ts` 从 `docs/platform/catalog/slots.md` 生成（与内核 catalog.json 同源）。

### 3.4 PluginApi

```ts
interface PluginApi {
  pluginId: string;
  fetch(path: `/api/${string}`, init?: RequestInit & { idempotent?: boolean }): Promise<Response>;   // 带会话与 CSRF；非 /api/ 路径直接抛错
  json<T>(path: `/api/${string}`, init?: …): Promise<T>;                                          // problem+json → ApiError
  t(key: string, args?: Record<string, unknown>): string;    // 'term:…' 与界面文案
  useTerm(key: string): TermValue;                            // {name, short?, unit?, icon?}
  navigate(to: string): void;
  toast(msg: string, kind?: 'info' | 'success' | 'error'): void;
  user(): UserSummary | null;
  batch<K, V>(key: string, loader: (keys: K[]) => Promise<Map<K, V>>): (k: K) => Promise<V | undefined>;
  refreshMe(): void;                                          // 改动了当前用户的魔力值 / 流量 / 等级后调用：刷新顶栏与个人卡片
  queryClient: QueryClient;                                   // 共享的 TanStack Query 客户端（键自动加 pluginId 前缀的 helper）
}
```

### 3.5 批量预取（`batch`）

同一渲染周期内多个插槽实例请求相同资源时合并：`batch('medals.show', ids => api.json('/api/p/medals/v1/show?user_ids=' + ids.join(',')))` 返回的函数在一个微任务内收集所有键，发出一次请求，最多 100 个键一批。用于 `user.name.decorations`、`torrent.list.row_badges` 等列表插槽。

## 4. Schema 表单（`@pt-studio/schema-form`）

| schema / 扩展 | 控件 |
|---|---|
| `string` | 文本框；`format: date / date-time` 日期选择；`x-pt-widget: markdown` Markdown 编辑器（预览走 comments 的 `/preview`）；`mediainfo` 多行等宽文本框 + 预览（mediainfo 插件 `/parse`） |
| `string` + `enum` | 下拉（选项文案 = `x-pt-label-term` 下的子键或 `enum` 值）；选项 > 10 时可搜索 |
| `array` + `items.enum` | 多选；`x-pt-widget: tags` 标签输入 |
| `integer` / `number` | 数字框；带单位时显示单位术语 |
| `boolean` | 开关 |
| `x-pt-widget: external-id` | 文本框 + “拉取信息”按钮（调用对应 metadata 插件 lookup，回填 `x-pt-from-metadata` 字段） |
| `oneOf` + 判别字段 | 判别字段切换显示子表单（type-generic 的 kind） |
| `if/then/else` | 条件显示 |

校验：Ajv（2020-12）客户端预校验 + 服务端 `details.errors[]`（JSON Pointer）映射到字段。

**筛选面板**：从 `/api/p/search-meilisearch/v1/indexes/torrents/schema` 读取字段（`filterable`、`facet`、`label_term`）→ facet 字段生成多选（带计数，来自搜索响应的 `facetDistribution`）、range 字段生成区间滑块；条件序列化到 URL 查询参数（可分享）。

## 5. 术语与 i18n

- 启动时 `GET /api/kernel/v1/terms?locale=<l>`（全量快照，带 `version`）；响应头 `X-PT-Terms-Version`（terms 03 §10 提议）大于本地版本时后台刷新。
- `t('term:bonus.currency')` → 术语名；`t('term:bonus.currency|short')`、`|unit` 取短名与单位；`tp('term:levels.class', id)` 动态键；`<TermIcon k>` 渲染图标。
- 界面文案 `t('ui.torrent.download')` 走 i18next 资源包（`app/locales/<l>/*.json`），插件自带资源包（`ui/locales/<l>.json`），命名空间为插件 ID。

## 7. 安全设计

- CSP（内核下发）：`default-src 'self'; script-src 'self' 'nonce-<n>'; style-src 'self'; img-src 'self' data: <image_hosts>; connect-src 'self'; frame-ancestors 'none'; base-uri 'none'; object-src 'none'`；`require-trusted-types-for 'script'`（支持的浏览器），`<UserContent>` 内部用 DOMPurify 的 Trusted Types 策略。
- `<UserContent html>`：唯一允许插入 HTML 的组件；DOMPurify 配置与服务端 `pt-markup` 白名单一致；链接 `rel="nofollow noopener ugc"`。
- 下载链接：点击时请求 `/api/p/torrent/v1/torrents/:id/download`，响应为文件，不在页面中展示 passkey。
- 插件：只能通过 PluginApi 访问 `/api/`；宿主不向插件暴露会话令牌（cookie 为 HttpOnly）。

## 8. 性能设计

- 路由级代码分割；`ui-kit` 与共享依赖独立分块并长期缓存（文件名带哈希）。
- 列表虚拟滚动（> 100 行）；图片 `loading="lazy"` 与 `srcset`（海报转存时生成多个尺寸——请 metadata 插件提供，⊕）。
- Query 缓存：种子详情 60 s、列表 30 s、术语与 manifest 会话期内。

## 9. 测试策略

见 04。CI：类型检查、ESLint（含 `react/no-danger` 规则只允许 `UserContent`）、单元与组件测试、Playwright E2E（对接 testkit 启动的内核与插件）、包体积检查（size-limit）、Lighthouse CI（性能预算）。

## 10. 错误码文案

`app/locales/<l>/errors.json`：`{ "kernel.rate_limited": "操作太频繁，请稍后再试", "ratio-policy.download_restricted": "你的分享率不足，暂时不能下载", … }`；插件错误码文案由插件资源包提供（命名空间为插件 ID）。未知错误码显示服务端 `message`。

## 实现说明（2026-10-17，开站计划 M4.5）

- **Markdown 编辑器**：`@pt-studio/ui-kit` 的 `MarkdownEditor`（工具栏：粗体、斜体、删除线、链接、图片、引用、代码、无序 / 有序列表、表格；快捷键 Ctrl/⌘+B / I / K；编辑 / 预览页签）。
  预览调用 `@pt-studio/sdk` 的 `renderPreview(body, markup)` → `POST /api/kernel/v1/markup/preview`（需登录、每用户 60 次 / 分钟、正文 ≤ 100000 字），
  与插件保存时同一个 pt-markup 渲染器，结果仍经 `UserContent` 净化。输入框在 DOM 中排在工具栏之前、预览时隐藏而不卸载，
  使外层 `<label>`（`Field`）始终关联到输入框。已用于：论坛发帖与编辑、站内信（新消息、回复、群发公告）、工单（提交、回复）、求种描述、种子发布与编辑描述。
- **后台页面**：用户详情页 `admin.user.tabs` 新增 等级（levels：当前等级与来源、生效中的覆盖、设置 / 锁定、解除、保号）、流量（accounting：手动调整）、
  余额（ledger：各货币余额与调整）、邀请（invite：名额调整、暂停邀请权）、促销卡（promotion：发放 / 扣除）；插件后台页新增 邀请管理（邀请码列表与撤销、
  发放系统 / 活动码、连带处罚复核）、促销管理（全站活动的创建与提前结束、自动规则的 JSON 新建与停用 / 启用）、AI 内容审核（准确率与标记列表）、
  AI 发布预审（近 30 天统计）、搜索索引（状态、待同步、重建与进度）、Claude 模型（用量与连通性测试）、自定义资源类型（JSON 编辑定义）。
  原生插件（accounting、ledger、search-meilisearch、llm-claude）同样通过 `plugin.toml` 的 `[frontend]` 声明前端。
- **移动端**：`.pt-stack` 的网格列改为 `minmax(0, 1fr)`（宽表格不再撑开整页，由 `.pt-table-wrap` 横向滚动）；两列表单（`.upload-grid`）在 720px 以下改为单列。
  浏览器测试在 390px 宽度下检查 27 个用户与后台页面，任何不在滚动容器内且超出视口的元素都会使测试失败。
