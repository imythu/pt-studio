## 1. 引言

### 1.1 目的

定义官方 React 前端 `web/` 的需求。前端是**参考实现**：站点可整体替换（只依赖 OpenAPI 生成的 SDK 与公开的插件前端契约），也可基于它二次开发。

### 1.2 范围

包含：应用外壳（布局、导航、登录态、错误处理）、核心框架页面（首页、种子列表 / 搜索、种子详情、作品页、上传、用户中心、设置、通知入口、后台框架）、插件前端加载（插槽、路由、设置页）、Schema 驱动表单与筛选面板、主题与暗色模式、i18n 与站点术语、响应式与移动端、可访问性、性能预算、API SDK 生成。

不包含：各插件的业务页面（由插件自带的前端包提供，如论坛、商城）；服务端渲染（见 §2.4）。

### 1.3 参考资料

- docs/design/06-frontend.md、docs/platform/catalog/slots.md、conventions/api.md、conventions/security.md（CSP）
- UNIT3D：Laravel Blade + Livewire（服务端渲染 + 局部更新），主题可切换；Gazelle：PHP 模板 + 少量 JS，样式表皮肤（stylesheets）；NexusPHP：PHP 模板，多套 CSS 主题
- 插件化前端参考：Grafana（插件以独立 bundle 动态加载，`@grafana/runtime` 提供宿主 API）、Backstage（插件以 React 组件 + 扩展点组合）

## 2. 总体描述

### 2.1 定位

单页应用（SPA），静态资源由内核或 CDN 提供；所有数据经 `/api/kernel/v1/*` 与 `/api/p/<plugin>/v1/*`。

### 2.2 用户角色

访客（登录、注册、找回密码页）、普通用户、员工（审核台、后台）、管理员。

### 2.3 现有开源 PT 程序的做法调研

| 程序 | 做法 | 优点 | 缺点 | 我们的取舍 |
|---|---|---|---|---|
| UNIT3D | Livewire 服务端组件，主题 CSS | 开发快、首屏快 | 前后端耦合，换前端等于重写后端模板；插件无法注入 UI | **改进**：API 优先 + SPA，前端可整体替换；插件通过插槽注入 |
| Gazelle / NexusPHP | PHP 模板与多套样式表 | 主题生态成熟（用户自选皮肤） | 模板与业务逻辑交织；XSS 历史问题多 | **采纳**多主题与用户自选；**改进**：主题只是设计令牌（CSS 变量），不改结构；渲染统一安全 |
| Grafana / Backstage | 插件独立打包、动态加载、宿主提供运行时 API | 插件与宿主解耦 | 共享依赖版本管理复杂 | **采纳**动态 ESM 加载 + 宿主提供的共享依赖（import map） |

### 2.4 约束

- PT 站页面几乎都需要登录，SEO 价值低：不做 SSR；登录页、注册页、错误页做成轻量静态页以保证首屏速度；
- 浏览器支持：最近两个大版本的 Chrome / Edge / Firefox / Safari，iOS Safari 16+；
- 插件前端由管理员安装（与插件一同放入目录），视为受信任代码，但仍受 CSP 与宿主 API 的约束。

## 3. 功能需求

| 编号 | 名称 | 描述 | 优先级 | 验收标准 |
|---|---|---|---|---|
| FR-WEB-001 | SDK 生成 | 从内核聚合的 OpenAPI（`/api/kernel/v1/openapi.json`）生成 TypeScript 客户端与类型（openapi-typescript + 轻量 fetch 封装） | P0 | 构建时生成，类型检查通过 |
| FR-WEB-002 | 外壳 | 顶栏（站点名术语、主导航插槽 `nav.main`、搜索框、通知铃铛、用户菜单插槽 `nav.user_menu`）、页脚、侧边（后台） | P0 | |
| FR-WEB-003 | 认证 | 登录（密码 + 2FA + WebAuthn）、注册（含插槽 `auth.register.form_extra`）、找回密码、会话过期处理（401 → 跳转登录并保留返回地址） | P0 | |
| FR-WEB-004 | 种子列表 / 搜索 | 搜索框、筛选面板（由索引 schema 生成 + 插槽 `torrent.list.filters`）、结果表格（列插槽 `torrent.list.columns`、徽标插槽 `torrent.list.row_badges`）、排序、游标分页、按作品折叠 | P0 | |
| FR-WEB-005 | 种子详情 | 头部（插槽 `torrent.detail.header`）、信息区（`torrent.detail.info`）、侧栏（`torrent.detail.sidebar`）、操作（下载按钮 + `torrent.detail.actions`）、标签页（`torrent.detail.tabs`） | P0 | |
| FR-WEB-006 | 作品页 | `group.detail.header`、种子列表（按 edition 分组）、`group.detail.tabs` | P0 | |
| FR-WEB-007 | 上传 | 选择资源类型 → 类型表单（`torrent.upload.type_form`，默认由 schema 生成）→ 扩展区（`torrent.upload.extra`）→ 提交；显示钩子返回的错误（字段级） | P0 | |
| FR-WEB-008 | 用户中心 | 个人页（`user.profile.*` 插槽）、设置页（`user.settings.tabs`） | P0 | |
| FR-WEB-009 | 后台框架 | 后台布局、入口插槽 `nav.admin`、仪表盘 `admin.dashboard.widgets`、插件设置页（schema 自动生成或插件自定义）、用户 / 种子管理标签页插槽 | P0 | |
| FR-WEB-010 | 插件加载 | 启动时获取 `/api/kernel/v1/frontend/manifest`，按需动态 import 插件 ESM 入口；共享依赖经 import map 提供；插件路由 `/p/<id>/*` 与 `/admin/p/<id>/*` | P0 | |
| FR-WEB-011 | 插槽 | `<Slot name ctx>` 组件：类型 list / single / tabs / columns；错误边界隔离；懒加载；批量预取接口（见 03） | P0 | |
| FR-WEB-012 | Schema 表单 | JSON Schema 2020-12 + `x-pt-*` 扩展 → 表单（字段控件、校验、错误展示、条件显示） | P0 | |
| FR-WEB-013 | 术语与 i18n | `t('term:<key>')` 取站点术语（`/api/kernel/v1/terms?locale=` 快照，版本头失效）；界面文案 i18n（zh-CN、en，可扩展） | P0 | |
| FR-WEB-014 | 主题 | 设计令牌（CSS 变量）；亮 / 暗模式跟随系统，可手动切换；站点可提供多个主题，用户自选 | P1 | |
| FR-WEB-015 | 响应式 | 375 px 起可用；表格在窄屏转卡片 | P0 | |
| FR-WEB-016 | 可访问性 | WCAG 2.2 AA：键盘可达、焦点可见、对比度、ARIA | P1 | |
| FR-WEB-017 | 错误处理 | problem+json 错误统一展示（错误码 → 本地化文案，未知码显示 message）；网络错误重试；全局错误边界 | P0 | |
| FR-WEB-018 | 用户内容渲染 | 服务端已净化的 HTML 以受控方式插入（只在专用组件中使用 `dangerouslySetInnerHTML`，并加 DOMPurify 二次净化）；纯文本一律文本节点 | P0 | |
| FR-WEB-019 | 二次开发 | 文档化的扩展方式：替换主题、覆盖页面组件（`overrides` 映射）、新增路由；不修改核心源码即可定制 | P1 | |

## 4. 非功能需求

| 编号 | 描述 | 指标 |
|---|---|---|
| NFR-WEB-001 | 首屏 | 登录后首页 LCP < 2.0 s（4G、中端手机） |
| NFR-WEB-002 | 包体积 | 初始 JS（gzip）≤ 180 KiB；每个路由块 ≤ 80 KiB |
| NFR-WEB-003 | 交互 | INP < 200 ms |
| NFR-WEB-004 | 安全 | CSP：`script-src 'self'`（无 inline / eval）；Trusted Types（支持的浏览器）；插件脚本同源 |
| NFR-WEB-005 | 兼容 | §2.4 浏览器矩阵 |

## 5. 可配置项

运行时（`/api/kernel/v1/frontend/manifest` 返回）：站点名、默认语言、可用主题、插件列表与入口、功能开关。构建时：API 基础路径、CDN 前缀。

## 6. 外部接口需求概述

依赖内核：`/api/kernel/v1/frontend/manifest`、`/openapi.json`、`/terms`、`/session`；依赖插件：各插件 OpenAPI 路由。对插件提供：`@pt-studio/slots`（类型与运行时 API）、import map 中的共享依赖。
