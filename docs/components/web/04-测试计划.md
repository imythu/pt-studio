## 1. 测试范围与策略

| 层次 | 工具 | 内容 |

| 单元 | Vitest | SDK 错误映射、幂等键、术语函数、schema → 控件映射、batch 合并 |

| 可访问性 | axe-core | WCAG 2.2 AA 自动检查 |
